Куда растёт СИНГУЛЯР

Закономерность линии: каждая версия устраняет один класс слепого доверия. 06 закрывает последний класс в одиночном файле — происхождение примитива. Дальше масштаб решает: файлы должны находить друг друга.

Эволюция ядра

01 Лаб: файл → текст
02 Фабрика: файл → продукт + материя
03 Runtime: намерение → граф → доказательство
04 Геном: типизированный граф → хэш-цепь → кристаллизация → файл-память
05 Песочница: граф → изолированный исполнитель → измерение → VERIFIED
06 Контракт: граф → подписанный пакет → золотые векторы → планировщик по стоимости
дальше: рой → словарь гипотез → аудит и GC → эмерджентное приложение

Принципы 06

1. Пакет самодостаточен: путь + условия + векторы + подпись.
2. Доверие — вычислимо: SIGNED → TESTED → VERIFIED (воспроизведения).
3. Стоимость ребра = время × множитель риска уровня доверия.
4. Планировщик — Дейкстра, не BFS: дешёвый непроверенный путь проигрывает дорогому проверенному.
5. Неподписанное ≠ враждебное, но всегда дороже.

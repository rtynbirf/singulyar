04 · прогноз как инженерная гипотеза

Генеральный план 2026 → 2032

Это не предсказание с вероятностью. Это моя экстраполяция из уже наблюдаемых технических направлений.

2026–2027 · ADAPTIVE RUNTIME

UI становится функцией состояния

Состояние, история и capability graph начинают определять, какие controls и представления вообще нужны. Responsive остаётся физическим слоем, но перестаёт быть всей адаптацией.

2027–2029 · COMPOSABLE AGENTIC WEB

Сайт превращается в исполняемый граф

Данные, инструменты и UI связываются через явно описанные capability. Агент предлагает план, но детерминированный runtime решает, что разрешено выполнить.

2029–2031 · EVIDENCE-NATIVE WEB

Происхождение результата становится частью интерфейса

Claim, input, operation, test и result образуют проверяемую цепочку. «Ответ» без происхождения теряет инженерную ценность.

2031–2032+ · EMERGENT APPLICATION

Приложение перестаёт иметь фиксированную форму

Устойчивые композиции capability превращаются в новые примитивы. Пользователь видит не заранее спроектированный сайт, а текущую конфигурацию локального вычислительного пространства.

Ключевой переход

Было: page → components → API calls
Сейчас: state → intent → components
Следующий слой: intent → capability graph → verified state → generated view
Эмерджентный слой: verified graph → reusable capability → новый graph

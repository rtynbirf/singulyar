## Способ 1 — из git (самый честный)

```
git log --oneline --all -- index.html | grep -i хозЯИН
# найти коммит v1.45.0 (44b536b) и взять index.html из него:
git show 44b536b:index.html > index.html
```

## Способ 2 — из снимка руками

В снимке три блока с пультом:

1. `<style>`: комментарий `/* ── ПУЛЬТ ХОЗЯИНА (v1.45.0) … */` до конца блока
   (правила `.пульт-хозяина`, `.пульт-группа`, `.пульт-разделитель`,
   `.пульт-трек` и медиа-правило) — скопировать в `<style>` живого лица.
2. `<body>`: `<div id="пультХозяина" class="пульт-хозяина" …>…</div>` целиком
   (внутри секции `crystalTitle`) — скопировать на то же место.
3. `<script>`: обработчики пульта — искать `музПлей`, `музПауза`, `музСтоп`,
   `музРепит`, `музСлучайно`, `пультХозяина` — скопировать блок целиком.

Проверка: открыл лицо → пульт над шаром → ПЛЕЙ играет фонд `minus/` →
нить внизу ведёт по дому.

## Почему пульт мог уйти

На такте v1.46.0 «СЦЕНА» дом получил дверь ·32 — настоящее караоке фонда
(62 минусовки + тексты + очки). Пульт же был помечен «временно». Решение
за владельцем: остаётся ли пульт на лице, уходит в угол или возвращается —
I-01: ЧЕЛОВЕК РЕШАЕТ.

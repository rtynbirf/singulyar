# ЛАДОМ v0.2.0 — полностью переписанный прототип

Чистая модульная архитектура вместо монолита 1.68 МБ.

## Что исправлено относительно оригинала

| Косяк оригинала                    | Как сделано здесь                          |
|------------------------------------|--------------------------------------------|
| 1.68 МБ один файл                  | Модули: HTML + CSS + JS + data             |
| 97 версий вперемешку               | Один источник — VERSION в data/song.js     |
| eval()                             | Полностью отсутствует                      |
| 85 × innerHTML                     | Только textContent / createElement         |
| CSP unsafe-inline + unsafe-eval    | Жёсткий CSP в meta (пример)                |
| Дневник разработчика в UI          | Только пользовательский текст              |
| 537 кнопок, accessibility-дыры     | Все кнопки с aria-label / aria-pressed     |
| Заявление «сеть не нужна» + CDN    | Ноль внешних зависимостей                  |

## Структура

```
ladom-v2/
├── index.html          # тонкий шелл + CSP
├── css/main.css
├── js/
│   ├── app.js          # точка входа
│   ├── state.js
│   └── lyrics-engine.js
├── data/song.js        # песня + версия
├── SECURITY.md         # полный разбор дыр оригинала
└── README.md
```

## Запуск

Открой `index.html` в браузере  
или:

```bash
npx serve .
```

## Клавиши

- Пробел — хлопок / старт
- R — заново
- Esc — закрыть справку

## Что намеренно не включено в этот срез

Реальный audio-элемент + Web Audio, полный текст-пульс по слогам, лаборатория цветов, голосовые команды, PeerJS, Service Worker.  
Всё это добавляется поверх этой архитектуры без возврата к монолиту.

# СИНГУЛЯР — офлайн-вселенная караоке RUVSON

Полностью автономная караоке-платформа: **61 песня × 158 языков · ОРКЕСТРАТОР ·15 · ОС из 17 модулей · PWA**.
Один HTML-файл = вся платформа: без сервера, без установки, без интернета. Скачал — открыл — поёшь.

**Живой сайт (PWA):** https://rtynbirf.github.io/singulyar/

---

## Быстрый старт — три пути

| Путь | Как | Что получишь |
|---|---|---|
| **Сайт (рекомендуется)** | Открой https://rtynbirf.github.io/singulyar/ | Платформа онлайн, устанавливается как PWA, работает офлайн после первого визита (service worker `sw15.js`) |
| **Единый файл ОС** | Скачай `SINGULYAR_OS_v17_13_MODULES.html` (= СИНГУЛЯР_ОС v1.7, GitHub хранит имена релизов латиницей) из [Release v1.7](https://github.com/rtynbirf/singulyar/releases/tag/v1.7) и открой в браузере | Все 13 модулей в одном файле, 100% офлайн с первого открытия |
| **Локальная копия репо** | `git clone` → открой `index.html` (или `python -m http.server`) | Полная копия сайта на своём диске |

Подробности, горячие клавиши и диагностика — в [ИНСТРУКЦИЯ_СТАРТ.md](ИНСТРУКЦИЯ_СТАРТ.md).

## СОБЫТИЕ ·18 — как это работает (по архитектуре «СОБЫТИЕ/СОВМЕСТНОЕ ПЕНИЕ/ПАМЯТЬ»)

- **LOCAL CORE не тронут**: без интернета всё по-старому; зал — функция, не зависимость.
- **ROOM**: LOBBY → READY → COUNTDOWN → SINGING → FINISH → REVIEW; хост-авторитет + миграция хоста.
- **Участники**: только имя + эмодзи (никаких email/password); слушатель без микрофона — равноправен.
- **Голоса**: WebRTC mesh (до ~4–5 участников), MediaTransport-абстракция: ретранслятор Nostr (между
  устройствами) или BroadcastChannel+WebRTC (окна одного браузера, без сети).
- **Синхронизация**: ping/pong clock-offset (медиана), старт от единого timestamp — «3-2-1-🎵» у всех одновременно.
- **Запись**: WebAudio-микс (минусовка + все голоса) → MediaRecorder → IndexedDB у КАЖДОГО участника.
  Серверу не достаётся ни байта голоса. Политика памяти (одного достаточно / все должны ❤️) — в манифесте события.
- **ПАМЯТЬ**: TEMPORARY 7 дней → ❤️ навсегда; фото (сжатие до 640px) + подпись; экспорт webm; GC стирает
  просроченные временные записи при старте (метаданные + blob, безвозвратно).
- **Честные границы**: mesh упирается в O(n²) соединений (для 3–5 человек — то что нужно; дальше SFU в дорожной карте);
  TURN-релея нет — за жёстким симметричным NAT голос может не пробиться; записи живут в браузере каждого,
  серверного хранилища воспоминаний нет (это осознанно: приватность по умолчанию).

## Технические принципы

- **Ноль `innerHTML`** — вся отрисовка через DOM-фабрику (`textContent`), XSS-безопасно
- **Честные счётчики** — «×157», «61×13» и пульс платформы считаются из фактических данных
- **Импорт LRC/SRT/VTT/TXT** со строгой валидацией до сортировки; экспорт LRC/VTT (караоке-теги)/JSON
- **Мастер-часы** `audio.currentTime + rAF`; темп ×0.5–1.5 и тональность ±6 пт в синтез-режиме
- **PWA**: manifest + `sw15.js` (cache-first), Media Session, RTL для ar/he/fa/ur, режим «не смотреть» (aria-live)
- **IndexedDB** — свои минусовки и файлы хранятся локально
- Типизированные ошибки `S15_*`, аудиторская панель по каждой из 62 строк реестра

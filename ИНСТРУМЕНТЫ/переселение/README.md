# ПЕРЕСЕЛЕНИЕ — цех фазы 2 (переселение глобалов казны)

Фаза 1 (С22 «КАЗНАЧЕЙ») — реестр `window.__КАЗНА` в проде: 13 семей, всё на виду.
Фаза 2 (С23 «КОМОД», начата коллегой) — физическое переселение семей в ящики
с мостами-аксессорами `window.*` (enumerable:false — перечисление не смещается,
getOwnPropertyNames казну не обманешь).

Этот цех — ОБРАТНАЯ сторона переселения: инструменты, которые разбирают
прод-монолит на части и собирают назад **БАЙТ-В-БАЙТ**.

## Инструменты

- `разобрать.py` — прод-HTML → части/ + manifest.json. Каждое JS-тело проходит
  `node --check`, JSON-тело — `json.loads`. Границы — по тегам целиком
  (урок a9140e74: не резать по первому `};`).
- `собрать.py` — части/ → HTML. Лампа ЗЕЛЁНАЯ только при байт-в-байт равенстве
  sha256 источника. Красная лампа = прод правили в обход закона.

## Закон сборки

```
head + Σ( открывающий тег + тело + закрывающий тег + зазор ) + tail
```

## Части НЕ хранятся в репо

Замороженные части в репо = мусор после первого же такта. Части выводятся
из свежего байта одной командой:

```
python3 разобрать.py СИНГУЛЯР_31_ЛАДОМ.html <каталог-выхода>
python3 собрать.py <свежий-прод.html>
```

После каждого такта (своего или коллеги) — переразбор на свежем байте.

## Обряд такта с переселением (по С23 коллеги)

снапшот (typeof-гарды) → снятие полки (delete) → мост defineProperty
(enumerable:false, configurable:false) → проба в ЗДОРОВЬЕ (круг
WRITE→READ→COMPARE→CLEANUP) → ЭП-06 (титул=og=APP=sw15, кэш +1) →
эталон-инварианты → пуш с блоб-контролем ДО/ПОСЛЕ.

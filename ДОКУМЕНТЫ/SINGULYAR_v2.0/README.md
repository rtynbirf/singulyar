## Почему это золото, а не балласт

Прототип отвечает на вопрос «что если дом целиком — один локальный файл»: OPFS вместо надстроек над IndexedDB, `storage.persist()` против чистки браузером, ECDSA-подписи для почты ·24 и журналов ·25, тест-комплект пробует железо устройства прямо на месте. Это не замена дома — это эталон и донор идей: дом сверяет свои такты с арсеналом и забирает лучшее по закону «один факт — одно место».

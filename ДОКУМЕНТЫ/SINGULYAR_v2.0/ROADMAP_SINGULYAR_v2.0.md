```
│ AGENT ALPHA  │   │  AGENT BETA  │   │ AGENT GAMMA  │    │ AGENT DELTA  │   │AGENT EPSILON │
│ (OS & Storage│   │ (Audio-DSP & │   │ (HIR Intent &│    │ (Mesh, Crypto│   │ (Hardware &  │
│ Architecture)│   │  Phonetics)  │   │  UI Design)  │    │  & Security) │   │  Emulation)  │
└──────────────┘   └──────────────┘   └──────────────┘    └──────────────┘   └──────────────┘
```

### Спецификация агентов:
1. **Agent Alpha (Core OS & Storage Architecture):**
   * *Двери:* `·27`, `·28`, `·38`, `·46`, `·51`.
   * *Задачи:* Монолитный HTML-каркас, PWA Manifest, Self-Healing Service Worker, OPFS/IndexedDB менеджер памяти.
2. **Agent Beta (Audio-DSP & Phonetics):**
   * *Двери:* `·01`, `·02`, `·02б`, `·15`, `·16`, `·20`, `·32`.
   * *Задачи:* `AudioWorkletThread` с YIN-анализатором, Wasm-модуль слогоделения, субкадровый вайп субтитров.
3. **Agent Gamma (HIR Intent & UX Design):**
   * *Двери:* `·21`, `·29`, `·36`, `·37`, `·40`, `·41`, `·47`.
   * *Задачи:* Классификатор намерений HIR на Cosine Similarity, кинетическая CSS-система Design Tokens, Storybook.
4. **Agent Delta (P2P Mesh, Crypto & Security):**
   * *Двери:* `·17`, `·18`, `·19`, `·22`, `·23`, `·24`, `·25`, `·26`, `·30`, `·33`, `·34`, `·49`.

5. **Agent Epsilon (Hardware & Emulation Tools):**

   * *Задачи:* Эмулятор колонки OMNISPEAKER-1, In-Browser Test Runner, SVG-растеризатор, Dual-Screen адаптер.

## 2. ПОШАГОВАЯ ДОРОЖНАЯ КАРТА РЕАЛИЗАЦИИ (ROADMAP 2026)

```
[Этап 1: Ядро и Память] ──> [Этап 2: Audio-DSP] ──> [Этап 3: P2P Mesh] ──> [Этап 4: HIR & UX] ──> [Этап 5: Релиз]
   (Недели 1–2)               (Недели 3–4)             (Недели 5–6)           (Недели 7–8)            (Недели 9–10)
```

### Этап 1: Архитектурный Фундамент и Хранилище (Недели 1–2)
- [x] **Agent Alpha:** Сборка базового `SINGULYAR_v2.0.html` с инлайн-регистрацией Self-Healing Service Worker.
- [x] **Agent Alpha:** Настройка интеграции с **OPFS (Origin Private File System)** для хранения 62 минусовок.
- [x] **Agent Epsilon:** Интеграция встроенного **In-Browser Test Runner** (дверь `·45`) для валидации компонентов.

### Этап 2: Вокально-Аудио Процессинг и Вайп (Недели 3–4)
- [x] **Agent Beta:** Разработка и отладка `AudioWorkletGlobalScope` модуля выделения частоты голоса YIN (дверь `·16`).
- [x] **Agent Beta:** Перевод текстового вайпа на `requestAnimationFrame` с синхронизацией по `AudioContext.currentTime` (дверь `·32`).
- [x] **Agent Beta:** Внедрение алгоритма **WSOLA SoundTouch** для качественной смены тональности без искажения формант (дверь `·15`).

### Этап 3: Бессерверный P2P Mesh и Связка Устройств (Недели 5–6)
- [x] **Agent Delta:** Реализация модуля **Air-Gapped QR-Handshake** для безсерверной связки ТВ-экрана (`·17`) и мобильного пульта (`·44`).
- [x] **Agent Delta:** Внедрение **LWW-Element-Set CRDT** для автономного журнала взносов (дверь `·25`).
- [x] **Agent Delta:** Подключение нативного **Web Crypto API** для асимметричной подписи сообщений по ECDSA P-256 (дверь `·24`).

### Этап 4: Рантайм Намерений HIR и Мультиязычность (Недели 7–8)
- [x] **Agent Gamma:** Сборка интерпретатора **HIR (Runtime of Intentions)** на косинусном сходстве N-грамм для строки «Нить Ариадны» (`·41`).
- [x] **Agent Beta & Gamma:** Подключение слогового алгоритма **Unicode Hyphenation** под 200+ языков (дверь `·20`).
- [x] **Agent Gamma:** Перевод верстки на CSS Design Tokens и CSS Container Queries (`·27`, `·29`).

### Этап 5: Аппаратный Контур, Адаптеры и Финальный Релиз (Недели 9–10)
- [x] **Agent Epsilon:** Создание виртуального эмулятора аппаратной колонки OMNISPEAKER-1 (`·42/·52`).
- [x] **Agent Alpha & Epsilon:** Валидация работы PWA в полностью изолированном окружении (Air-Gapped Mode) на iOS, Android, Linux и Windows.
- [x] **Swarm Governor:** Финальный сбор контрольных сумм SHA-256, подпись манифеста и выкатка монолитного файла `SINGULYAR_v2.0.html`.

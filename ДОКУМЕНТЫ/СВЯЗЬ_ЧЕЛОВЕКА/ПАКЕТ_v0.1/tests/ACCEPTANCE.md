# Приёмочные проверки

## Локальная функциональность

- [ ] Страница открывается без сети после распаковки; внешние запросы отсутствуют.
- [ ] Можно добавить контакт, перезагрузить страницу и увидеть его снова.
- [ ] Можно сохранить намерение и увидеть честный статус «только локально».
- [ ] Пустое сообщение не создаётся.
- [ ] Экспорт создаёт JSON с `schema=singulyar.local.v0.1`.
- [ ] Импорт своего экспорта восстанавливает контакты и записи.
- [ ] Импорт неправильного JSON отклоняется и не уничтожает существующие данные.
- [ ] Импорт файла более 2 МБ отклоняется.
- [ ] Очистка данных требует подтверждения.
- [ ] Настройки доступности сохраняются и остаются локальными.
- [ ] Крупный текст и высокий контраст применяются без перезагрузки.
- [ ] Клавиатурой можно пройти все элементы; фокус видим.
- [ ] Озвучивание сообщает статус или корректно сообщает об отсутствии SpeechSynthesis.

## Этическая/семантическая честность

- [ ] Нигде не говорится, что сообщение отправлено другому человеку.
- [ ] Нигде не заявляется E2EE или шифрование локального журнала.
- [ ] Номер, SMS, eSIM, email-hosting и платёж помечены как неподключённые.
- [ ] Профиль доступности не отправляется автоматически.
- [ ] Очистка предупреждает, что экспорт следует сделать заранее.

## Интеграция с Домом дверей

- [ ] Перед patch записан commit SHA и чистый `git status`.
- [ ] Новая дверь добавлена минимальным diff; исходные двери не удалены.
- [ ] URL с кириллицей открывается на GitHub Pages.
- [ ] Проверены кэш/service worker и версия ресурсов.
- [ ] Нет новых сетевых запросов к сторонним доменам.
- [ ] Пройдены мобильный viewport, клавиатура и экранный диктор.

## Будущие реальные адаптеры

- [ ] Adapter contract tests покрывают успех, отказ, отмену, повтор, timeout, rate limit.
- [ ] Доставка не подтверждается одним лишь HTTP 200/`send()`.
- [ ] Ключи и provider secrets отсутствуют в frontend и репозитории.
- [ ] Независимо проверены E2EE и жизненный цикл ключей до публичных заявлений.
- [ ] Для платежа проверены получатель, сумма, комиссия, idempotency и двойная отправка.

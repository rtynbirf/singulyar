# Реестр первоисточников для следующего этапа

Ссылки ниже — первичные спецификации/официальные документы, которые следует сверять при реализации. Сам факт ссылки не означает, что функции уже реализованы.

- W3C WCAG 2.2: https://www.w3.org/TR/WCAG22/
- W3C WebRTC 1.0: https://www.w3.org/TR/webrtc/
- W3C Web Authentication (для будущих вариантов идентификации, не обязательный MVP): https://www.w3.org/TR/webauthn-3/
- IETF RFC 8446, TLS 1.3: https://www.rfc-editor.org/rfc/rfc8446
- IETF RFC 9420, Messaging Layer Security (MLS): https://www.rfc-editor.org/rfc/rfc9420
- IETF RFC 7489, DMARC: https://www.rfc-editor.org/rfc/rfc7489
- IETF RFC 7208, SPF: https://www.rfc-editor.org/rfc/rfc7208
- IETF RFC 6376, DKIM: https://www.rfc-editor.org/rfc/rfc6376
- WHATWG HTML: https://html.spec.whatwg.org/
- MDN IndexedDB API: https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API
- MDN Web Crypto API: https://developer.mozilla.org/en-US/docs/Web/API/Web_Crypto_API
- MDN WebRTC connectivity: https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API/Protocols
- JSON Schema 2020-12: https://json-schema.org/draft/2020-12
- OWASP ASVS: https://owasp.org/www-project-application-security-verification-standard/
- OWASP Cheat Sheet Series: https://cheatsheetseries.owasp.org/
- GSMA eSIM consumer resources (background; provisioning depends on operators/devices): https://www.gsma.com/solutions-and-impact/technologies/esim/

## Исследовательский протокол

Для каждого источника записать дату просмотра, версию документа, применимые разделы и проверяемое требование. Для коммерческих провайдеров дополнительно фиксировать страны, тарифы, идентификационные требования, сроки хранения, условия блокировки/переноса и процедуру прекращения сервиса. Не полагаться только на рекламные страницы.

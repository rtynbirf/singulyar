# Протокол объектной передачи v0.1 (проект)

Это прикладной контракт для будущих адаптеров, не реализованный сетевой протокол. JSON-поля версионируются; неизвестные критические версии отклоняются.

## Объект

- `schema`: идентификатор схемы;
- `id`: случайный уникальный идентификатор;
- `kind`: `text | file | voice | call_invite | value_intent | contact_invite`;
- `createdAt`: ISO 8601 UTC;
- `sender`: локальный/публичный идентификатор, не телефон как доказательство личности;
- `recipient`: выбранный адресат;
- `payload`: типизированные данные;
- `manifest`: размер, MIME, SHA-256 для бинарных объектов, политика хранения;
- `consent`: основание передачи и объём разрешения;
- `delivery`: состояние и подтверждение транспорта.

## Семантика

1. Повторная отправка одного `id` не должна создавать двойной платёж или дублировать действие с побочным эффектом.
2. При повторе адаптер обязан использовать idempotency key, если поддерживается.
3. Хеш проверяет целостность, но сам по себе не доказывает автора.
4. Срок хранения — политика, а не гарантия стирания всех копий.
5. `value_intent` не равен переводу денег и не должен показываться как завершённый платёж.
6. Подтверждение доставки содержит `transport`, `observedAt`, `evidence`, `adapterVersion`; «прочитано» допустимо только если адресат/клиент дал соответствующее подтверждение.

## Возможная машина состояний

`draft → locally_saved → queued → attempting → accepted_by_transport → acknowledged_by_recipient → read_receipt_optional`.

Терминальные состояния: `cancelled`, `failed`, `expired`. Сетевые ошибки не удаляют исходный объект.

## Границы честности (не реализовано — и не имитируется)

- Реальная межсетевая доставка (SMS/eSIM/PSTN/почтовый сервер/платежи) — внешние провайдеры, шаг ROADMAP комплекта; двери ·24/·25/·26 дома — место для их адаптеров.
- E2EE поверх P2P-канала: ключи и отпечатки генерируются (Web Crypto), но шифрование payload в канале не включено — честная помета, шаг WP-06 комплекта.
- Сигналинг — ручной обмен SDP-токенами (Zero-Server); QR-передача токенов — шаг карты (эмуляторы П.7 уже в доме).

## Как проверять

1. Песочница: `python3 ДОКУМЕНТЫ/ПОЛИМАТ_ВИТОК_3/СВЯЗЬ_ЧЕЛОВЕКА/v1.0-final/singulyar_core.py` — Conformance 10/10.
2. Целостность: `cd ДОКУМЕНТЫ/ПОЛИМАТ_ВИТОК_3/СВЯЗЬ_ЧЕЛОВЕКА/v1.0-final && sha256sum -c MANIFEST.sha256`; их пакет v0.1: `cd ДОКУМЕНТЫ/СВЯЗЬ_ЧЕЛОВЕКА && sha256sum -c SHA256SUMS`.
3. Дверь дома: две вкладки `СИНГУЛЯР_53_СВЯЗЬ_ЧЕЛОВЕКА.html` — их Фаза 0 (локальные намерения) + мой контур v1.2 (ключи → P2P → ACK → журнал); каждая кнопка отвечает.
4. Тест-страж дома: `python3 ИНСТРУМЕНТЫ/test_singulyar_53.py` — 20/20.
5. Локальный LAN-сервер для телефона: `python3 ДОКУМЕНТЫ/СВЯЗЬ_ЧЕЛОВЕКА/serve_p2p.py` (руководство рядом).

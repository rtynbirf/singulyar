# ВЕС ДЕПЛОЯ — расчёты I-01 / I-02 / I-03 (П.5, решение за владельцем 👤)

> **Такт:** v11.20 «АРСЕНАЛ» · **Дата:** 2026-10-14 · **Статус:** расчёты готовы, исполнение — после слова владельца
> **Источник цифр:** аудит живого сайта (коллега-агент, блокнот владельца 2026-10-14), строки 4214/4220: деплой **1209 МБ** > лимита Pages **1024 МБ**; `minus/` = **1102 МБ** = 62 × `max.webm` **827 МБ** + mp3-дубль **202 МБ** + прочее ≈ 73 МБ; топ-файл `minus/Qb8xb0vUYDg.max.webm` — **86,2 МБ** (битрейт 510k, впритык к гит-лимиту 100 МБ).

## I-01 · Битрейт max.webm 510k → 128k — РЕКОМЕНДОВАН ПЕРВЫМ ШАГОМ

Арифметика: 827 × (128/510) ≈ **208 МБ** → экономия **≈ 619 МБ** → деплой ≈ **590 МБ** (запас до лимита ≈ 434 МБ). Консервативная оценка аудитора «≈ −500 МБ» даёт деплой ≈ **709 МБ** — тоже под лимитом с запасом.

- **Почему честно:** Opus 128k прозрачен для голоса и музыки на битрейтах источника; караоке-качество не деградирует заметно.
- **Цена работ:** один проход перекодирования 62 файлов (`ffmpeg -c:a libopus -b:a 128k`), имена файлов не меняются — **ноль изменений кода**; верификация ffprobe-длительностями против осей текста (канон v10.85 «СИНХРОН»: длительность мастера = длительность оси ±5 с).
- **Риски:** минимальны; обязательный контрольный прогон СЦЕНЫ ·32 после замены.

## I-02 · mp3-дубль (202 МБ) сделать опциональным — ТОЛЬКО ВРЕМЕННАЯ МЕРА

Арифметика: 1209 − 202 = **1007 МБ** — под лимитом, но запас **17 МБ** (1,7%): одна новая песня вышибет дом за лимит. mp3 — фолбэк для старых браузеров без Opus; их отрыв делает фолбэк пустым.

## I-03 · Мастера webm в GitHub Releases — СТРАТЕГИЧЕСКИ, НО НЕ БЕСПЛАТНО

Арифметика: webm 827 МБ уезжает из Pages → деплой ≈ **382 МБ** — максимальный запас (≈ 642 МБ).

- **Цена работ не нулевая:** Releases-ассеты отдаются без CORS-заголовков → голый `<audio>` играет, но Web Audio API (гармония, пульс, хвосты v10.85) требует `fetch` + CORS — клиенту нужен прокси-слой или другой хост мастеров. Это изменение кода дома и отдельное решение.
- **Плюс:** топ-файл 86,2 МБ перестаёт дышать на границе гит-лимита 100 МБ.

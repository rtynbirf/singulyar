## Что сделано

### 1. СПРАВКИ ВЕЗДЕ — ux-engine v9.4 → v9.5
Раньше подсказка при наведении бралась из `aria-label → placeholder → текст
элемента` — то есть тупо повторяла то, что и так написано на клавише. Это
эхо, а не справка. Теперь у справки честный приоритет:

1. `data-справка` страницы — автор сказал правду о своём контроле;
2. словарь дома — известные контролы (кристалл, намерение, «Я сам», двери,
   бирка, нить, пульт) — известные справки;
3. разрешение ссылки по манифесту ядра: наведи на любую дверь — получишь
   «Дверь ·22 СВЯЗЬ: девять каналов связи, fallback вниз, мост ·21⇄·22.
   Открыть комнату.»;
4. роль элемента: отправка формы, свернуть/развернуть, внешняя ссылка
   (честно предупреждает: «уйдёт из дома в сеть»);
5. и только в самом конце — ярлык, если о контроле больше нечего сказать.

Состояние переключателей входит в справку: у РЕПИТ и СЛУЧАЙНО при наведении
говорится «Сейчас: включено/выключено». По-прежнему только нативный `title`:
ничего не рисуем, ничего не перекрываем, `data-нет-подсказки` — явный отказ
страницы.

### 2. СКВОЗНАЯ НАВИГАЦИЯ — в бирке каждой комнаты
Бирка `⬢ МОДУЛЬ ·XX` в каждой из 20 комнат получила навигационный кластер:
**⌂ хаб · ← предыдущая дверь · следующая дверь → · ⌇ нить**. Дом проходится
насквозь по кругу, не возвращаясь на лицо. Строится ядром (SNG v1.10.0) из
манифеста — «манифест — истина»; у каждой ссылки честная справка с кратким
описанием той двери, куда она ведёт. На лице дома сквозной путь — нить
Ариадны + «Я сам» (закон лица дома не тронут: бирка на лице не появляется).

### 3. ПУЛЬТ ХОЗЯИНА — музыка над шаром (временно, для владельца)
Над кристаллом — стекло-панель с клавишами **ПЛЕЙ · ПАУЗА · СТОП · РЕПИТ ·
СЛУЧАЙНО** и строкой «что играет»: «♪ Название — n/62». Плюс сквозная
навигация: **⌇ нить** (открывает все двери) и **¶ доки**.

- Играет **ЛОКАЛЬНЫЙ фонд дома**: 62 минусовки из папки `minus/` — те же
  файлы, что у дверей ·15 ОРКЕСТРАТОР, ·16 СУФЛЁР, ·18 СОБЫТИЕ. Ноль сети.
- РЕПИТ — текущая песня по кругу (`loop`), СЛУЧАЙНО — после конца песни
  ставит случайную, не повторяя текущую; без режимов песни идут по порядку
  фонда. Номер песни и режимы помнит `localStorage` (гард КОРДа).
- Ошибки честные: файл не читается — пульт говорит об этом словами, не
  падает. Весь пульт в try/catch — лицо дома он уронить не может.
- Канон соблюдён: стекло + void, золото — единственный акцент, ноль
  innerHTML, все справки через `data-справка`/словарь v9.5.

### 4. УБОРКА — YouTube-хвосты выкурены из названий песен
Все видимые человеку списки песен были в YouTube-обрезках: «Где настоящее |
RUVSON (Премьера 2026)», «RUVSON — Свет в темноте ‣ Песня для тех кому
сейчас тяжело», «Не Угасай — трек который цепляет», «Остаться человеком
·t4wQ». Выкурено в трёх местах: каталог ·01 (61 запись), каталог ·18
(62 записи), `ИНСТРУМЕНТЫ/s18_catalog.json` (62 записи). Остались чистые
имена: «Где настоящее», «Свет в темноте», «Не Угасай», «Бой с собой».
Проверено сканом: порно и непотребства в доме НЕ найдено ни в одной комнате
(62 названия песен, все тексты, все документы — чисто); вложенные авторские
документы (·02: драфты и транскрипты) не тронуты — это архив автора.

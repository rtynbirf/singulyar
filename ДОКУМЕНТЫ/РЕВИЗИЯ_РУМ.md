## Что выкурено в этом такте (v1.40.0)

### РУМА-1 · СИНГУЛЯР_01 «Когда теряем 157 голосов» — ЗАКОНЧЕНА до бела
- **Ноль живых innerHTML.** Было 28 присвоений; 18 — в живом коде, 10 — цитаты
  граббера внутри мастер-плана (данные документа, не тронуты). Все 18 живых
  выкорчеваны в DOM API: `replaceChildren()`, `createElement`, `textContent`
  (экранирует сам — лишние `esc()` вокруг карточек ушли). Сборка карточек
  `cardHTML(c)` (строка) → `mkCard(c)` (DOM руками).
- **Ремонт глифа избранного.** Баг: `textContent = on ? '' : ''` — обе ветки пустые.
  Кнопка плеера рождалась пустой, карточка ТЕРЯЛА глиф `◈` при первом клике.
  Стало честно: `◇` (не в избранном) ↔ `◈` (в избранном), согласовано с карточками
  каталога. Проверено живым браузером: клик меняет глиф туда-обратно.
- **Правка врущих комментариев.** «MODAL песни (каталог → заглушка)» — модал рабочий
  инструмент, комментарий исправлен.
- **Свой смоук-тест.** `ИНСТРУМЕНТЫ/test_s01_smoke.py` (Playwright, 7/7): открытие без
  pageerror, DOM-сборка карточек, глиф ◇/◈ в плеере и карточках, консоль чиста.
- **Синтакс-проверка** всего живого скрипта (node --check) — ОК.

### Сервер СИНГУЛЯРА — декларация стала рабочим инструментом
- **Ноль внешних зависимостей.** `server/server.mjs` больше не импортирует npm-пакет
  `ws` — WebSocket (RFC 6455: handshake, фрейминг, фрагментация, ping/pong, close,
  защита от не-маскированных клиентов и payload > 16 МБ) встроен своими руками
  (~130 строк, комментирован). Следствие: **склонировал дом → `node server.mjs` →
  живо.** `npm install` больше не нужен никому и никогда.
- **s19-серверные тесты оживлены** — падали у КАЖДОГО, кто клонировал репо (сервер
  не поднимался без node_modules; сам тест тоже требовал `ws` для клиента). Теперь
  тест юзает нативный WebSocket node (≥22) с fallback на `ws`. Прогон: **12/12**.
- **README сервера перестал врать:** удалён обязательный `npm install`; таблица
  контракта дополнена честным `/api/ws/ticket` + `/ws?ticket=` (путь `/ws?token=`
  закрыт навсегда с v1.25.1 — а README ещё продавал старый).
- **`server/.env.example` создан** — README на него ссылался, файла не существовало
  (декларация без тела). Теперь есть: все переменные окружения с комментами.
- `server/package.json` v1.1.0: `"dependencies": {}`, engines `>=22`.

# ТРАНСПОРТ — каналы дома без Wi-Fi (air-gapped + ультразвук)

> **Такт:** v11.20 «АРСЕНАЛ» · **Дата:** 2026-10-14 · **Источник:** блокнот владельца `notebook.google.com` (2026-10-14) · **Двери:** ·17 ЗАЛ, ·22 СВЯЗЬ, ·30 ТКАНЬ
> **Закон приёмки:** артефакты владельца приняты байт-в-байт; README — единственная новая строка.

## Зачем это дому

Зал ·17 соединяет экран и пульты по WebRTC, но настоящая автономия начинается там, где нет ни Wi-Fi, ни роутера, ни облака. Здесь лежат четыре эмулятора каналов и один звуковой пилот — прототипы транспорта «из воздуха».

## Артефакты

| Файл | Канал | Суть |
|---|---|---|
| `qr_sdp_emulator.gif` | QR-рукопожатие | Главный экран показывает динамический QR с SDP-оффером; пульт сканирует камерой — DataChannel поднимается без сигнального сервера |
| `qr_sdp_answer_emulator.gif` | QR-ответ | Обратная нога рукопожатия: пульт возвращает answer тем же способом |
| `qr_fountain_droplets_emulator.gif` | Фонтанные капли | Передача большого файла каплями-QR в любом порядке: собрал k уникальных капель — собрал файл (фонтанные коды) |
| `merkle_proof_qr_emulator.gif` | Merkle-доказательства | Целостность полученного: каждая капля несёт доказательство в merkle-дереве — подделка видна сразу |
| `fallback_cascade_emulator.gif` | Каскад деградации | Если QR не читается — канал падает по лестнице: QR крупнее → дольше → голосом/буквами; связь держится до последнего |
| `ultrasonic_pilot_chirp.m4a` | Ультразвуковой FSK-пилот | Синхронизация экран↔колонка звуком за пределами слышимости (≈18–20 кГц): chirp-пилот, FSK-модуляция |
| `ultrasonic_fsk_spectrum.png` | Спектрограмма пилота | Улика: виден частотный план chirp-пилота |

## Смысл — транспорт отдельно

MEANING ≠ TRANSPORT: смысл (что передаём) не зависит от канала (чем передаём). Эти эмуляторы — запасные дороги дома: интернет может умереть, дом — нет.

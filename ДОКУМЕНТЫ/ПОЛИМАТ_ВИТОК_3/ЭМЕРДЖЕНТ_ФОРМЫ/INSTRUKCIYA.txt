ИНСТРУКЦИЯ ПО ВОСПРОИЗВЕДЕНИЮ
================================

Цель: любой человек, не зная меня, берёт этот архив и получает
точно тот же набор форм, который был задуман.

1. Открой index.html в любом современном браузере.
   Там 50 карточек с SVG-визуализациями + координатами вершин.

2. Папка polyhedra_data/ содержит JSON-файлы:
   каждый файл = одна фигура.
   Формат:
   {
     "name": "...",
     "vertices": [[x,y,z], ...],   // все точки
     "faces": [[i,j,k], ...],      // индексы вершин граней
     "n_vertices": N,
     "n_faces": M
   }

3. Чтобы повторить / изменить / распечатать / отправить в Corel / Rhino / Blender:
   - возьми vertices
   - построй рёбра из faces (каждые два соседних индекса + замыкание)
   - масштаб уже нормализован (описанная сфера ≈ 1)

4. Оператор (эмерджентная сингулярная):
   SEED (любой из 46-50) + набор направленных векторов зон
   → новое тело, в котором исходное семя остаётся читаемым.

5. Все координаты выведены из классических конструкций
   (золотое сечение φ = (1+√5)/2) и операций Харта (zonish expansion).

Это полный reproducible package.
Достаточной информации не бывает много.

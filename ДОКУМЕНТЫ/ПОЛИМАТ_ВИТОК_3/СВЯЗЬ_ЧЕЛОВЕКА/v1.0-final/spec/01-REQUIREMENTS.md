# 01-REQUIREMENTS.md · Техническое Задание v1.0

## Функциональные требования
* **FR-01 (Типы намерений):** Поддержка `text`, `file`, `voice`, `call_invite`, `value_intent`, `contact_invite`.
* **FR-02 (Формат объекта):** Валидация JSON-схемы `singulyar.v1.0/object.json`, генерация UUID v4 и SHA-256 манифеста.
* **FR-03 (Машина состояний):** Строгий контроль графа переходов `draft` → ... → `read`.
* **FR-04 (P2P WebRTC):** Использование RTCDataChannel с контролем подтверждения доставки (ACK).
* **FR-05 (E2EE Crypto):**ECDH P-256 + AES-256-GCM шифрование с генерацией 32-символьного отпечатка SHA-256.
* **FR-06 (Value Intent Disclaimer):** Автоматическая вставка предупреждения *«DISCLAIMER: NOT A BANK TRANSFER»*.

## Требования к доступности (WCAG 2.2 AA)
* **NFR-01:** Поддержка режима крупного шрифта (125%) и высокой контрастности.
* **NFR-02:** Синтез речи (TTS) через Web Speech API.
* **NFR-03:** Полная навигация с клавиатуры и корректные ARIA-атрибуты (`aria-live="polite"`).

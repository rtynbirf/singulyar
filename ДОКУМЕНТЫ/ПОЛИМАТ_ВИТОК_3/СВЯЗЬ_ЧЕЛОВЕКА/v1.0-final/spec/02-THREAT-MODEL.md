# 02-THREAT-MODEL.md · Модель Угроз и Границы Безопасности v1.0

## 1. Профиль Противников (Threat Actors)
1. **Сетевой наблюдатель (Passive MITM):** Прослушивание трафика. *Защита:* WebRTC DTLS/SFrame, E2EE AES-256-GCM.
2. **Вредоносный узловой сервер (Malicious Relay/Signaling):** Перехват токенов SDP. *Защита:* Ручной/P2P сигналинг, шифрование SDP токенов.
3. **Локальный вредоносный скрипт / Браузерное расширение:** Чтение хранилища. *Защита:* Изоляция IndexedDB, контроль Web Locks API.
4. **Атака повторного воспроизведения (Replay Attack):** Повторный запуск `value_intent`. *Защита:* Уникальный `idempotency_key` и метка времени ISO 8601 UTC.

## 2. Честные Границы (Fair Boundaries)
* Система НЕ гарантирует стирание данных у собеседника после доставки.
* Система НЕ защищает устройство от компрометации на уровне OS/Rootkit.
* Система НЕ является методом анонимного обхода блокировок.

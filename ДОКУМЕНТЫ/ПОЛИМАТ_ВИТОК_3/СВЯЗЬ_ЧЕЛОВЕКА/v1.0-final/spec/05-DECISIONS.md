# 05-DECISIONS.md · Реестр Решений (ADR)

* **ADR-001 (Подключение Дверей):** Безопасный патч главного `index.html` без переименования или повреждения существующих дверей.
* **ADR-002 (Переход на IndexedDB):** Отказ от `localStorage` в пользу `IndexedDB` с транзакционным журналом аудита и Web Locks API.
* **ADR-003 (Шифрование E2EE):** Использование стандартизированного `Web Crypto API` (ECDH P-256 + AES-GCM 256-bit).
* **ADR-004 (P2P WebRTC):** Использование `RTCDataChannel` с возможностью ручного обмена токенами сигналинга без постоянного центрального сервера.

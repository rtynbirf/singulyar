# СИНГУЛЯР · Контур Человеческой Связи (v1.0 Final Emergent Blueprint)

## Главный принципиальный манифест
**СИНГУЛЯР** — это фундаментальный протокол и эталонный контур связи, ставящий человека и его намерение выше монопольных цифровых платформ и коммерческих провайдеров.

---

## Архитектурные инварианты
1. **Намерение ≠ Транспорт (Intent vs Transport):** Человек формулирует *цель* («связаться», «передать файл», «выразить намерение передачи ценности»), а система адаптирует *представление* (текст, крупный шрифт, TTS, аудио) и выбирает доступный *транспортный канал* (Local, File Export, WebRTC P2P DataChannel, Email Relay).
2. **Прозрачность зависимостей (Zero-Trust):** Никаких скрытых серверов, телеметрии или коммерческих SDK. Все внешние провайдеры (SMS, PSTN, Email, Payments) оформлены как сменяемые адаптеры с прозрачными карточками стоимости и условий передачи данных.
3. **Честная машина состояний:**
   `draft` → `locally_saved` → `queued` → `transport_attempted` → `accepted_by_transport` → `recipient_acknowledged` → `read`
   Отправка HTTP 200 или сетевого пакета не считается прочтением или доставкой адресату.
4. **Сквозная инклюзивность (WCAG 2.2 AA):** Профиль доступности хранится строго локально, обеспечивая поддержку крупного текста (125%), высокой контрастности и озвучивания через Web Speech API (TTS).

## Состав инженерного комплекта v1.0
* `index.html` — Интегрированная точка входа «Дома Дверей» СИНГУЛЯР с дверью `·53 СВЯЗЬ ЧЕЛОВЕКА`.
* `СИНГУЛЯР_53_СВЯЗЬ_ЧЕЛОВЕКА.html` — Полнофункциональный автономный P2P WebApp с поддержкой WebRTC DataChannels, Web Crypto API E2EE, IndexedDB Store и WCAG 2.2 AA.
* `singulyar_core.py` — Исполняемый модуль ядра Python с автоматическим комплексом проверок Conformance Test Suite.
* `js/singulyar_crypto.js` & `storage/indexeddb_store.js` — Модули Web Crypto API и хранилища IndexedDB с Web Locks API.
* `spec/` — Спецификации: Архитектура, ТЗ v1.0, Модель угроз STRIDE, Протокол объектов, Контракт адаптеров, Реестр решений ADR.
* `integration/` & `roadmap/` — Контракты интеграции дверей, Дорожная карта и Декомпозиция работ (WBS WP-00…WP-12).
* `tests/` — Автоматический валидатор пакета `validate_bundle.py` и Критерии приёмки `ACCEPTANCE.md`.

## Что сделано

**`src/masked-repair.mjs`** — адресный ремонт IR (ladom.project.v1 / composition-IR) без полной перегенерации:

1. **План** `ladom.repair.v1`: `planMaskedRepair(project, mask)` фиксирует маску и текущие bbox в шагах; дубликаты маски съедаются; пустая маска / неизвестный id / locked-регион — честные TypeError. `planMaskFromOverlaps(project, {iouMin})` — эвристический планировщик маски по пересечениям: жертва — поздний в списке регионов (конвенция задокументирована в шапке модуля); locked-сосед не жертва; оба locked — «не наше дело»; пустая маска — валидный план с `overlaps: []` (честное «нечего чинить», применение вернёт `nothing-to-repair`). Это ЭВРИСТИКА, не агент — agentic repair planner остаётся открытым пунктом P4.
2. **Применение** `applyMaskedRepair(project, plan, {derive})` → `{project, report}`:
   - чинится ТОЛЬКО маска; удержанные регионы возвращаются теми же ссылками — гарантия нетронутости проверяется тестом и ссылками, и байтами;
   - план расходится с проектом (bbox шага, title, состав регионов) — честный отказ «пересоберите план» (план не применяется к уехавшему проекту);
   - `derive` вернул null / тот же bbox / пустышку — шаг `kept` (ремонт не притворяется ремонтом); derive отказал из-за отсутствия места — `blocked` (проект не меняется вовсе); отчёт `partial`;
   - грань «ремонт не наехал на удержанных» — `bboxIoU` из `qa-metrics.mjs` (та же мера, что у метрик Л3) и бьёт только НОВОЕ перекрытие: шаг со сдвигом обязан лечь свободно, наследованное пересечение (prompt-ремонт без сдвига) — не вина ремонта;
   - отчёт `ladom.repair-report.v1` без timestamps — детерминизм байт-в-байт.
3. **Офлайн-базлайн** `baselineDerive` — детерминированный fallback «без Reve» и основа будущего P4.1: попытка 0 (место свободно — не трогаем) → ступени сжатия 1.0/0.85/0.7 × решётка сдвигов 5×5 в фиксированном порядке; гарвард `MAX_ATTEMPTS=73` (1 + 3×24) ловит случайный разрастание перебора; ни часов, ни случайности — один вход → один выход.
4. **Batch experiments**: `batchRepair(project, variants)` — серия вариантов на одном входе (вход не мутируется, имена уникальны, у каждого свой derive), `pickBest(results, scoreFn)` — детерминированный максимум, при равенстве — первый по порядку; не-число от scoreFn — честный отказ.

## Честные границы

- Перекрытие отремонтированных МЕЖДУ СОБОЙ не гарантируется (каждый шаг сверяется только с удержанными) — задокументировано в шапке модуля, не спрятано.
- Модуль держит лёгкий shape-гард и НЕ заменяет канонический валидатор студии: финальная валидация — за валидатором студии (test_validator.mjs).
- «Не наехал» бьёт только новое перекрытие; наследованное видно планировщику и метрикам Л3.
- Решётка базлайна грубая (±0.2/±0.4, сжатие 15%/30%) — это черновик-базлайн для человека, не истина.
- Живой браузерный прогон (через студию) и скринридеры — 👤 владельца; здесь машинная часть.

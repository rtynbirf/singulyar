## 1. Миссия и законы

**Миссия L1 «живой Reve»**: живая визуальная сущность дома — она СЛУШАЕТ (реагирует на звук), ЧУВСТВУЕТ РИТМ (пульс/бит), РИСУЕТ (рендер поверх своей кисти), СМОТРИТ (свой глаз + липсинк/виземы), ГОВОРИТ И ПОЁТ (локальный мозг), ПОМНИТ (свой ledger/память). Реву не нужен ни один чужой сервер.

**Законы владельца (дословно)**: «МЫ САМИ МОЖЕМ СДЕЛАТЬ ТО ЧТО ОНИ СДЕЛАЛИ… НАДО ПРОСТО ВСЁ ЧТО У НИХ БЫЛО ВЗЯТЬ И УЛУЧШИТЬ САМИМ ОТ НОЛЯ ДО ИХ УРОВНЯ И ДАЖЕ НА ГОЛОВУ ЛУЧШЕ». Отсюда законы разведки: (1) БЕСПЛАТНО — ни одной платной услуги, ни одного чужого токена (закон I-13 «СВОЙ МЕХАНИЗМ», вшит в СВОД тактом v10.92 «СВОИ»); (2) ОФЛАЙН-ФЁРСТ — весь стек локальный: WASM LLM, Web Audio, WebGL/WebGPU, IndexedDB; (3) ЛУЧШЕ ОРИГИНАЛА — у чужих берём ИДЕИ и (только при MIT/Apache/BSD/ISC/CC) код, но каждая заимствованная вещь переизобретается своим механизмом с нашими преимуществами: детерминизм, 0 кредитов, альтернативный текст для незрячего (владелец видит ушами), замки, ledger.

**Наш задел (перечислено по файлам трека /ДОКУМЕНТЫ/ТРЕКИ/LADOM_SINGULAR/)**:
- `src/svoya-kist.mjs` — СВОЯ КИСТЬ (svoya-kist/0.1): рендер Project → детерминированный SVG байт-в-байт (FNV-1a палитра из промпта, экранирование строк, data-bbox точных координат, `альтернативныйТекст()` для незрячего, ledger `ladom.svoya-kist.v1`). Готова стать «телом» Рева: её SVG — холст, на котором дышат шейдеры.
- `src/svoy-glaz.mjs` — СВОЙ ГЛАЗ (svoy-glaz/0.1): extractLayout (round-trip SVG→Project байт-в-байт), reconcileLayout с маской изменённых разблокированных id (встаёт в repair-agent), применитьКоманду — их 6 команд машиной состояний с нерушимыми замками, мост toReveWire/fromReveWire (x0/y0/x1/y1). Глаз уже ВИДИТ свою картинку — чужой растр честно отказывается.
- `src/reve-adapter.mjs` — канон дома: валидатор проекта, СХЕМА_ПРОЕКТА (импорт ровно один).
- `src/music-region.mjs` — музыкальный регион трека (основа «поющей» части).
- `src/open-model-adapter.mjs` — адаптер локальных открытых моделей (слот для wllama/нейро-музыки).
- `src/repair-agent.mjs` + `src/masked-repair.mjs` — починка по маске ГЛАЗА.
- `src/sync-crdt.js` — CRDT-синк (многопользовательское «живое» состояние).
- `src/krug-profiles.js`, `src/qa-metrics.mjs` — профили КРУГ и метрики качества.
- `09_ARCHITECTURE_BLUEPRINT_RU.md` — чертёж: Intent Parser → Scene Graph → Layout IR → Constraint Solver → Renderer → Result Inspector → Repair Planner → Ledger (12 компонентов, наши интерфейсы parseIntent/buildLayout/render/inspect/planRepair).
- В доме уже стоят: **wllama** (WASM LLM локально), **adapter-os** (А3-приоритеты владельца: Whisper→OCR→gaze→Demucs→Брайль), **UX-движок** зала ·31 (ПУЛЬТ v10.96 «ГРУППЫ»: 14 групп-аккордеона, справки, скринридер), трек **КАРАОКЕ_СИНХРОН** (ПУЛЬС-СИНХРОН 00-06, PKE, ЛИНГВО 4417 строк) — карaoke-хребет уже есть, живой Reve встанет на него как на позвоночник.

## 3. Синтез: архитектура живого Reve

Шесть слоёв, каждый ДОПОЛНЯЕТ существующий механизм дома, ничего не выбрасывая:

**(а) СЛУХ** — Web Audio API: AudioContext → MediaElementSource/MediaStreamSource → AnalyserNode (getByteFrequencyData, getFloatTimeDomainData) + AudioWorklet для низколатентного извлечения признаков (RMS, спектральные полосы, onset). Единственный источник правды о звуке. Интеграция: `music-region.mjs` получает постоянный поток слуха; UX-движок зала ·31 получает ползунки чувствительности в новую группу ПУЛЬТА (v10.96 «ГРУППЫ»). Учебный эталон «живого объяснения» — ciechanow.ski/sound; канон API — MDN (строка 13 таблицы).

**(б) РИТМ/ПУЛЬС** — свой детектор битов на Web Audio (референс MIT: web-audio-beat-detector, строка 7; карта альтернатив — строка 20). Выход: beat/tatum/bar такт-часы. Интеграция: это ПУЛЬС трека КАРАОКЕ_СИНХРОН (ПУЛЬС-СИНХРОН 00-06 уже описан в доме) — Reve пульсирует синхронно с караоке-подсветкой слов (W3C WAI, строка 14 — доступные титры).

**(в) РУКА-РЕНДЕР** — шейдерный слой ПОВЕРХ СВОЕЙ КИСТИ: svoya-kist.mjs отдаёт детерминированный SVG-холст (структура, палитра из промпта, data-bbox); WebGL/WebGPU-слой дышит поверх него: FBM-шум (паттерн строки 10), бит-морфинг пресетов (паттерн Butterchurn, строка 1), compute-частицы WebGPU (строка 9). Пресет — НАШ JSON-формат, живёт в ledger `ladom.svoya-kist.v1`; fallback WebGL2 если WebGPU недоступен. ГЛАЗ не теряет зрения: шейдерный слой НЕ переписывает data-bbox — глаз по-прежнему разбирает картинку round-trip.

**(г) ВЗГЛЯД-ГЛАЗ** — svoy-glaz.mjs (сверка/команды/замки) + липсинк: MediaPipe Face Landmarker (Apache-2.0, строка 4) даёт blendshapes в браузере офлайн; они маппятся на виземы; таблица «фонема→визема» (схема строки 16) озвучивает реплики wllama: рот SVG-морды Рева морфится по реплике. Опционально 3D-аватар: three-vrm (MIT, строка 8) с MToonNodeMaterial для WebGPU-пути. Heavy-видео-липсинк (строка 17) честно вне класса — наш путь лёгкий и честный.

**(д) МОЗГ** — wllama (уже в доме, WASM LLM локально) порождает намерения/реплики/настроения Рева; open-model-adapter.mjs — слот для Magenta.js (Apache-2.0, строка 5) — инкрементальная мелодия офлайн; целевой горизонт — RealTime-нейросинтез (строка 6). Всё локально: 0 сети в рантайме.

**(е) ПАМЯТЬ** — localStorage/IndexedDB: сессии выступлений, пресеты, mood-история; append-only ledger (традиция чертежа 09, компонент 10 «Experiment Ledger») + sync-crdt.js, если Рев поют вдвоём. Каждый шаг Рева записывается, как и каждое движение КИСТИ.

Поток: МОЗГ(д) решает → РУКА(в) рисует по КИСТИ → СЛУХ(а)+ПУЛЬС(б) диктуют дыхание → ГЛАЗ(г) смотрит и говорит → ПАМЯТЬ(е) помнит. Все слои обмениваются через тот же EventLoop дома, без чужих сервисов; ни один слой не требует токена.

## 4. План от ноля до их уровня и выше

**Р1 — СЛУХ (фундамент)**. Сборка: AudioWorklet-анализатор (FFT 1024/2048, RMS, 3 спектральных полосы, onset-энергия) как отдельный .mjs рядом с music-region.mjs. Критерий готовности: живая проба — микрофон или файл → 60 FPS обновление индикаторов, латентность ≤ 50 мс, 0 сети, детерминированный тест на фиксированном WAV-файле (один вход → одна последовательность значений). Референс: MDN (строка 13).

**Р2 — ПУЛЬС**. Сборка: свой бит-детектор (алгоритм референса MIT переписан своим механизмом или честный MIT-порт с копирайтом) + такт-часы (beat/tatum/bar). Критерий: на тестовом 4/4-треке бит ловится с ошибкой ≤ 1 кадра на 30 сек; ПУЛЬС синхронизирует КАРАОКЕ-подсветку (трек КАРАОКЕ_СИНХРОН) и дыхание Рева одним такт-часом.

**Р3 — РУКА**. Сборка: шейдерный слой поверх SVG КИСТИ: WebGPU/WGSL (или TSL через three) с WebGL2-fallback; пресет-машина своего формата (JSON в ledger), бит-морфинг, FBM-дыхание. Критерий: 1920×1080 @ 60 FPS на среднем ноутбуке; тот же пресет+тот же аудио-фрагмент+тот же seed → воспроизводимая последовательность кадров (детерминизм СВЫШЕ того, что чужие обещают); data-bbox КИСТИ не тронут (тест ГЛАЗА round-trip зелёный).

**Р4 — ВЗГЛЯД И ГОЛОС РЕВА**. Сборка: blendshapes MediaPipe (Apache-2.0) → виземы → морфы SVG-морды; таблица фонема→визема; реплики wllama озвучиваются движением рта. Критерий: произнесённая реплика имеет синхронный рот (ручная поверка + скриншоты-пробы), при выключенном микрофоне Рев живёт на репликах мозга (деградация честная, не падение).

**Р5 — ПЕНИЕ**. Сборка: Magenta.js-слот в open-model-adapter (Apache-2.0), инкрементальная мелодия по настроению мозга; синтез голоса — местные средства adapter-os (А3-приоритет Whisper стоит в доме). Критерий: офлайн-«песня» (мелодия+реплика+виземы) собирается без сети и поётся Ревом; длина/тональность детерминированы seed.

**Р6 — ПАМЯТЬ И ПУЛЬТ**. Сборка: IndexedDB (сессии, пресеты, mood), группа «ЖИВОЙ РЕВ» в ПУЛЬТЕ v10.96 (чувствительности, пресет, регистратор), альтернативныйТекст() расширяется на выступление (незрячий слышит, что Рев рисует и чувствует). Критерий: перезагрузка страницы → Рев восстанавливает состояние из IndexedDB + ledger; все пробы ЗДОРОВЬЯ зелёные; регресс трека не падает.

Порядок сборки строго снизу вверх (Р1→Р6): каждый слой проверяем отдельно, затем сверху. Чужое заменяем нашим так: чужой API-рендер → КИСТЬ (сделано v10.92); чужой extract → ГЛАЗ (сделано); чужая cloud-музыка (Suno и т.п. — отклонено по закону) → Magenta-слот локально; чужой липсинк-вес (SadTalker) → виземы на blendshapes; чужой пресет-формат MilkDrop → свой JSON-пресет в ledger.

## 5. Приоритеты и риски

**Топ-5 первых ходов**:
1. Р1-СЛУХ: AudioWorklet-анализатор + фикстура WAV + детерминированная проба (самый дешёвый, самый независимый ход; ничего не ломает).
2. Р2-ПУЛЬС: свой бит-детектор + такт-часы, склейка с ПУЛЬС-СИНХРОНОМ КАРАОКЕ_СИНХРОН (дому уже принадлежит караоке-хребет — Reve оживёт на нём первым).

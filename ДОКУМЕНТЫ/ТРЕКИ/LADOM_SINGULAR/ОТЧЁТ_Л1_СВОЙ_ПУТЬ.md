## 2. Что взяли, что построили, чем лучше

**Взято (как спека, не как услуга):** сам workflow layout-first — create/extract/render/reconcile + шесть команд + форма ответа с честными статусами. Это публичный контракт, а не их собственность: идею «структура первична» дом принял ещё в ТЗ трека.

**Построено от ноля (0 сети, 0 токена, 0 часов, 0 случайности):**

| Модуль | Канон | Что делает |
|---|---|---|
| **СВОЯ КИСТЬ** | `src/svoya-kist.mjs` (`svoya-kist/0.1`) | renderLayout: Project → **детерминированный SVG** — реальная картинка (палитра из промпта FNV-1a, слои по zIndex, замок штрихом, текст экранирован); альтернативныйТекст — словесная картина для незрячего владельца; ledger ladom.svoya-kist.v1 без timestamps |
| **СВОЙ ГЛАЗ** | `src/svoy-glaz.mjs` (`svoy-glaz/0.1`) | extractLayout: SVG кисти → Project (round-trip байт-в-байт, чужое — честный отказ); reconcileLayout: добавлен/удалён/сдвинут/изменён-размер/переименован/изменён-промпт/… + маска изменённых разблокированных id (встаёт в их repair-agent); применитьКоманду: их шесть команд — детерминированной машиной, замки не снимаются; toReveWire/fromReveWire — мост в их форму x0/y0/x1/y1 |

**Чем лучше на голову (проверяемо, не лозунг):**

1. **Детерминизм байт-в-байт** — они не обещают воспроизводимость (их аудит: UNKNOWN); у нас два вызова — один файл (тесты T02/T13/T22/T34).
2. **Цена** — у них кредиты и content_violation чужой цензуры; у нас 0.0 кредитов всегда и внешней цензуры нет — при честно названной границе: кисть рисует ПО СТРУКТУРЕ (вектор), а не выдумывает пиксели из текста.
3. **Доступность** — у них картинка без слова; у нас каждый рендер несёт словесную картину (desc + aria-label + альтернативныйТекст) — владелец видит ушами. Для незрячего владельца это не фича, а суть.
4. **Прозрачность глаза** — их extract_layout от растра — чёрный ящик; наш читает свой формат открытым парсером и честно отказывается от чужого.
5. **Замки нерушимы** — команды глазу запрещают двигать/снимать замки (закон дома), reconcile не пускает замки в маску ремонта.
6. **Независимость** — их workflow требует токен, сети и их сервер; наш работает в офлайне из коробки (страница, node — где угодно).

**Честные границы (не утверждается):** кисть — не диффузионная модель; фотонов «с нуля» она не синтезирует, она честно рисует структуру. Когда у владельца появятся СВОИ веса локальной модели — они встанут в open-model-adapter (P4.1, канон v10.89), а кисть останется детерминированным исполнителем структуры. Мост в их прод-схему — экспортный, production-совместимость не утверждается (их же правило: без pinned SDK заявлений не делать).

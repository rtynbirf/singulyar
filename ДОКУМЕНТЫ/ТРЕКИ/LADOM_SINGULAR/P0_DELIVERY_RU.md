# ЛАДОМ Layout Studio P0 — реализованный прототип

Дата: 2026-10-12  
Файл: `ladom-layout-studio-p0.html`  
Статус: автономный P0 по архитектурному чертежу. **Сеть и Reve API не вызываются.**

## Что воплощено из Blueprint

| Компонент Blueprint | Реализация в P0 |
|---|---|
| Layout IR | `schemaVersion: ladom.layout.v1`, Project + Region (id, label, prompt, bbox 0..1, zIndex, locked) |
| Constraint Solver | `validateLayout`: min size, границы кадра, нулевые/отрицательные размеры; ошибки на холсте и в панели |
| Layout Editor | drag, resize, числовые поля, список, замок, порядок слоёв, клавиатура |
| JSON import/export | Экспорт; импорт с жёсткой валидацией; **транзакционный** — невалидный JSON не затирает текущий проект |
| History | Undo/Redo (стек до 40), именованные снимки версий, восстановление снимка |
| Diff | `diffLayout(old, new)` — добавление/удаление регионов, изменения label/prompt/bbox/lock/zIndex |
| Policy | Без токена, без сети, лимит размера файла 1 МБ, без `innerHTML` для пользовательских строк (escape) |

## Условие готовности P0 (из Blueprint)

- Создать сцену — да (стартовый пример + добавление регионов)
- Добавить / удалить / переместить / изменить объект — да
- Увидеть ошибки геометрии — да (красная рамка + список)
- Сравнить версии — да (Diff + снимки)
- Экспортировать валидный JSON и восстановить — да
- Без API-ключа и сети — да
- Ни одна операция не молча уничтожает исходную версию — да (pushUndo + transactional import)

## Чего намеренно нет (P1+)

- Reve adapter / render / extract_layout
- Серверный proxy и токен
- OCR / object detection / QA
- Intent Parser / Scene Graph relations
- Masked repair / local diffusion

Это соответствует приоритету: **сначала открытая структура и контроль, потом сменный renderer**.

## Как открыть

Откройте `ladom-layout-studio-p0.html` в браузере (двойной клик или `file://`).  
Либо из комплекта `reve_sdk_delivery/ladom-composition-studio.html` — более ранний MVP без истории/diff/валидатора.

## Связь с Reve

Reve отличается от «мусора» тем, что layout — **промежуточное управляемое представление**, а не одноразовый prompt→картинка.  
Этот прототип воплощает **ту же идею на стороне клиента**: человек владеет структурой сцены до любого вызова модели. Адаптер к Reve (или к локальной модели) — отдельный сменный слой, не смешанный с IR.

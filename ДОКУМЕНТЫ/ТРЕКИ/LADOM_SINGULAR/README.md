## Такт v10.85 «АРХИТЕКТОР» — строка Л5-P4: agentic repair planner (допись · Task ID 5-a)

**P4 (остаток) закрыт машинной частью: агентный цикл поверх их канона v10.81 — планирование вынесено в proposer'ов, применение и выбор остались ихними.** (Граница v10.81 «ЛАТКА» принята честно: их `planMaskFromOverlaps` — детерминированная эвристика, не агент.) Канон — `src/repair-agent.mjs` (`repair-agent/0.1`). Применение агент не изобретает: гарантия нетронутости удержанных — их `applyMaskedRepair`/`batchRepair` (derive — их `baselineDerive`), выбор — их `pickBest`, мера пересечения — их `bboxIoU` из qa-metrics (Л3). 0 сети · 0 часов · 0 случайности — детерминизм байт-в-байт.

- **ЗАКОН ЧЕСТНОСТИ**: агента-модели в доме нет — реестр proposer'ов пуст от моделей; стоковые proposer'ы детерминированы; адаптеры (Л1 Reve, P4.1 локальная модель) встанут сюда ЧЕРЕЗ `registerProposer`, когда будут честны. `listProposers()` пишет это честной пометкой «стоковые: heuristic, lattice; моделей нет».
- **Контракт proposer'а**: `proposer(имя, project, память) → {план: ladom.repair.v1} | {маска: []} («нечего чинить») | {отказ: причина}` — чистая функция, 0 мутаций входа. Агент подстраховывает: proposer'у уходят снимок проекта и копия журнала прошлых раундов — мутация не дойдёт (тест ловит её proposer'ом-подглядывателем).
- **Стоковые proposer'ы**: `heuristic` — обёртка их `planMaskFromOverlaps` (жертва пересечения — поздний в списке, замки не чинятся никогда); `lattice` — детерминированный план из их `baselineDerive` (ступени × решётка в фиксированном порядке); маска — все разблокированные регионы, отсортированные по id (конвенции «свежих/unfixed» в их каноне v10.81 нет — регион несёт только id/label/prompt/bbox/zIndex/locked; честный fallback); нет чинимых пересечений — честная пустая маска (иначе план выродился бы в kept по всем шагам).
- **Агентный цикл** `runRepairAgent(project, {proposers, rounds, scoreFn})`: (1) опрос proposer'ов — порядок имён лексикографический, дубликаты имён съедаются; (2) их `batchRepair` применяет планы — по варианту, отказ варианта остаётся записью в памяти, не броском в никуда; (3) `scoreFn` меряет результат (меньше — лучше; дефолт `scoreRepair`); (4) их `pickBest` выбирает лучший вариант раунда (инверсия знака внутри цикла); (5) память раундов `{раунд, proposer, исход: план|пусто|отказ, счёт, причина}` — БЕЗ timestamps; (6) стоп: раунды кончились ИЛИ все proposer'ы вернули «нечего чинить»/отказ — честная остановка без единого применения (проект в результате — тот же объект-ссылка). `rounds` клампится в 1..8; вход не мутируется (байты и ссылки удержанных — тестом).
- **`scoreRepair(project, отчёт)`** (меньше — лучше): новое пересечение с удержанными (их `bboxIoU` > 0 → штраф; только шаги со сдвигом — их же грань «наследованное — не вина ремонта»), число blocked (их поле отчёта), число не-отказов (repaired+kept — мера адресности: раздутая маска дороже точной).

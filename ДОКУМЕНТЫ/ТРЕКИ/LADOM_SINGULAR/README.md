Произведение = структура (Composition IR).  
Восприятие и рендер = сменные адаптеры.  
Совместность возникает из общего IR, а не из одинакового интерфейса.

## Такт v10.81 «ЛАТКА» — строка Л5, шаг P4: masked repair (допись · PAT №18)

Л5 «P3–P4: поочерёдное» берёт свой следующий шаг: **P4 «Masked repair · batch experiments»** закрыт машинной частью — адресный ремонт региона без полной перегенерации. Agentic repair planner остаётся честно открытым: здесь детерминированный эвристический планировщик, не агент.

### P4 · masked repair — `src/masked-repair.mjs`

- План ремонта `ladom.repair.v1`: `planMaskedRepair` (маска → шаги с зафиксированными bbox) и эвристический `planMaskFromOverlaps` (маска из пересечений с незаблокированными соседями; жертва — поздний в списке, конвенция задокументирована; замки не чинятся никогда; пустая маска — валидный ответ «нечего чинить», а не ошибка).
- Применение `applyMaskedRepair`: чинится ТОЛЬКО маска — удержанные регионы остаются теми же объектами (байт-в-байт); план устарел (проект менялся после плана, чужой title, locked в маске) — честный отказ; «ремонт не нужен» — kept, мест нет — blocked (проект не меняется вовсе); отчёт `ladom.repair-report.v1` без timestamps; грань «ремонт не наехал на удержанных» меряется тем же `bboxIoU` из `qa-metrics.mjs` (связка с Л3) и бьёт только НОВОЕ перекрытие — наследованное (prompt-ремонт без сдвига) не вина ремонта.
- Офлайн-базлайн `baselineDerive` — детерминированный fallback «без Reve» и основа будущего P4.1: попытка 0 → три ступени сжатия × решётка 5×5 в фиксированном порядке обхода; гарвард `MAX_ATTEMPTS=73`; один вход → один выход, ни часов, ни случайности.
- Batch experiments: `batchRepair` (серия вариантов на одном входе, вход не мутируется, имена уникальны) + `pickBest` (детерминированный максимум; при равенстве — первый по порядку).

### Тесты такта

- `tests/test_takt_10.81.mjs` — 24 теста: гарантия нетронутости (ссылки и байты), детерминизм двух прогонов байт-в-байт, честные отказы (устаревший план, чужой title, locked, плохой derive: мало/за кадром/не число/наехал), blocked-кейс на геометрии «замок-рамка», планировщик (жертва/замки/пусто/iouMin), batch + pickBest, повторное применение плана — отказ, статика источника (0 сети, 0 часов, единственный импорт qa-metrics, константы контракта).

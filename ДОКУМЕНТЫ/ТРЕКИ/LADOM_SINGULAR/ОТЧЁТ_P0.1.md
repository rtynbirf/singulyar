# ОТЧЁТ P0.1 — LADOM_SINGULAR (такт v10.74 «СВОД», перезапуск после таймаута)

Файлы остаются автономными single-file HTML, без сети, без сборки. Обновлённые копии лежат здесь
(оригиналы в `upload/unpack/.../ladom_singular_delivery/` не тронуты, пуш в GitHub не делался).

## Сделано

1. **Маркеры валидатора.** В обоих HTML ровно по одному `// VALIDATOR-BEGIN … // VALIDATOR-END`;
   внутри — чистая `validateProject(project)` (плюс `validateImport`), прежние проверки и тексты
   сообщений сохранены, поведение файлов не изменилось.
2. **Автотесты валидатора** — `tests/test_validator.mjs`: читает ОБА живых HTML, вырезает блок
   между маркерами, исполняет в `node:vm` (без DOM), гоняет кейсы: валидный проект; bbox вне
   0..1; нулевые/отрицательные размеры; отсутствующие поля; неизвестный `schemaVersion`; неверные
   типы; лимит регионов 64/65; специфика `ladom.composition.v1` (type региона, adapters) и
   `ladom.layout.v1`; немутация входа; транзакционные отказы `validateImport`. Тест проверяет
   живые файлы, не копию логики.
3. **Keyboard/SR-аудит и правки (минимальные)** в обоих HTML:
   - видимый фокус: `:focus-visible` + `outline` + `offset` для button/input/textarea/select/region;
   - подписи: `aria-label` у иконочных/символьных кнопок (↶ ↷ ✕ ✕регион и т.п.), `type="button"`,
     `role="tablist"/"tabpanel"` с `aria-labelledby`, подпись холста с клавиатурной альтернативой;
   - `aria-live`/`role="status"` у контейнера ошибок валидации и статусов (в т.ч. `#autosaveStatus`);
   - Esc: закрывает диалог, снимает фокус с полей, отменяет drag/resize;
   - `prefers-reduced-motion: reduce` — гасит CSS-анимации (пульс-бар и пр.);
   - таб-порядок — естественный DOM-порядок, `tabindex>0` нет.
   Найденные дефекты исправлены прямо в HTML (см. «Было → стало»).
4. **IndexedDB-автосохранение** в ОБА HTML (модуль `// AUTOSAVE-BEGIN … // AUTOSAVE-END`):
   - база `ladom-singular`, store `projects`, ключ = имя файла; debounce 800 мс после валидной
     транзакции (гейт `validateProject(...).length === 0` **до** `idbPut` — невалидный импорт не
     затирает автосохранение);
   - восстановление при открытии — только валидного сохранения, панель «Проект восстановлен из
     автосохранения (дата)» с кнопками «Сброс к заводскому примеру» и закрытием ✕;
   - кнопка сброса к заводскому примеру (`factoryReset` → `factoryProject()`) в баннере и на панели;
   - транзакционность импорта/undo не тронута;
   - при недоступности IndexedDB (`file://`, приватный режим, отсутствие API) — честный статус
     «Автосохранение недоступно: … — работа как раньше, без записи» (3 ветки), без молчаливого падения.

## Проверено

`node --test tests/*.mjs` → **80/80 зелёные** (30 validator + 28 a11y + 22 autosave), 0 fail.
Самопроверка маркеров: в каждом HTML ровно 1×`VALIDATOR-BEGIN`, 1×`VALIDATOR-END`, 1×`AUTOSAVE-BEGIN`,
1×`AUTOSAVE-END`. В тестах и HTML: 0 `fetch`/`XMLHttpRequest`/`WebSocket`/`http(s)://`, 0 `innerHTML`
в модуле автосохранения и для пользовательских строк (только `textContent`).

## Было → стало (a11y-дефекты, исправленные минимально)

- иконочные кнопки без имён (`↶`, `↷`, `✕`, `Сброс`) → `aria-label` + `type="button"`;
- контейнер ошибок/статусов без `aria-live` → `role="status" aria-live="polite"`;
- табы без ролей → `role="tablist"/"tabpanel"` + `aria-labelledby`;
- холст (drag-only) без текстовой альтернативы → `role="group"` + подпись «клавиатурная
  альтернатива — числовые поля X, Y, W, H»;
- анимации не уважали reduced-motion → `@media (prefers-reduced-motion: reduce)`;
- Esc не гасил ввод в полях → `blur()`/закрытие по Esc.

## Честные границы

- Клавиатура/SR проверены **статически** (регэксп-разбор живых HTML) + осмысленный ручной проход;
  живой прогон скринридерами (NVDA/VoiceOver) и на целевых браузерах — 👤, за пределами такта.
- Автосохранение не гонялось в реальном браузере (нет DOM в тестовой среде); логика покрыта
  статическими проверками структуры и гейтов. Поведение при `file://` описано честным статусом,
  но живой прогон — 👤.
- Известный зазор (задокументирован тестом): `validateImport` студии не отклоняет **чужую строку**
  `schemaVersion` до `validateProject` — конечный гейт ловит, но текст ошибки менее точный.
- Счётчики debounce 800 мс и ключ-файл заданы константами; смена имени файла = новая запись
  автосохранения (осознанно).
- Пуш в GitHub не выполнялся (запрещено; только главный агент).

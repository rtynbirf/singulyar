# ОТЧЁТ P1.1 — Intent → region seed (такт v10.78 «ОТКЛИК», С54)

**Дата:** 2026-10-12 · **Строка карты:** Л2 (LADOM_SINGULAR, P1.1) · **Статус:** ✅ закрыт кодом, тестом и живой поверкой

## Что сделано

В студию `ladom-layout-studio-p0.html` встроен «Намерение → черновик»: из текстового описания сцены офлайн-правила собирают черновик регионов `ladom.layout.v1` — **без сети, без LLM, без токена** (LLM остаётся опциональным на будущее, как записано в ТЗ P1.1).

- **Чистый блок** `INTENT-SEED-BEGIN/END` — детерминированные правила без DOM: лексикон (фон · заголовок · текст · свет · герой · логотип · люди · декор), позиции (слева / справа / вверху / внизу / в центре), размеры (на весь экран · полоса · большой · маленький), плейсмент 3×3 без пересечений, фон — под всем (zIndex 0).
- **Честность:** нераспознанные фразы **не** мапятся молча — попадают в `unrecognized`; переполнение полотна (9 регионов) честно отмечается в `notes`; `prompt` региона хранит фразу человека без затирания (суверенитет слов); `trace` объясняет, почему регион таков (какие слова сработали).
- **UI:** textarea + «Собрать черновик» + «Добавить в проект» + вывод с отчётом. Добавление идёт через `pushUndo` → `takeSnapshot` → `renderAll` — история и undo живые; повторное добавление защищено (черновик очищается).

## Испытания

- **`tests/test_intent_seed.mjs` — 20/20 зелёные**: детерминизм, 0 сети (нет fetch/XHR/WS/eval в блоке), лексикон (8 родов), честный `unrecognized`, границы bbox в [0,1] и ≥ MIN_SIZE, плейсмент без пересечений, переполнение, **черновик целиком проходит живой `validateLayout`** студии, UI-связка (С37: обе кнопки привязаны, история честная). Блок вырезается из живого HTML и исполняется в node:vm — если блок сломается в файле, тест краснеет.
- Регресс студии не тронут: `test_validator.mjs` 30/30, `test_a11y_static.mjs` 28/28, `test_autosave_static.mjs` 22/22. Итого 100/100.
- **Живая поверка** (локальный стенд, браузер): фраза «фон — мягкий градиент, заголовок вверху, большой герой справа, полоса текста внизу, летающий чемодан» → 4 региона (фон во весь кадр z0, заголовок вверху, герой справа 0.5×0.45, полоса внизу 0.92×0.14), «летающий чемодан» — честно в непознанном; «Добавить в проект» → «Геометрия: ок · регионов: 7», снимок версии 2, undo возвращает.

- Правила лексические: они понимают слова лексикона, не «смысл». Сложные намерения (настроение, стиль, композиционные метафоры) — территория P2+ (LLM optional), не этого такта.

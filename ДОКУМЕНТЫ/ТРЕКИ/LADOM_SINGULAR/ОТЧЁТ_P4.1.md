## Что сделано

### Разделение власти (роль 9 из 09_ARCHITECTURE_BLUEPRINT_RU.md)

Repair Planner «определяет, какую область/сущность исправить». Такт проводит границу честно:

| Вопрос | Кто решает | Чем |
|---|---|---|
| **ЧТО чинить** | модель хоста | выбирает маску регионов своим ответом `{маска:[...]}` |
| **КАК чинить** | канон дома (v10.81, не правится) | их `applyMaskedRepair` + `baselineDerive` |
| **Сборка плана** | канон дома | их `planMaskedRepair` — в плане их `generatedBy: masked-repair/0.1` |
| **Применение/выбор/мера** | их агентный цикл (v10.85, не правится) | `runRepairAgent` → `batchRepair` → `scoreRepair` → `pickBest` |

Модель не двигает байты: план по её маске собирает их канон, применение — их derive. Никаких приписок авторства.

### Контракты

- **Запрос модели** `ladom.open-model-ask.v1` — детерминированная сериализация мира: регионы по id (`id/label/prompt/bbox/locked/zIndex`), пары пересечений их `bboxIoU` (округление 6 знаков — их конвенция), копия журнала раундов, правило ответа. Два прогона — байт-в-байт. Вход не мутируется (регионы и журнал копируются глубоко).
- **Ответ модели** — строго `{маска:[id...]}` или `{отказ:"причина"}`. Гард строгий: лишние поля, двусмысленность (`{маска, отказ}`), не-объект, маска не массив, id не строкой, неизвестный id, locked-регион — честный отказ с причиной. Дубликаты съедаются (их конвенция `planMaskedRepair`), порядок ответа модели сохранён.
- **Proposer** — контракт repair-agent/0.1: `(имя, снимок, журнал) → {план}|{маска:[]}|{отказ}`. Любой сбой модели — честный отказ записью: цикл агента не падает, память раундов несёт причину.
- **Реестр** — `registerOpenModel({имя, модель, правило})` вкомкивает адаптер через их `registerProposer`; дубликат имени/плохой вход — честный false, их реестр не перезаписывается. `списокАдаптеров()` — живая правда о моделях процесса.

### Честные границы

- **Весов в модуле нет.** Хост приносит модель сам: wllama/WebLLM или любая локальная — в виде синхронной детерминированной функции `модель(запрос) → {маска}|{отказ}`. Асинхронный инференс ведётся ВНЕ цикла агента (реестр синхронный — их контракт), готовый ответ вкомкивается обёрткой. Пример хоста:
  ```js
  import { registerOpenModel } from './open-model-adapter.mjs';
  // модель уже загружена хостом и синхронизирована (или инференс готов заранее)
  registerOpenModel({ имя: 'open-model:qwen-0.5b', модель: (запрос) => маскаИзИнференса(запрос), правило: 'локальная Qwen2.5-0.5B' });
  runRepairAgent(проект, { proposers: ['heuristic', 'lattice', 'open-model:qwen-0.5b'] });
  ```
- **Детерминизм модели — ответственность хоста** (как у их `scoreFn` в `pickBest` — честно сказано в шапке модуля): температура 0, без часов, без случайности.
- **В продукте (Pages) реестр пуст от моделей** — их статическая пометка `listProposers().пометка` («моделей нет») остаётся верной; их канон и их тесты не тронуты байт-в-байт (их тест №125 защищает пометку — правка не проводилась). Живую правду о вкомканных адаптерах даёт `списокАдаптеров()`.
- **Модель может врасть маской** — дом защищён в глубину: гард адаптера → их `planMaskedRepair` (unknown/locked — отказ) → их `applyMaskedRepair` (устаревший план — отказ; наезд на удержанных — отказ) → их агентная мера. Модель не может тронуть ни удержанные, ни замки, ни журнал.

### Наблюдение семантики их цикла (не баг, зафиксировано)

Финальный `статус` `runRepairAgent` говорит о **последнем** раунде: ремонт происходит в раунде 1 (факт — в `итог.лучший`), раунд 2 честно находит «нечего чинить» и останавливает цикл со статусом «нечего-чинить». Потребителю результата надо читать `лучший`, а не только `статус`. Проверено тестом «E2E runRepairAgent» и зафиксировано здесь и в README трека.

# 12 · ДОРОЖНАЯ КАРТА

Оценки ориентировочные (команда 6–8 человек); корректируются после Фазы 0. Правило: **каждая фаза оставляет safety-путь рабочим**.

| Фаза | Срок | Содержание | Выход |
|---|---|---|---|
| **0. Основание** | 4–6 нед. | ADR (SoC, рантайм, голос), стенд, CI с ядром; юр. консультация; DPIA-черновик; решения по LIC-функциям | ADR, зелёный CI, список функций v1.0 |
| **1. Агент-MVP** | 3–4 мес. | шины событий, MCP-хост (2026-07-28), манифест, policy, журнал, голосовой конвейер, быстрый путь + SLM, локальные таймеры/напоминания, e2e на моках | офлайн-демо «голос → действие → журнал» |
| **2. Дом** | 3 мес. | Matter-контроллер, OTBR/Thread 1.4, реестр, сцены, датчики, конфликты автоматизаций | управление 10 реальными устройствами |
| **3. Безопасность и приватность** | 2–3 мес. (параллельно 1–2) | secure boot, SE, vault, согласия, hash-chain-якорь, песочница навыков, атаки в CI | pentest, отчёт |
| **4. Железо P/D** | 6–9 мес. (параллельно) | акустика/DSP, массив, safety MCU, аппаратные ключи, корпус, радио-сертификация | инженерные образцы |
| **5. Perception+** | 2–3 мес. | mmWave presence, акустические события, камера D с шторкой, локальный RAG | события, виджеты |
| **6. Забота** | 3 мес. | SOS, неподвижность, падение с подтверждением, напоминания, vault здоровья; юр. ревизия | пилот-готовность |
| **7. Энергия и масштаб** | 3 мес. | тарифы/углерод Matter 1.5, сдвиг нагрузки, мульти-агентные роли, опциональное облако с согласием | v1.0-RC |
| **8. Пилот и сертификация** | 3–4 мес. | 5–10 домов, CRA/RED, Matter, доступность, SBOM/CVD | релиз v1.0 |

## Бэклог (из каталога)

- **v1.0:** все tier M (176): см. `catalog.csv` (фильтр `tier=M`).
- **v1.x:** tier S (223): мультирум/AirPlay/Cast (после лицензий), Zigbee-мост, HEMS, поиск по фото, Wi-Fi 7, голосовые профили, интерком.
- **Исследования (C, 110):** Wi-Fi sensing, UWB, жесты/взгляд, генеративная музыка, перевод, федеративное обучение/DP, коммерческие агенты.
- **Вне объёма (X, 6):** инференс эмоций, остановка дыхания, хрипы, дезориентация, деменция-диагностика, автовызов служб без провайдера.

## Риски проекта

| Риск | Митигация |
|---|---|
| Feature bloat | tier-дисциплина; v1.0 = M |
| Регуляторные изменения (омнибусы, статусы актов) | квартальная сверка; док. 13 |
| Лицензии (Atmos, AirPlay, Cast, …) | коммерческое решение в Фазе 0 |
| Малые модели ошибаются в tool calling | быстрый путь, структурный вывод, verifier, eval |
| Ложные тревоги падения | подтверждение, пилот, настройка порогов |
| Зависимость от вендора NPU | абстракция рантайма; два кандидата SoC |
| Устаревание стандартов (Matter/MCP) | трекер версий, адаптеры, тесты совместимости |

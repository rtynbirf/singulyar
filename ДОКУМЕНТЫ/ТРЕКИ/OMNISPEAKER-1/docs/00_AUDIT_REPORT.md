# 00 · АУДИТ И РЕВИЗИЯ

Дата: 2026-10-12. Объект: четыре исходных документа (планирование и tool calling; 515-пунктный прототип «универсальной колонки»; архитектура локального ИИ-агента; сетевая архитектура) и два ранее выданных пакета (`omnispeaker-1.zip` v0.1 и `prototype-only.zip`).

## 1. Метод: роли-«агенты» ревизии

Ревизия выполнена как последовательный проход ролей. Каждая роль проверяла свой срез, фиксировала находки с идентификатором `F-xxx`, серьёзностью (S1 — блокирует безопасность/законность, S2 — ломает работоспособность/целостность, S3 — улучшение) и исправлением. Исправления внесены в документы 02–12, каталог 04 и референс-код.

| Роль | Срез проверки |
|---|---|
| Системный архитектор | границы слоёв, согласованность схем между документами, профили железа |
| Безопасность / red team | модель угроз, prompt injection, supply chain, эскалация привилегий, журнал |
| Протоколы и сети | Matter/Thread/Zigbee/MQTT/MCP, порты, VLAN, мультикаст |
| ML / edge-инженер | реальность моделей на NPU, задержки, оценка качества |
| Аудио / DSP | микрофонный массив, AEC, калибровка, лицензируемые форматы |
| Регуляторика и право | ЕС (CRA, AI Act, GDPR, Data Act, RED, EAA), медицинские границы, ответственность |
| Приватность | минимизация, согласие, биометрия, дети, хранение |
| Медицина/уход | граница wellness ↔ медицинское изделие |
| Энергетика | Matter energy, тарифы, standby |
| UX / доступность | EN 301 549, режимы, подтверждения |
| SRE / эксплуатация | обновления, откат, наблюдаемость, деградация |
| Продукт | объём MVP, дубли, «feature bloat» |

### 3.2. Безопасность агента

| ID | S | Находка | Исправление |
|---|---|---|---|
| F-010 | S1 | **Нет защиты от indirect prompt injection**: тексты из веба, RAG, писем, календаря и **звук с ТВ** попадают в контекст планировщика. «tool request ≠ authorization» недостаточно: хост авторизует по `risk`, но `risk` берётся из каталога/модели. OWASP ставит инъекцию на 1-е место и для LLM, и для агентных приложений; полностью её не устраняют, ею управляют. | Введена **provenance** каждого вызова (10 классов). ## 6. Что аудит НЕ закрывает

- Нет юридического заключения: регуляторные пункты — ориентиры для юриста; даты и статусы, помеченные «по вторичным источникам», требуется сверить с первоисточниками.
- Нет измерений на железе: цифры по задержкам/мощности/WER — целевые, не измеренные.
- Нет сертификации; нет клинической валидации.
- Версии Matter/MCP актуальны на 2026-10-12 и быстро устаревают — см. док. 13.

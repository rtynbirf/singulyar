# 09 · ЖЕЛЕЗО: ПРОФИЛИ И ОРИЕНТИРЫ

Цифры — **проектные ориентиры**, не измерения. Конкретные чипы/поставщики выбираются в Фазе 0 (см. док. 12).

## 1. Блок-схема (все SKU)

```text
 Микрофоны (PDM/TDM) ─► Аудио-DSP ─┐
 Динамик ◄─ усилитель D ◄─ DSP ◄──┤
 Сенсоры (T/RH/lux/IMU/PIR/mmWave)─► SoC (CPU + NPU + RAM) ◄─► NVMe/eMMC
 Радио: Wi-Fi 6/6E · BLE · Thread(802.15.4) · [NFC] · [UWB]  ─┘      │
 Secure Element/TPM ◄───────────────────────────────────────────────┤
 SAFETY MCU (независимые часы, watchdog, сирена, кнопка SOS, UART к SoC)
 Аппаратные ключи: MIC · CAM · RADIO  (разрывают питание/данные физически)
 Питание: PD USB-C / DC; [конденсатор «last gasp» или АКБ] 
```

| Параметр | P — Puck | D — Display | H — Hub |

| SoC | 4×A-класс + NPU 4–8 TOPS | 4–8 ядер + NPU 8–16 TOPS | 8 ядер + NPU/GPU 30+ TOPS |
| RAM | 4–8 ГБ | 8–12 ГБ | 16–32 ГБ |
| Хранилище | 64–128 ГБ eMMC | 128–256 ГБ | NVMe 512 ГБ–2 ТБ |

## 3. Тепловой и энергетический бюджет (цели)

| Режим | P | D | H |
|---|---|---|---|
| Networked standby (радио вкл, wake word, mmWave) | ≤ 2 Вт | ≤ 3 Вт (экран выкл) | ≤ 8 Вт |
| Диалог (ASR+SLM) | 6–10 Вт | 8–12 Вт | 15–35 Вт |
| Пик (звук) | 15–25 Вт | 25–40 Вт | 40–65 Вт |

Правила: NPU-бюджет через DVFS; троттлинг моделей, но не safety-пути; профиль «ночь» ограничивает SPL и яркость.

## 4. Аудио

- Драйверы и акустика — предмет отдельной разработки; 3–5 (твитеры/мидрейнж/пассив) — детали конструкции в рамках 1.
- DSP: EQ, DRC, лимитер с тепловой моделью катушки, кроссовер, AEC, beamforming, шумоподавление.
- Калибровка помещения (S): тест-свип + оценка импульса помещения.
- Метрики: AFR 60 Гц–18 кГц (±3 дБ) цель; THD < 1% на номинале; SPL (P) ≥ 80 дБ @1 м.
- Лицензируемые форматы — только H.

## 6. Аппаратные выключатели и индикаторы

- MIC: физический разрыв питания и данных микрофонов; LED красный; состояние читается MCU/SoC, но **не может быть программно изменено**.
- CAM: механическая шторка + разрыв питания; LED.
- RADIO: опционально — отключает Wi-Fi/Thread (BLE-сервисный канал остаётся для SOS по настройке).
- LED «передача данных»: включается egress-proxy при внешних соединениях.

## 7. Безопасность железа

Secure Boot (ROM → loader → ядро), измеримая загрузка; отключённые в production JTAG/UART/USB-данные; антивскрытие (тампер-датчик → стирание ключей по политике); раздельные домены питания Safety MCU; генератор случайных чисел; защищённое хранение ключей в SE.

## 8. Мини-спецификация образцов для Фазы 1 (разработческий стенд)

Одноплатник с NPU (класс Rockchip RK3576/RK3588 или эквивалент), USB-микрофонный массив (4–6), динамик с усилителем, радиомодуль Thread RCP (nRF/EFR32-класс) для OTBR, Matter-устройства (лампа, розетка, замок-эмулятор), датчик mmWave на UART. Это стенд для разработки ПО, не прототип корпуса.

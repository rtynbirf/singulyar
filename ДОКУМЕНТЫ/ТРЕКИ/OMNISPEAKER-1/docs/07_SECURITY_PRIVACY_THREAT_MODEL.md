# 07 · БЕЗОПАСНОСТЬ, ПРИВАТНОСТЬ, МОДЕЛЬ УГРОЗ

## 1. Активы и границы доверия

Активы: (A1) физическая безопасность жителей; (A2) доступ в дом (замки/сигнализация); (A3) приватные разговоры/видео; (A4) данные здоровья; (A5) ключи и журнал; (A6) конфигурация и политики; (A7) целостность прошивки.
Границы доверия: пользователь ↔ устройство ↔ локальная сеть ↔ интернет; агент ↔ MCP-серверы/навыки; SoC ↔ safety MCU ↔ Secure Element.

## 3. Агентные принципы (OWASP Agentic Top 10, 2026 — соответствие)

Цели хакинга цели (goal hijacking) → provenance и подтверждение; злоупотребление инструментами → манифест + verifier + идемпотентность; цепочка поставок агента → подписи/SBOM; неконтролируемые побочные эффекты → сага; идентичность агента → отдельный принципал `system` со scope; каскадные отказы → лимиты и loop-detector; недоверенные агенты → единый policy-периметр. (Классификация OWASP меняется — сверять при релизе.)

## 4. Криптография и ключи

- Secure Element/TPM: корневой ключ устройства, ключ тома, ключ подписи журнала, ключ подтверждений.
- Тома: FDE AES-256-XTS; данные пользователя — AEAD (AES-GCM/ChaCha20-Poly1305); health — отдельный ключ.
- Каналы: TLS 1.3; mTLS внутри; DTLS-SRTP для WebRTC.
- Стирание: уничтожение ключа тома + перезапись метаданных.
- Журнал: SHA-256 hash-chain; голова периодически подписывается ключом SE; экспорт по запросу.

## 6. Процессы

- **SBOM** (CycloneDX/SPDX) на каждый релиз; хэши моделей.
- **CVD**: публичная политика, security.txt, срок реакции; **отчётность по CRA** об активно эксплуатируемых уязвимостях (24 ч раннее предупреждение, 72 ч уведомление) с 11.09.2026.
- **Поддержка** патчами ≥ 5 лет (ориентир CRA; уточнять по периоду поддержки продукта).
- **Pentest**: перед релизом и после крупных изменений; red-team агента (инъекции, цепочки инструментов).
- **Журнал изменений политики** — подписан; релиз-ревью правил.

# 08 · РЕГУЛЯТОРИКА И СООТВЕТСТВИЕ (ориентир, не юридическое заключение)

Рынок и юрисдикция продукта определяют обязательства. Основной разбор — **ЕС** (самый плотный режим для подобных устройств); для США/других — перечень ниже. Статусы и даты — на 2026-10-12 по открытым источникам (часть — вторичные); перед решениями сверять с первоисточниками и юристом.

## 1. Календарь ЕС (ключевое)

| Акт | Что важно для продукта | Дата / статус |
|---|---|---|
| **Cyber Resilience Act (CRA)** | кибербезопасность изделий с цифровыми элементами; отчётность об активно эксплуатируемых уязвимостях и серьёзных инцидентах; CE-маркировка | уведомление нотифицированных органов — с 11.06.2026; **отчётность — с 11.09.2026** (24 ч / 72 ч через платформу ENISA); основные требования и оценка соответствия — **11.12.2027**; практическое руководство Комиссии — 27.07.2026 |
| **RED (Radio Equipment Directive)** + делегированный акт по кибербезопасности радиооборудования | защита сети, приватность, защита от мошенничества для радиоустройств | действует с 01.08.2025; гармонизированные стандарты (ETSI EN 18031-серия) |
| **AI Act (Reg. 2024/1689)** | запреты (в т.ч. инференс эмоций на работе/в учёбе), прозрачность, высокорисковые системы; грамотность | запреты и общие положения действуют; сроки высокорисковых обязательств смещены «цифровым омнибусом по ИИ» (в силе с 27.07.2026): Annex III — 02.12.2027, Annex I — 02.08.2028 (по вторичным источникам; **сверить с OJ**) |
| **GDPR** | обработка голоса/видео/биометрии; дети; DPIA; права субъекта | действует |
| **Data Act** | доступ пользователя к данным подключённого изделия «по умолчанию»; переносимость | требования к проектированию — **с 12.09.2026** |
| **European Accessibility Act / EN 301 549** | доступность изделий и услуг | применяется с 28.06.2025 (объём зависит от категории изделия; для колонки — ориентироваться на EN 301 549/WCAG 2.2 AA как критерий качества) |
| **Ecodesign (Reg. 2023/826 — standby/networked standby), ESPR, регламент по батареям** | энергопотребление в ожидании, ремонтопригодность, АКБ | сверить применимость к категории |
| **LVD/EMC, RoHS, WEEE** | электробезопасность, ЭМС, вещества, утилизация | CE-процесс |
| **MDR (2017/745)** | если заявляется медицинское назначение | см. §3 |
| **NIS2** | относится к операторам, не к бытовому устройству; влияет на облачного оператора | по ситуации |

## 2. Что вытекает в требования продукта

- CRA: SBOM, политика CVD, процесс отчётности, обновления ≥ 5 лет (по ожидаемому сроку использования), «secure by default» (нет паролей по умолчанию, закрытые порты, отключённые UPnP/SSH), журнал безопасности.
- RED-кибер: аутентификация, защита данных, ограничение отказа в обслуживании; Matter Product Security 1.1 покрывает требования гармонизированных стандартов RED для сертификации (по заявлению CSA).
- GDPR: правовое основание (согласие для биометрии/здоровья), DPIA, минимизация, права субъекта, данные детей (возрастные пороги по странам), роль изготовителя (оператор облака — контролёр/процессор).
- Data Act: пользователь получает доступ к данным устройства/журналу в читаемом формате и может передать третьей стороне; дизайн API и экспорта (каталог 230, 405).
- AI Act: приоритет — не вводить запрещённые практики; прозрачность для голосовых/генеративных ответов; документация для возможных высоких рисков при расширении (лица, эмоции, health).

## 3. Граница wellness ↔ медицинское изделие

| Допустимо (wellness / бытовой сервис) | Требует регуляторного трека (MDR/FDA) |
|---|---|
| напоминание о лекарствах по расписанию пользователя | рекомендации по дозировке, интерпретация взаимодействий |
| SOS, уведомление контактов | автоматический вызов скорой без пользовательской настройки юрисдикции |
| «нет движения N минут» | «остановка дыхания», «апноэ», «аритмия» |
| индекс сна/активности как тренд | диагностика расстройств сна |
| падение → подтверждение → уведомление контактов | заявления об эффективности предотвращения смерти/травм |
| счётчик событий кашля | вывод о заболевании по кашлю/хрипам |

Правило копирайтинга: **ни в UI, ни в маркетинге** нет слов «диагностика», «лечит», «обнаруживает апноэ/инфаркт», «защищает от пожара/газа».
Автоматический вызов экстренных служб допускается только через сертифицированного провайдера PERS и явную настройку; без него — уведомление контактов.

## 4. Извещатели и безопасность жилья

Дым/CO/газ — сертифицированные устройства (EN 14604, EN 50291-класс) подключаются по Matter; колонка слушает сирену и ретранслирует. Привод ворот/гаража — требования безопасности привода (EN 12453-класс) остаются на стороне привода.

## 5. Радио и электробезопасность

| Тема | Что сделать |
|---|---|
| Радио (Wi-Fi, BT, Thread, UWB, mmWave, NFC, LoRa/HaLow) | региональные сертификации (RED/FCC/ISED/…); 60 ГГц/24 ГГц радар — отдельные разрешения/частоты по регионам |
| Акустика | ограничение SPL (детский режим), защита слуха |
| Батарея (если есть) | UN 38.3, IEC 62133-класс, BMS-защиты |
| ЭМС/безопасность | LVD/EMC, IEC/EN 62368-1 |
| Matter | сертификация CSA; **Product Security** (программа 1.1) — по желанию, снижает риск несоответствия RED/CRA |

## 6. Лицензии и коммерческие договоры (до разработки соответствующих функций)

AirPlay 2 / Cast / Spotify Connect / Tidal / Roon; Dolby Atmos / DTS:X / Sony 360RA; DRM (Widevine и др.); тексты песен; данные (карты, новости, котировки); wake word чужих брендов; лицензии голосов и моделей (в т.ч. открытых — проверять условия); сторонние пакеты (SBOM → лицензионный анализ).

## 7. США и другие юрисдикции (кратко)

США: FCC Part 15, COPPA (дети), штатные законы о биометрии (напр., Иллинойс BIPA), FTC «Health Breach», E911/Kari's Law при телефонии; Калифорния — приватность и «прозрачность ИИ»; кибер-метка US Cyber Trust Mark (добровольная). Другие — по местным законам о персональных данных и связи.

## 8. Чек-лист соответствия (до релиза)

- [ ] DPIA подписана (голос, радар, камера, дети)
- [ ] Каталог 123/383/410/359/409 не реализован в обозначенных формах
- [ ] CRA: SBOM, CVD, процесс отчётности, срок поддержки в документации
- [ ] RED: сертификация радио; Matter (+Product Security 1.1 опционально)
- [ ] Accessibility: отчёт по EN 301 549/WCAG 2.2 AA
- [ ] Data Act: экспорт/доступ к данным
- [ ] Ecodesign: измерения networked standby
- [ ] Лицензии/договоры на включённые функции LIC
- [ ] Юридическая ревизия копирайтинга и дисклеймеров

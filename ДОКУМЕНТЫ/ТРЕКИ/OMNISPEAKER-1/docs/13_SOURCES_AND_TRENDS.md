## Тренды, учтённые в ревизии

1. Matter — центр экосистемы (камеры, энергия, NFC); колонка как Matter-контроллер + Thread BR.
2. MCP стал stateless и стандартизировал авторизацию; агенты на краю подключаются к инструментам через MCP.
3. Локальный голосовой стек (wake → ASR → intent → SLM → TTS) реализуем на NPU уровня SBC; быстрый детерминированный путь важен для надёжности.
4. Безопасность агентов — отдельная дисциплина: provenance, песочницы, identity агента, supply chain.
5. Регуляторика ЕС: CRA/Data Act/RED/AI Act определяют проектные решения уже сейчас.
6. Приватность как продуктовая функция: аппаратные ключи, локальность, журнал доступа.

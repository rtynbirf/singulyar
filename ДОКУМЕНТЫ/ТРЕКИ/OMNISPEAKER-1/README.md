# OMNISPEAKER-1 · ЕДИНЫЙ АРХИВ v1.0

Универсальная амбиентная ИИ-колонка + локальный ИИ-агент. Аудит и ревизия четырёх исходных документов и предыдущих пакетов, сверка с актуальными стандартами на 2026-10-12, полное ТЗ, каталог из 515 пунктов **без сокращений**, референс-код, рабочий прототип и пошаговая инструкция по реализации.

> Проектная спецификация. Не утверждается, что продукт существует. Не медицинское изделие. Регуляторные разделы — ориентиры, не юридическое заключение.

## С чего начать (5 минут)

1. Откройте `prototype/index.html` двойным щелчком (сервер и интернет не нужны) — «Пульт доверия»: цель → план по волнам → проверка → политика → исполнение → откат → журнал с цепочкой хэшей; «Лаборатория атак».
2. Прочитайте `docs/00_AUDIT_REPORT.md` — что найдено и исправлено.
3. Выполните `cd reference/agent_core && python3 -m pip install pytest && python3 -m pytest -q` — 38 тестов ядра.
4. Для реализации идите по `docs/10_IMPLEMENTATION_GUIDE.md`.

## Ключевые решения ревизии (кратко)

- LLM предлагает — **хост решает**. Риск и права берутся из подписанного манифеста хоста, не от модели и не от MCP-сервера.
- **Provenance** каждой инструкции; ТВ/веб/документы/память не запускают действия (P-002).
- Голосовой ID — не второй фактор; critical (unlock, disarm) — два фактора; стоп (P0) важнее всего.
- Health и биометрия никогда не уходят в облако; аппаратные выключатели mic/cam не отменяются прошивкой.
- Журнал — hash-chain; повторы только идемпотентных; откат (сага).
- Каталог 515: M 176 · S 223 · C 110 · X 6; удалены медицинские псевдо-функции (остановка дыхания, хрипы, дезориентация), инференс эмоций, ретранслятор Wi-Fi, GNSS.
- Matter ≥ 1.5 (отслеживать 1.6), MCP 2026-07-28, VLAN с единым L2 для Matter, CRA/Data Act/RED в требованиях.

## Что проверено, а что нет

Проверено автоматически: 38 тестов ядра; прототип — браузерный прогон 8 сценариев и 8 атак без ошибок консоли; SHA-256 прототипа сверен с эталоном; каталог содержит ровно 515 пунктов.
Не проверено: железо, задержки/мощность/WER (цели), сертификации, юридическая корректность (нужен юрист), стендовые конфиги не запускались (версии образов закрепить).

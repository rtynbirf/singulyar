## 2 · ДОПОЛНЕНИЯ К КАРТЕ_ПАКЕТА (детали, которых там нет)

### 2.1 PKE: полный реестр 20 ролей — назван поимённо

В `pke-ladom.js` реестр `ROLES` насчитывает ровно 20 ролей; маршрутизацию 100 практик ведут **10 тематических**, остальные **10 — резерв** (ждут Ж4/КС3–КС4):

**Маршрутизируют (по 10 практик на роль):**
1. **Goal Architect** — практики 1–10 (цели/контракты/PDCA/кайдзен)
2. **Conversation Partner** — 11–20 (коммуникативные задачи/ролевые игры/перифраз)
3. **Listening Coach** — 21–30 (слушание/shadowing/диктант)
4. **Speaking Coach** — 31–40 (речь вслух/языковой обмен/монолог 90 сек)
5. **Phonetics Coach** — 41–50 (IPA/минимальные пары/ударение и ритм)
6. **Vocabulary Miner** — 51–60 (SRS/карточки/коллокации/корпус)
7. **Grammar Coach** — 61–70 (правило из строки/дневник ошибок)
8. **Reading Coach** — 71–80 (чтение экстенсивное/интенсивное/пересказ)
9. **Writing Coach** — 81–90 (дневник/черновик-исправление/изложение)
10. **Progress Auditor** — 91–100 (среда/SRS-приложения/ежемесячный контроль)

**Резерв (зарегистрированы, практик не маршрутизируют):**
11. Level Diagnostician · 12. Song Curator · 13. Lyrics Intelligence · 14. Prosody Coach · 15. Memory Scheduler · 16. Error Forensics · 17. Pronunciation Scorer · 18. Rhythm & Timing Coach · 19. Confidence Coach · 20. Cultural Context Agent

Механика: инструкция — **общая на роль** (один текст на 10 практик, не 100 алгоритмов); все практики `status:"guided"`; ключ хранилища `ladom.pke.v1`, схема `pke/1` (`{profile:{language,goal}, notes:{}, cards:[], events:[]}`); чтение с проверкой схемы (не она — честный `storageOK=false`).

### 2.3 Интегрированный HTML: рассинхрон `__BUILD_SHA` (археологическая метка)

Строка 1157: `window.__BUILD_SHA = "89017cab14a98f1d"; /* v10.69 ГОЛОС */` — при титуле/`window.APP` = **v10.71 «СВЕДЕНИЕ» (С47, PAT №9)**, кэш `s15-orkestrator-v126`. То есть база патча не просто «старая» — внутри неё остался и более старый маркер сборки v10.69. Для истории: сборка многослойная. Правило археологии: базу сверять по титулу/APP, не по `__BUILD_SHA`. ### 2.4 Два сервера — два НЕсовместимых протокола (решение для сведения КС5/КС6)

| | Прототип v0.1 (`src/server.js`) | Мост v0.2.0 (`server/server.js`) |
|---|---|---|
| Порт (дефолт) | 8080 (env `PORT`) | 8787 (`HOST`/`PORT` env; хост 127.0.0.1) |
| Вход в комнату | `join{room, from, name, create, sourceLang, targetLang}` (код `[A-Z0-9]{4,12}`) | `create-room`/`join-room{room, name, sourceLanguage, targetLanguage}` (код `[A-Z0-9_-]{4,12}`; занятая непустая → ошибка) |
| WebRTC-обмен | релей `offer`/`answer`/`candidate` всем | **адресный** `signal{to, description|candidate}` (`description.type` ∈ offer/answer/pranswer/rollback, иначе `error`) |
| Текст | `text` ≤4000 симв. (name ≤40) | `text` ≤2000 симв. (`sourceLanguage/targetLanguage` ≤35, дефолт `und`) |
| Роль офферщика | клиент решает: `joined{shouldOffer:!other}` | **сервер назначает polite**: новому `polite:false`, второму `polite:true` |
| Выход | `leave` + close/error → `peer-left`, пустая комната удаляется | `leave-room` → ответ `left` + `peer-left`; SIGINT — мягкий |
| Лимиты | maxPayload 16 КБ; комнаты `Map<code, Set<ws>>`, максимум 2 | maxPayload 16 КБ; `rooms: Map<room, Map<clientId,…>>`, максимум 2 (`room-full`); binary → ошибка |
| HTTP | статика (path-traversal защита, `no-store`, `nosniff`) | health-строка «WebSocket endpoint is /signal» |

**Вывод:** это два разных контракта — соединить «как есть» нельзя. За образец сведения брать **v0.2** (create-room/join-room, адресный signal, серверная polite-роль, языковые поля с дефолтом `und`); прототип v0.1 — референс UI-потока. Единый контракт — на этап 2 (контракты ·22 по их roadmap).

### 2.5 Прототип v0.1: факты интерфейса (для стенда КС6)

STUN-only `stun:stun.l.google.com:19302` (TURN не настроен, коммент «production: add managed TURN»); зачатки perfect negotiation (`makingOffer`/`ignoreOffer`, инициатор делает оффер); `clientId = crypto.randomUUID()`; код комнаты — 6 символов base36; RTC-ограничения `{echoCancellation, noiseSuppression, autoGainControl: true, video:false}`; TTS — `speechSynthesis` с выбором голоса по языку; **localStorage не используется вовсе** (состояние только в памяти); демо-словарь — 12 пар (pt-BR↔ja-JP по 4 фразы, pt-BR→en-US и ja-JP→en-US по 2); неизвестная фраза → честное «ДЕМО: … подключите настоящий переводческий адаптер»; aria-live polite на `#lyricsView` и `#feed`; узкое место экрана 720px.

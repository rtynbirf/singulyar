================================================================================
ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)
ЭМЕРДЖЕНТНАЯ СИСТЕМА СИНХРОНИЗАЦИИ КАРАОКЕ-ТЕКСТА
================================================================================

1. ОБЩИЕ ПОЛОЖЕНИЯ
================================================================================

1.1. Наименование системы
KARAOKE-SYNC-SINGULARITY-2026

1.2. Назначение
Обеспечить максимально точную, удобную и гибкую синхронизацию визуальных
меток текста (буква, слог, слово, строка) с временной позицией оригинального
вокала в аудиодорожке для использования в караоке-системах любого типа.

1.3. Область применения
- Домашнее караоке
- Профессиональные караоке-бары и студии
- Создание контента (YouTube, TikTok, Instagram)
- Обучение вокалу
- Локальные офлайн-системы
- Мобильные и десктопные устройства

1.4. Принцип эмерджентности
Система не является простой суммой существующих инструментов.
Она синтезирует лучшие практики 2025–2026 годов в единый coherent workflow,
где AI-автоматизация и ручная точность существуют в симбиозе.

2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
================================================================================

2.1. Обязательные функции (Must Have)

2.1.1. Автоматическая синхронизация
- Разделение вокала и инструментала (source separation)
- Генерация word-level и syllable-level timestamps
- Поддержка множественных AI-моделей (Audioshake, WhisperX, MusicAI, Demucs+WhisperX)
- Возможность выбора модели под жанр и язык

2.1.2. Ручная подстройка
- Визуальный timeline с waveform
- Перетаскивание отдельных слов (drag & drop)
- Изменение длительности слова (resize handles)
- Точный ввод времени (миллисекунды)
- Глобальный offset (сдвиг всей песни)
- Секционный сдвиг (только куплет / только припев)
- Split / Merge строк и слов
- Preview в реальном времени + loop + замедление

2.1.3. Поддержка уровней детализации
- Line-level
- Word-level
- Syllable-level
- Character-level (опционально)

2.1.4. Импорт / Экспорт
- Вход: MP3, WAV, FLAC, M4A, YouTube URL, существующие LRC / Enhanced LRC / SRT / ASS / KFN
- Выход: Enhanced LRC, Standard LRC, SRT, WebVTT, ASS, JSON (word-level), CD+G (где применимо)

2.1.5. Кроссплатформенность
- Мобильный (iOS / Android)
- Десктоп (Windows / macOS / Linux)
- Браузер (Web)
- Полностью локальный режим (offline)

2.2. Желательные функции (Should Have)

- Автоматическое определение BPM и сетки долей
- Визуализация фонетической разметки
- Поддержка дуэтов (разные цвета для разных вокалистов)
- Batch-обработка нескольких песен
- История изменений (Undo/Redo 50+ уровней)
- Горячие клавиши для профессионального workflow
- Экспорт готового караоке-видео с анимацией текста

2.3. Опциональные функции (Could Have)

- Real-time pitch detection живого голоса (для оценки)
- Интеграция с аппаратными караоке-машинами (Ikarao, Singing Machine и др.)
- Облачная синхронизация проектов
- Совместное редактирование

3. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
================================================================================

3.1. Точность
- Целевая точность word-level: ≤ 50–80 мс
- Возможность ручной доводки до 10–20 мс

3.2. Производительность
- AI-синхронизация 3–4 минутной песни: ≤ 90–120 секунд
- Отзывчивость интерфейса редактирования: ≤ 16 мс

3.3. Удобство использования
- Новичок должен получить приемлемый результат за ≤ 10 минут
- Профессионал должен иметь полный контроль без ограничений

3.4. Приватность
- Полностью локальный режим обязателен
- Возможность работы без отправки аудио в облако

4. ОГРАНИЧЕНИЯ И ДОПУЩЕНИЯ
================================================================================

- Качество исходного аудио критически влияет на качество AI-синхронизации
- Для максимальной точности рекомендуется предоставлять точный текст песни
- Некоторые жанры (экстремальный метал, очень быстрый рэп, сильный акцент) требуют больше ручной работы

5. КРИТЕРИИ ПРИЁМКИ
================================================================================

Система считается соответствующей ТЗ, если:
1. Пользователь может загрузить любую песню и получить word-level разметку.
2. Пользователь может вручную исправить любое слово с точностью до 50 мс.
3. Результат экспортируется в Enhanced LRC и корректно воспроизводится в стандартных караоке-плеерах.
4. Все сценарии (mobile / desktop / local / max precision) покрыты без взаимного исключения.

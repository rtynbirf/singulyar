3. Для караоке-бара / студии
   - Локальный сервер с ELYSY + библиотека Enhanced LRC
   - Резервное копирование
   - Стандартизация форматов

4. Для максимальной приватности
   - Только ELYSY + локальные модели
   - Никакого облака

МОБИЛЬНЫЙ + ДЕСКТОП + ЛОКАЛЬНЫЙ + МАКСИМАЛЬНАЯ ТОЧНОСТЬ

СЦЕНАРИЙ A. МОБИЛЬНЫЙ (iOS / Android)
--------------------------------------------------------------------------------
Основной инструмент: Karaoke Sync

Шаги:
1. Установить Karaoke Sync.
2. Импортировать песню (файл / YouTube).
3. Вставить точный текст (по одной строке).
4. Перейти в Timing → Start Timing → тапать в начале каждой строки.
5. Переключиться в режим Words.
6. Перетащить только те слова, которые не попали.
7. Использовать Fine-tune (±0.1 сек), Loop, 0.5x скорость.
8. Экспортировать Enhanced LRC.
9. При необходимости перенести файл на десктоп для финальной доводки.

Преимущества: можно делать везде.
Ограничения: менее удобный waveform, чем на большом экране.

СЦЕНАРИЙ B. ДЕСКТОП (Windows / macOS / Linux) — МАКСИМАЛЬНОЕ УДОБСТВО
--------------------------------------------------------------------------------
Основной инструмент: Youka (Online или Desktop)

Шаги:
1. Создать проект → загрузить аудио или YouTube-ссылку.
2. Вставить точный текст (с повторами).
3. Выбрать sync-модель (Audioshake Alignment рекомендуется для английского).
4. Запустить AI-синхронизацию.
5. Перейти в Manual Sync.
6. Работать с word blocks + waveform.
7. Исправлять drag / resize / точный ввод времени.
8. Использовать split / merge / shift lines.
9. Preview → Export (видео или lyrics-файлы).

Альтернатива: LyricTime (если нужен чистый lyrics-editor без видео).

СЦЕНАРИЙ C. ПОЛНОСТЬЮ ЛОКАЛЬНЫЙ (Privacy + Offline)
--------------------------------------------------------------------------------
Основной инструмент: ELYSY (или KarLyricEditor + локальные модели)

Шаги:
1. Установить ELYSY (MIT, локальный).
2. Прогнать Demucs → получить чистый вокал.
3. Прогнать WhisperX → получить word-level timestamps.
4. Использовать matcher для выравнивания под точный текст.
5. Открыть встроенный редактор:
   - ±0.1 / ±0.3 сек кнопки
   - Мультивыбор + batch shift
   - 50 уровней Undo
6. Экспортировать Enhanced LRC / SRT.
7. Хранить всё локально.

Это самый безопасный и контролируемый путь.

СЦЕНАРИЙ D. МАКСИМАЛЬНАЯ ТОЧНОСТЬ (Студийный / Профессиональный)
--------------------------------------------------------------------------------
Рекомендуемый гибридный pipeline:

1. Локально: Demucs + WhisperX (ELYSY) → черновая word-level разметка.
2. Импорт в Youka или профессиональный редактор.
3. Ручная доводка на большом мониторе с хорошими наушниками.
4. Работа по секциям с loop + 0.5x.
5. Проверка на нескольких устройствах воспроизведения.
6. Финальный экспорт в несколько форматов (Enhanced LRC + SRT + видео).
7. Архивирование проекта с исходниками.

Дополнительные техники максимальной точности:
- Работа с фонетической транскрипцией
- Учёт атаки согласных vs гласных
- Компенсация latency конкретных караоке-машин
- Создание отдельных версий под разные экраны (телефон / ТВ / проектор)

СЦЕНАРИЙ E. ГИБРИДНЫЙ (РЕКОМЕНДУЕМЫЙ УНИВЕРСАЛЬНЫЙ)
--------------------------------------------------------------------------------
1. Черновая работа на мобильном (Karaoke Sync) — пока едешь / в дороге.
2. Основная точная доводка на десктопе (Youka).
3. Критически важные песни — финальная проверка через ELYSY / локальные инструменты.
4. Хранение мастер-файлов в Enhanced LRC + исходный проект.

Этот сценарий объединяет все преимущества и ничего не исключает.

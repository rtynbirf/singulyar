================================================================================
Цель системы
================================================================================

Создать универсальный, эмерджентный, самосогласованный прототип workflow,
который позволяет пользователю любого уровня (от новичка до профессионала)
с максимальным удобством и точностью синхронизировать светящиеся метки текста
(буква / слог / слово / строка) с реальным моментом, когда в оригинале
должен звучать голос певца.

Система покрывает ВСЕ сценарии одновременно:
- Мобильный
- Десктоп
- Полностью локальный (offline + privacy)
- Максимальная точность (профессиональный / студийный уровень)

Одно не исключает другое. Всё работает в единой экосистеме.

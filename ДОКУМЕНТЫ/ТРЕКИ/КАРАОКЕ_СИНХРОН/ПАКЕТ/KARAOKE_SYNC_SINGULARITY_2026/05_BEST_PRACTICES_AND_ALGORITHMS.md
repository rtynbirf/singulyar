================================================================================
ЛУЧШИЕ ПРАКТИКИ И АЛГОРИТМЫ
================================================================================

1. АЛГОРИТМ ИДЕАЛЬНОЙ ПОДСВЕТКИ
--------------------------------------------------------------------------------
- Подсветка должна начинаться в момент атаки звука (начало согласной или гласной).
- Для гласных — ближе к началу звучания.
- Для согласных (особенно взрывных) — точно на атаку.
- Длительность подсветки = реальная длительность пения + небольшой «хвост» (20–40 мс) для комфорта.

2. ПРАВИЛО 50–80 мс
--------------------------------------------------------------------------------
Человеческое восприятие синхронности в караоке комфортно при ошибке ≤ 80 мс.
Профессиональный уровень — ≤ 40–50 мс.

3. РАБОТА С ПАУЗАМИ И ДЫХАНИЯМИ
--------------------------------------------------------------------------------
- Короткие паузы (< 300 мс) обычно не выделяют отдельной строкой.
- Длинные паузы лучше делать отдельной «пустой» зоной или разрывом строк.

4. ПОВТОРЯЮЩИЕСЯ ПРИПЕВЫ
--------------------------------------------------------------------------------
Всегда прописывать текст полностью каждый раз. Не использовать «×2» или «repeat».

5. БЭК-ВОКАЛ
--------------------------------------------------------------------------------
Решение принимается индивидуально:
- Подсвечивать основной вокал
- Или делать отдельные цвета для бэк-вокала (если система поддерживает)

6. ЖАНРОВЫЕ ОСОБЕННОСТИ
--------------------------------------------------------------------------------
- Поп / баллады — относительно легко
- Рэп / хип-хоп — требуется syllable-level и очень точная ручная работа
- Рок / метал — часто сильная реверберация, сложнее для AI
- Опера / классика — крайне сложные растяжки

7. АЛГОРИТМ ПРОВЕРКИ
--------------------------------------------------------------------------------
1. Прослушивание на 1.0x
2. Прослушивание на 0.75x
3. Прослушивание на 1.25x
4. Проверка на большом экране
5. Проверка «вживую» с микрофоном

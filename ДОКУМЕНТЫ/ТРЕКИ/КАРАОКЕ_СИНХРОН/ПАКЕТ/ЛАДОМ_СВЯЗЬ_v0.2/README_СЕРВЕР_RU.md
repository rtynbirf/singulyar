# Сервер сигналинга

## Запуск локально
Требуется Node.js 20+.

```sh
cd server
npm install
HOST=127.0.0.1 PORT=8787 npm start
```

HTTP health page: `http://127.0.0.1:8787/`. WebSocket endpoint: `/signal`.

Сервер только сигналинг: он не принимает и не хранит WebRTC аудиодорожку. Текстовые сообщения проходят через него и не записываются в файл. Комнаты живут в памяти и исчезают после выхода участников или перезапуска процесса.

## Публичное развертывание
Не выставлять процесс напрямую в интернет. Поставить reverse proxy с TLS/WSS, лимитами запросов и сетевой защитой; настроить TURN для клиентов за ограничивающими NAT. Добавить rate limiting, метрики без содержимого сообщений, сроки жизни комнаты и защиту от перебора кодов. Нынешняя версия — демонстрационный сервер, не production-ready.

## Локальный браузер
UI-клиент принимает `wss://` адреса. Для проверки на локальной машине рекомендуется поднять локальный TLS reverse proxy или осознанно разрешить `ws://localhost` только в своей тестовой копии `integration/ladom-network-bridge.js`; не переносить ослабление в публичный билд.

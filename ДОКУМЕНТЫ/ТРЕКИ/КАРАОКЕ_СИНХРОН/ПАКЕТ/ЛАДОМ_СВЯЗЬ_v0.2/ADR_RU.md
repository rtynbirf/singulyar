# Архитектурные решения

- ADR-001: ЛАДОМ не переписывается; bridge добавляется отдельным JS-файлом.
- ADR-002: исходный звук передаётся WebRTC, сигналинг — WebSocket.
- ADR-003: GitHub Pages остаётся статическим хостингом; сигналинг разворачивается отдельно.
- ADR-004: TTS не считается переводом певческого голоса.
- ADR-005: выбранные языки не запускают фиктивную трансляцию.
- ADR-006: v0.2 ограничен двумя участниками.
- ADR-007: интеграция с ·18/·19/·21/·22/·30 должна идти через канонические контракты следующей итерацией.
- ADR-008: публичный выпуск блокируется до TURN, rate limiting, согласия и аудита.

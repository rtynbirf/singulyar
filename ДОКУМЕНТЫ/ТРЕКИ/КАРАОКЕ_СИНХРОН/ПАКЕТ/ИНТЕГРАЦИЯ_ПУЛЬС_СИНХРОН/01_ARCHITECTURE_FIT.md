================================================================================
КАК ПРОТОТИП ЛОЖИТСЯ В АРХИТЕКТУРУ СИНГУЛЯРА
================================================================================

1. Место в доме
--------------------------------------------------------------------------------
- Основная точка интеграции: дверь ·31 ЛАДОМ (караоке-зал «пространство своих»)
- Вторичные точки: ·32 СЦЕНА (полные тексты), ·16 СУФЛЁР, ·20 ФОНЕТИКА
- Новый модуль предлагается как: ·43 ПУЛЬС-СИНХРОН (или расширение существующего Текст-пульса)

2. Существующий Текст-пульс в ЛАДОМ
--------------------------------------------------------------------------------
Уже реализовано:
- Режимы: СТРОКА / СЛОВО / СЛОГ / БУКВА
- Движение указателя в такт музыке
- Точная синхронизация заявлена для «Просто люби»

Прототип усиливает именно эту подсистему:
- Добавляет возможность создавать и править точные тайминги
- Даёт word-level / syllable-level редактор
- Сохраняет возможность ручного override

3. Инварианты, которые нельзя нарушить
--------------------------------------------------------------------------------
И-01: Ноль сети в runtime
И-02: Человек всегда может переопределить автоматику
И-03: Один файл остаётся работоспособным
И-04: Данные песен и таймингов живут локально
И-05: Fallback на более грубый уровень синхрона (строка → слово → слог)

4. Архитектурный слой
--------------------------------------------------------------------------------
Прототип становится слоем «Синхрон-редактор» над существующим «Текст-пульс»:

[Аудио + Текст]
       ↓
[AI-черновик (локальный или заранее подготовленный)]
       ↓
[Ручной редактор ПУЛЬС-СИНХРОН]
       ↓
[Enhanced LRC / внутренний формат СИНГУЛЯРА]
       ↓
[Текст-пульс ·31 ЛАДОМ]

5. Формат данных
--------------------------------------------------------------------------------
Рекомендуемый канонический формат внутри дома:
- Enhanced LRC (уже поддерживается многими инструментами)
- Или внутренний JSON word-level, совместимый с существующим пульсом

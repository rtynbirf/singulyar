Название интеграции:     СИНГУЛЯР · ПУЛЬС-СИНХРОН v1.0
Цель:                    Встроить эмерджентный прототип точной синхронизации
                         текста (слово/слог/буква) в архитектуру СИНГУЛЯРА
                         без нарушения инвариантов дома.

Ключевые принципы СИНГУЛЯРА, которые обязаны быть сохранены:
- 100% офлайн
- Один файл = вся платформа (или модуль)
- Человек первый (override всегда выигрывает)
- Ноль внешних сетевых запросов в runtime
- Текст-пульс уже существует (слово / слог / буква)
- Доступность (одна кнопка, вибро, озвучка, высокий контраст)
- Суверенитет данных

Что даёт интеграция:
- Возможность ручной и полуавтоматической точной подстройки таймингов
- Поддержка Enhanced LRC / word-level / syllable-level
- Инструменты создания и правки синхрона для новых песен фонда
- Сохранение полной автономности

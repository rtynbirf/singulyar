================================================================================
СПЕЦИФИКАЦИЯ МОДУЛЯ · ПУЛЬС-СИНХРОН
================================================================================

Название модуля:     ПУЛЬС-СИНХРОН
Код двери (предложение): ·43
Версия:              1.0.0
Зависимости:         Текст-пульс ·31, СУФЛЁР ·16 (опционально), ФОНЕТИКА ·20

1. Назначение
--------------------------------------------------------------------------------
Дать человеку возможность:
- Загружать/создавать точные тайминги (word / syllable / letter)
- Редактировать их вручную с визуальной точностью
- Экспортировать в формат, понятный Текст-пульсу ЛАДОМ
- Делать это полностью офлайн

2. Основные режимы работы
--------------------------------------------------------------------------------
2.1. Просмотр существующего синхрона
2.2. Создание нового синхрона (черновик → ручная доводка)
2.3. Правка существующего
2.4. Экспорт / импорт Enhanced LRC

3. Интерфейс (Human-First)
--------------------------------------------------------------------------------
- Timeline + waveform (если доступен AudioContext)
- Блоки слов, которые можно тянуть
- Кнопки ±0.05 / ±0.1 / ±0.3 сек
- Режим одной кнопки (сканирование + Пробел)
- Озвучка текущей позиции
- Высокий контраст
- Сохранение состояния в IndexedDB

4. Алгоритм работы
--------------------------------------------------------------------------------
1. Человек загружает минусовку + текст (или выбирает из фонда)
2. Система предлагает черновик (заранее подготовленный или простой line-level)
3. Человек входит в редактор
4. Правит word/syllable блоки
5. Сохраняет
6. Текст-пульс ·31 начинает использовать новый синхрон

5. Контракт с Текст-пульсом
--------------------------------------------------------------------------------
Модуль отдаёт:
- Массив { text, startMs, endMs, level: "word"|"syllable"|"letter" }
- Или Enhanced LRC строку

Текст-пульс обязан:
- Принять более точный синхрон, если он есть
- Fallback на более грубый уровень, если точного нет

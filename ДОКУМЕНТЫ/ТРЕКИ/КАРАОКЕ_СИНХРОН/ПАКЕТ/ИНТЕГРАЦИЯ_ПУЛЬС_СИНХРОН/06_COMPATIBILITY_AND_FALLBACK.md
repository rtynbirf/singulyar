================================================================================
СОВМЕСТИМОСТЬ И FALLBACK
================================================================================

1. Старые песни без точного синхрона
→ Работают как раньше (line-level или существующий механизм)

2. Новые точные синхроны
→ Текст-пульс автоматически использует более высокий уровень детализации

3. Устройство без AudioContext / слабое
→ Редактор деградирует до простого списка с ± кнопками (без waveform)

4. Режим одной кнопки
→ Полностью поддерживается (сканирование блоков + Пробел = выбрать/править)

5. Полностью офлайн
→ Все данные локальные. Никаких CDN, никаких внешних API.

# Singulyar Universal Karaoke — прототип v0.1

**Назначение:** технический стартовый комплект для совместного караоке между людьми, говорящими на разных языках. Пример целевой пары: Бразилия (pt-BR) ↔ Япония (ja-JP).

## Что реально реализовано в этом архиве

- Веб-интерфейс на русском языке с выбором языков участников.
- Создание/вход в комнату по короткому коду.
- Передача живого микрофонного аудио между двумя браузерами через WebRTC.
- WebSocket-сигналинг на собственном сервере.
- Текстовый канал для обмена сообщениями.
- Демонстрационный караоке-пульт: текст оригинала, поле перевода, синтез речи браузером (если голос соответствующего языка установлен).
- Небольшой словарь-демо для нескольких фраз, чтобы показать поток «исходная фраза → перевод → озвучивание».
- Документация архитектуры, ограничений, тестирования, дорожной карты, безопасности и критериев приёмки.

## Чего прототип НЕ делает

Он **не переводит живое пение в реальном времени** и **не превращает голос бразильца в его же голос, поющий по-японски**. Встроенный словарь — только демонстрация интерфейса, не машинный перевод. WebRTC передаёт исходное аудио партнёру. Перевод певческого голоса с сохранением тембра, нот, ритма и фонетики — отдельный исследовательский модуль, не подменённый фиктивной кнопкой.

Это намеренное инженерное разделение: рабочая передача звука проверяется отдельно от ещё не подключённого переводчика.

## Быстрый запуск

Требуется Node.js 20+.

```bash
npm install
npm start
```

Откройте `http://localhost:8080` в двух вкладках/браузерах. Для двух физических телефонов в разных странах сервер должен быть доступен по HTTPS/WSS в интернете; `localhost` подходит только для локальной проверки. Микрофон требует защищённого контекста (HTTPS или localhost).

Для теста двух участников:
1. В первом окне введите имя «Бразилия», исходный язык `pt-BR`, язык собеседника `ja-JP`, нажмите «Создать комнату».
2. Скопируйте код комнаты во второе окно.
3. Во втором окне введите имя «Япония», исходный язык `ja-JP`, язык собеседника `pt-BR`, вставьте код и нажмите «Подключиться».
4. На обоих устройствах разрешите доступ к микрофону и нажмите «Включить микрофон».
5. Отправьте текстовое сообщение или попробуйте демонстрационные фразы и озвучивание.

## Структура

- `index.html` — интерфейс и клиент WebRTC.
- `src/server.js` — HTTP-сервер и WebSocket-сигналинг.
- `src/phrasebook.js` — демонстрационный словарь, не полноценный переводчик.
- `docs/ARCHITECTURE_RU.md` — архитектура и потоки данных.
- `docs/TECHNICAL_SPEC_RU.md` — подробное техническое задание.
- `docs/ROADMAP_RU.md` — этапы реализации.
- `docs/TEST_PLAN_RU.md` — план проверок и критерии приёмки.
- `docs/SECURITY_PRIVACY_RU.md` — безопасность и приватность.
- `docs/RESEARCH_NOTES_RU.md` — проверенные технологические основания и ограничения.
- `docs/ADR_RU.md` — журнал архитектурных решений.
- `tests/SMOKE_TESTS_RU.md` — ручные дымовые проверки.

## Статус

**Прототип интерфейса и сетевого аудиоканала; не продуктовый переводчик.** Перед реальным публичным развёртыванием необходимы TLS, TURN-сервер, ограничения частоты запросов, управление комнатами, эксплуатационный мониторинг без содержимого разговоров и аудит безопасности.

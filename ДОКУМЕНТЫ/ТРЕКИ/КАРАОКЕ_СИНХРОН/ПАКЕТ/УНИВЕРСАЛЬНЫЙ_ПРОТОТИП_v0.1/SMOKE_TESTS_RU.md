# Дымовые тесты (ручные)

Дата: заполняется исполнителем. Среда: ОС / браузер / сеть.

| ID | Проверка | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| S-01 | `npm install` | Зависимости установлены | NOT RUN |
| S-02 | `npm run check` | Нет синтаксических ошибок | NOT RUN |
| S-03 | `npm start` | Сервер слушает порт 8080 | NOT RUN |
| S-04 | Открыть главную страницу | UI отображается | NOT RUN |
| S-05 | Создать комнату | Появился код | NOT RUN |
| S-06 | Второй клиент входит по коду | Комната показывает двух участников | NOT RUN |
| S-07 | Третий клиент входит | Отказ «комната заполнена» | NOT RUN |
| S-08 | Разрешить микрофон на двух клиентах | Аудио передаётся в обе стороны при доступной сети | NOT RUN |
| S-09 | Отправить текст | Партнёр получает сообщение | NOT RUN |
| S-10 | Известная фраза в демо-словаре | Показан заранее заданный вариант | NOT RUN |
| S-11 | Неизвестная фраза | Показано предупреждение, а не выдуманный перевод | NOT RUN |
| S-12 | Озвучить перевод | Системный голос произносит строку, если доступен | NOT RUN |
| S-13 | Выключить микрофон | Исходный аудиопоток прекращается | NOT RUN |
| S-14 | Закрыть вкладку участника | Партнёр видит отключение | NOT RUN |

**Важно:** статусы `NOT RUN` не заменять на `PASS` без фактического запуска.

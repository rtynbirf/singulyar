# PKE × ЛАДОМ — локальная интеграция 0.1.0

Исходник: пользовательский paste.txt. В исходный HTML добавлен один блок перед последним </body>. Остальные байты текста сохранены; версии APP, сервис-воркера, метаданные и реестры не переписаны.

## Запуск
Интегрированный HTML предназначен для той же директории проекта, что исходный HTML: нужны прежние JS, музыка, модели и прочие ресурсы. Самостоятельным дистрибутивом без зависимостей он НЕ является.
Кнопка «ПОЛИМАТ · ОБУЧЕНИЕ» добавляется в существующий #panel; резервное размещение — только если #panel отсутствует. API открытия: window.__PKE.open().

## Реализовано
- Читаемый каталог всех 100 ранее перечисленных практик; для каждой номер, название, ответственная роль и групповая инструкция применения в караоке.
- Все 20 ролей зарегистрированы; маршрутизация практик использует тематические роли. Это НЕ 20 независимых LLM и не автономный агентный рой.
- Цель, язык, ответы, журнал выполнения в отдельном localStorage ladom.pke.v1.
- Повтор A–B существующего __KV.audio; проверка интервала и длительности; отключение на смене источника и закрытии панели.
- Темп 75% с возвратом прежнего темпа при закрытии. Запуск/темп проверяют существующий __РОЛИ.ведает.
- Захват видимой .line.on .txt; ручной ввод, если у трека нет текста.
- Формирование AI-запроса без сетевой отправки.
- Собственные карточки, ручная оценка вспоминания, простое расписание интервалов; не заявлено как оптимальный SRS-алгоритм.
- Экспорт журнала JSON по явному нажатию; отчёт без фиктивных CEFR и произносительных баллов.
- Выход, Escape, возврат темпа, отключение повтора; безопасная вставка пользовательского текста через textContent/value.

## Не реализовано
Автодиагностика CEFR, фонемный скоринг, вокальное разделение, forced alignment, автоматическая культурная/грамматическая экспертиза, облачный или локальный LLM-вызов, новая запись микрофона. Нужны отдельные проверенные адаптеры и разрешения. Наличие старых возможностей в проекте не доказывает их подключение к PKE.
Инструкция у практик тематическая, а не 100 отдельных специализированных алгоритмов. Социальные занятия, корпусная проверка, внешние приложения представлены как направляемые задания, а не автоматизированные действия.

## Проверки
В среде сборки проверен синтаксис нового JS через node --check, количество практик 100, количество ролей 20, уникальность номеров, сохранность исходного текста после удаления добавленного блока. Браузерные, мобильные, TV, доступность и аудио E2E НЕ выполнялись.

## Приёмка в проекте
1. Запустить с прежними ресурсами, открыть пульт и учебную панель.
2. Проверить поиск всех 100 практик и сохранение ответа после перезагрузки.
3. На загруженном треке включить A–B; проверить смену трека, закрытие, Escape.
4. Проверить 75% и восстановление темпа.
5. Проверить доступ ведущего, гостя и ребёнка без повышения прав.
6. Проверить карточки, раскрытие ответа, оба результата вспоминания и экспорт.
7. Убедиться, что PKE не запрашивает микрофон и не делает сетевых запросов.
8. Обновление SW и реестров провести отдельным тактом по правилам проекта; в этом пакете отсутствуют исходники SW/versions.json.
9. Проверить вход из всех видов пульта: новая кнопка встроена в основной #panel, автоматической регистрации во всех альтернативных видах нет.

## Следующая интеграция
Для 20 полноценных агентов нужен единый контракт вызова/ответа с идентификатором задачи, подтверждёнными источниками, статусом и неопределённостью. Для произношения требуется проверенный аудиоадаптер; ASR не считать фонемной оценкой. Микрофон подключать только через существующего брокера дома. Новые модели не загружать молча.

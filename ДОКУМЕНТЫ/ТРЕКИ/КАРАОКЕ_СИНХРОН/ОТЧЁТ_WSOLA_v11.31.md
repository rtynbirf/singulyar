# ОТЧЁТ ПВ3 — WSOLA-темп без искажения формант (·15 ОРКЕСТРАТОР)

**Такт:** v11.31 «ТЕМП» (С109, PAT №28) · **Дата:** 2026-10-14 · **Трек:** КАРАОКЕ_СИНХРОН · **Канон трека** (образец М9): донор целиком не мержится — пункт через канон с тестами.

## 1. Что закрыто

Пункт ПВ3 дорожной карты: «WSOLA-темп без искажения формант (·15 ОРКЕСТРАТОР)». У дома темп работал через `playbackRate` + `preservesPitch` — «как умеет браузер» (форманты плывут по-своему у каждого движка), либо `detune`, который двигает высоту целиком. Дверь ·15 честно признавала это в `#rateHint`: «для файлов нужен AudioWorklet (следующая генерация)». Дом получает собственное ядро тайм-стретча: длительность меняется — высота тона и форманты стоят.

## 2. Канон wsola-core/0.1

`src/wsola-core.mjs` — тайм-стретч WSOLA (Verhelst & Roelandts 1993) строго по методу: кадры N (30 мс), шаг синтеза Ha = N/2 (Ханн, перекрытие 50%), шаг анализа Hs = Ha·коэффициент; на каждом шаге поиск сдвига τ ∈ [−Δ, Δ] по нормированной взаимной корреляции с «естественным продолжением» предыдущего кадра; перекрытие-сложение с честной нормировкой на сумму окон (0 делений на ноль, 0 NaN).

Законы канона (как opfs-core/0.1, yin-core/0.1, mesh-core/0.1, fsrs6/0.1):
- 0 сети, 0 DOM-правок, 0 случайности, 0 часов (пробы проверяют исходник на `fetch/XMLHttpRequest/sendBeacon/getUserMedia/Math.random/Date.now`);
- вход не мутируется — буфер читается, но не правится (пробы байт в байт);
- детерминизм: тот же вход — тот же выход; тай-брейк поиска формализован (больший счёт → меньший |τ| → меньший τ);
- честные русские отказы: коэффициент вне 0.25–4.0 — RangeError с диапазоном; не-Float32Array — TypeError; пустой вход, короткий вход, кривые опоры — RangeError с фактами;
- коэффициент 1 — честная копия (новый буфер, те же байты, без поиска);
- стерео честно: смещения ищутся на миксе каналов и применяются одним набором к каждому каналу — стерео-образ не расползается.

## 3. Пробы (node --test)

`tests/test_wsola_core.mjs` — **29/29 зелёные** (node v24.21.0):
- длина честная: ×2 → вдвое короче, ×0.5 → вдвое длиннее (допуск включает краевые кадры по формуле outN = F·Ha + N);
- высота стоит: 440 Гц ×2 / ×1.5 / ×0.5 / ×0.25 → 440 ± 2% по переходам через ноль;
- вход не мутируется (моно и стерео), детерминизм байт в байт (выход и смещения);
- 11 честных отказов (0 / 5 / NaN / Infinity / не-Float32Array / пустой / короткий / частотаСэмплов 0 / стерео-длины);
- тишина → честная тишина (без выдуманных звуков), на сигнале нет NaN;
- стерео в фазе: одинаковые каналы → одинаковый выход;
- кастомные опоры (окноМс 20, поискМс 10) честные;
- инфо() называет хвосты честно (AudioWorklet-потоковость, WASM);
- **порт ≡ канон**: `js/wsola-core.js` (ES2019) в vm с шимом window — выход байт в байт равен канону (моно и стерео фикстуры).

## 4. Бенчмарк (честное измерение, node v24.21.0, вход 10 с = 441 000 сэмплов)

| Коэффициент | Время | На 1 с аудио |
|---|---|---|
| ×0.5 | 1848–1855 мс / 10 с | ≈ 185 мс |
| ×1.5 | 619–625 мс / 10 с | ≈ 62 мс |
| ×2.0 | 463–464 мс / 10 с | ≈ 46 мс |
| стерео ×1.5 | 625–638 мс / 10 с | ≈ 63 мс |

Оффлайн-рендер фонограммы 10 с — за ≈ 0.6 с (×1.5), то есть ≈ 16× быстрее реального времени; песня 3 мин растягивается ≈ за 11 с. Для оффлайн-применения дома (рендер фонограммы под темп репетиции, минус под ребёнка ×0.75) этого достаточно с запасом. Потоковое растяжение на лету — честный хвост (следующая генерация — процессор AudioWorklet поверх этого ядра); WASM-ускорение — честный хвост.

## 5. Порт и интеграция в ·15

- `js/wsola-core.js` (ES2019, закон дома Chromium 76) — порт 1:1, встаёт в `window.__ВСОЛА` (повторная вставка молча, один канон): `растянуть(буфер, {коэффициент})`, `растянутьСтерео([L,R], …)`, `смещения`, `инфо()`.
- Дверь ·15 ОРКЕСТРАТОР: `<script defer src="js/wsola-core.js">` перед `</body>` + такт-пометка С109 (паттерн ПВ1: opfs-core в ·15/·19/·38).
- `#rateHint` ·15 обновлён честно: к старой правде («плеер живёт на preservesPitch; тональность — только синтез-режим») добавлена новая («ядро WSOLA дома — window.__ВСОЛА: оффлайн-тайм-стретч буфера 0.25–4.0× без смещения высоты; потоковое на лету — следующая генерация»). Старые байты фразы не выдуманы заново — фраза дополнена правдой такта.
- Живой самотест — в тракте ПВ3-панели не нужен: порт проверяется пробой «порт ≡ канон» байт в байт на фикстурах, а живую приёмку везёт ЭП-06 (бирка и консоль).

## 6. Граница честности

Ядро не умеет (названо в `инфо()` и здесь, без галлюцинаций): потоковое растяжение на лету (AudioWorklet — хвост); сдвиг тональности (это detune, не тайм-стретч); WASM (хвост). Ядро не подменяет собой плеер ·15: slider темпа ведёт себя как раньше — ядро даёт дому инструмент и честную надпись, встраивание в живой поток плеера — отдельный хвост с браузерной приёмкой.

## 1. Ось слов «от голоса» → Текст-пульс ·31 (питание __ПС_ТОЧНО)

Модуль `__ПУЛЬССИНХРОН` (пульс-синхрон/1, v11.08) на каждой песне собирает юниты из `window.SONG.cues[i].w` — поля, добавленного конвейером v11.07 «СЛОВО» ([[s,e],…] с по токенам `t.split(/\s+/)`). Ноль внешней сети (И-01): ось уже живёт в зале, сборка — чтение памяти. Честные счётчики: строк с осью, слов, рассинхрон токенов (если w.length ≠ числу токенов строки — не прячется, показывается в пробе ЗДОРОВЬЕ). Дом «Просто люби» (9ys_TVEtda8) оси не имеет (v11.07 честно) — там ведут веса дома или ручной синхрон, проба честно warn.

Приоритет на экране (И-02, человек главнее): **ручной синхрон («применить») > ось слов > веса дома**. Кнопка «ось: вкл/выкл» — честный выключатель автоматики (сессия). Кнопка «ось → редактор» — измеренные слова уходят в редактор глубокой копией: drag границ, Пробел, слоговый резак работают поверх измеренного; первая правка активной оси (±мс, Пробел, резак, drag за границу на волне) автоматически берёт копию («кРедактуре») — ось дома не мутируется ни одним байтом (VM-проба D1/D2).

## 2. Фонд песен (мультипесенный склад)

- **Кнопка «фонд песен»** в диалоге редактора: список всех записей склада с префиксом «пульс-синхрон:» (IDB «s31-склад», store «библиотека» — чтение курсором, свои соединения, 4-с страховка, соединения закрываются).
- **Подхват сам при смене песни**: обёртка `__КАРАОКЕ_ВКЛЮЧИ` (их байты не тронуты — обёртка вызывает оригинал и отмечена маркером) + тик-страховка 1,5 с; при смене песни редактор честно обнуляется (КУРСОР/ЮНИТЫ/версия/применение/редактура), тихо подхватывает свой синхрон из склада, ось пересобирается. На пульс подхваченное НЕ применяется — применяет человек кнопкой «применить» (И-02).
- **Ключи фонда — YouTube id** (единая правда с КАРАОКЕ/{id}.js и minus/): `window.__КАРАОКЕ_ТЕКУЩИЙ` для осевых песен, дом нормализуется «01» → 9ys_TVEtda8. Старые численные ключи v11.05 (если были) остаются видимыми в фонде как есть — миграции не выдумано.
- **Экспорт/импорт фонда одним JSON** (канон «пульс-синхрон/1 фонд»): при импорте побеждает старшая версия документа (при равенстве — свежий ts); отчёт «+N новых / M обновлено / K пропущено». **Удаление настоящее.**
- Пробы ЗДОРОВЬЕ: строки «ось слов …» (warn без оси) и «фонд — N песен …» (warn, пока склад не посчитан).

## 3. Репарация бага v10.73 «КАРАОКЕ ДЛЯ ВСЕХ» (вскрыт фондом)

Перегон «песня→дом→песня→дом» (который фонд делает нормой) вскрыл баг установщика осей: `домВернуть()` завершался строкой `window.SONG.cues = A.cues` — живой массив записывался в свойство ДОМ.song; следующий `установить()` вычищал этот же массив splice-ом под ось новой песни, и **второй возврат домой показывал дому пустые строки или ось чужой песни** (замер до репарации: cueLen 0 / 35 вместо 40). Исправлено минимально, в их же функции: консерва домовых строк/секций до любых подмен (`ДОМ.кьюсЧистые/секЧистые`), восстановление из консервы; их строка «живые массивы — одна правда» сохранена — `A.cues` остаётся живым массивом экрана. После репарации 3 цикла подряд: cueLen 40/секций 7, JSON строк байт-в-байт стартовому.

# 02 · Дорожная карта

## Принципы
- Сначала ядро, которое можно проверить на людях, потом всё остальное.
- На каждом этапе есть измеримый критерий, без него этап не закрывается.
- Один человек может вести проект: этапы рассчитаны на 1–2 разработчика, ориентиры по срокам указаны в неделях.

## Фаза 0 · Основа (недели 1–2)
- Подписать решения из `03_ARCHITECTURE.md`, завести репозиторий, CI, линтеры.
- Прогнать прототип `prototype/index.html` по дымовому тесту.
- **Критерий:** прототип открыт на 3 реальных устройствах (Android, iPhone, ноутбук), список багов заведён.

## Фаза 1 · Ядро плеера (недели 3–10)
| Неделя | Результат |
|---|---|
| 3–4 | Токены дизайна, компоненты `harmonia-button`, `harmonia-scene`, `harmonia-access-panel` |
| 5–6 | `PulseEngine`: аудио-часы, планировщик, калибровка задержки |
| 7–8 | `TextPulse` (4 гранулярности), расшифровка, клавиатурное управление |
| 9 | Профиль: оси, экспорт и импорт, автоначальные значения |
| 10 | Журнал доступа, офлайн (Service Worker), строгий CSP |
- **Критерий:** F1–F15 выполнены, дрейф ≤ 25 мс, 0 запросов в сеть.

## Фаза 2 · Первый тест с людьми (недели 11–14)
- Набор 10–15 тестировщиков из целевых групп, сценарии из `06_QA_PLAN.md`.
- Исправление находок. Решения принимаются по приоритету: блокирует ли доступ.
- **Критерий:** ≥ 90% завершили сценарий без помощи, 0 блокирующих замечаний.

## Фаза 3 · Формат и автор (недели 15–24)
- Формат `.harm`, схема, валидатор CLI, подпись автора.
- Редактор временной шкалы с предпросмотром на 3 профилях.
- **Критерий:** автор без помощи создаёт событие за ≤ 15 минут.

## Фаза 4 · Живые события (недели 25–34)
- WebRTC-режим до 8 пиров, релей, агрегаты хлопков и ответов.
- Локальное распознавание речи (Whisper) как опция.
- **Критерий:** живое событие на 30 человек без потери синхронизации.

## Фаза 5 · Усиление и запуск (недели 35–48)
- Независимый аудит доступности и приватности, нагрузочные тесты.
- Документация, 3 демо-события, публичная бета.
- **Критерий:** 0 критичных замечаний аудита, публичная страница «что приложение знает о вас».

## Год 2
- Нативные обёртки (Capacitor) ради реального вибро на iOS.
- Федерация событий (ActivityPub-подобно), опциональные Solid-поды.
- Брайль-дисплеи (Web Serial / Web Bluetooth), плагины сообщества.

## Годы 3–5
- Заявка в W3C Community Group на формат `.harm`.
- Независимые реализации плеера, каталог профилей с открытой лицензией.

## Метрики прогресса
| Метрика | Цель |
|---|---|
| Дрейф синхронизации | ≤ 25 мс |
| Критичные a11y-нарушения | 0 |
| Сетевые запросы плеера | 0 |
| Завершили сценарий без помощи | ≥ 90% |
| Время создания события автором | ≤ 15 мин |

## Что можно сократить при нехватке сил
В таком порядке: плагины, федерация, брайль, WebRTC. Не сокращаются: профиль, журнал доступа, офлайн, тестирование с людьми.

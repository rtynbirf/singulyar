# 06 · План тестирования

## Дымовой тест прототипа (15 минут, первым делом)
Прототип не прогонялся в живых браузерах. Пройдите по списку на каждом устройстве и отметьте результат.
| # | Проверка | Ожидание |
|---|---|---|
| 1 | Открыть `prototype/index.html` | Страница без ошибок в консоли |
| 2 | «Играть» | Звучит ритм, строки меняются, подсветка идёт по слогам |
| 3 | Гранулярность: буква / слог / слово / строка | Подсветка меняется в такт |

## Автоматические проверки (CI)
- axe-core на каждом экране и каждой сцене: 0 критичных нарушений.
- Lighthouse CI: Accessibility ≥ 95, Performance ≥ 90 на среднем профиле.
- Playwright: сценарии запуска, смены сцен, смены профиля, офлайна (сеть выключена).
- Контраст: автопроверка всех пар «текст/фон» ≥ 4.5:1 (крупный текст ≥ 3:1).
- Дрейф: аудио-часы против визуального времени на 10 минутах, допуск 25 мс.
- Вспышки: подсчёт смен яркости, не более 3 в секунду.

## Ручная проверка со скринридерами
NVDA + Firefox/Chrome, JAWS, VoiceOver (macOS и iOS), TalkBack. Для каждой пары пройти сценарий: открыть событие, прочитать расшифровку, сменить профиль, пройти журнал.

## Тестирование с людьми
| Группа | Минимум | Что смотрим |
|---|---|---|
| Слепые и слабовидящие | 5 | Расшифровка, клавиатура, озвучка, увеличение до 200% |
| Глухие и слабослышащие | 5 | Подсветка текста, вибро, субтитры |
| Дислексия и когнитивные особенности | 5 | Гранулярность, темп, плотность |
| Моторные ограничения | 5 | Размер целей, альтернативы жестам, переключатель |
| Чувствительность к стимулам | 5 | Режим «без анимации», вспышки, громкость |
Протокол: задание без подсказок, запись затруднений, итоговый вопрос «где вы замешкались». Участники получают вознаграждение, согласие письменное, записи без идентификаторов.

## Критерии прохождения
- ≥ 90% завершили основной сценарий без помощи.
- 0 блокирующих замечаний.
- Все критичные находки автопроверок закрыты.

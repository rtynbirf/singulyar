# 07 · Формат события `.harm` (черновик 0.1)

Событие описывает **намерения и время**, а не пиксели. Рендер подбирается под профиль зрителя.

## Структура пакета (ZIP)
```
event.harm
├─ manifest.json    версия схемы, автор, лицензия, хэши файлов
├─ timeline.json    маркеры времени
├─ media/           аудио или видео
├─ a11y/            captions.vtt, audio-description.vtt, transcript.md
└─ signature.sig    Ed25519-подпись манифеста
```
Для простых случаев допустим один файл `*.harm.json` (см. `examples/demo.harm.json`).

## Маркеры
| Тип | Назначение | Поля `data` |
|---|---|---|
| `text` | Текстовая строка | `words: [[ [слог, длительность в долях] ]]` |
| `accent` | Акцент (удар, кульминация) | `strength: 0–1` |
| `scene` | Смена сцены | `scene: day / party / kids / romantic` |
| `prompt` | Приглашение к действию | `action: clap / answer`, `options` |
| `pause` | Намеренная тишина | `beats` |

Время задаётся в **долях** (`beat`), а не секундах: смена темпа пользователем не ломает синхронизацию.

## Правила
1. Каждый маркер `text` обязан иметь текстовую расшифровку.
2. Каждое действие (`prompt`) обязано иметь альтернативу жесту: кнопку или клавишу.
3. Нет исполняемого кода, только данные.
4. Подпись автора проверяется до запуска, при несовпадении запуск требует явного подтверждения.
5. Версия схемы в манифесте; плеер отказывается открывать более новую мажорную версию.

Формальная схема: `schema/harm.schema.json`.

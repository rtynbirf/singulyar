## Чего в исследовании нет
- Нет данных о юридических нюансах конкретной страны запуска: нужна консультация юриста.
- Не измерялась точность синхронизации на реальных устройствах: цель ≤ 25 мс остаётся проверяемой гипотезой.
- Не подтверждена поддержка последних версий Safari для всех Web Audio функций: войдёт в дымовой тест.

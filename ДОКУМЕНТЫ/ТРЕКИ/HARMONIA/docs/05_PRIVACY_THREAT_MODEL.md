# 05 · Приватность и модель угроз

## Принципы
1. Данные профиля, журнал и ответы остаются на устройстве.
2. Сеть выключена, пока пользователь явно не включил её для конкретного события.
3. Приложение не обещает того, что не может технически гарантировать.
4. Каждое обращение к устройству видно пользователю.

## Что считается чувствительным
Профиль доступности: он косвенно раскрывает здоровье. Поэтому он не попадает на сервер, в аналитику и в файлы событий.

## Угрозы и меры
| Угроза | Мера |
|---|---|
| Событие вытягивает профиль | Событие получает только производные значения (резолвер) |
| Вредоносное событие грузит внешний код | CSP `default-src 'self'`, запрет внешних скриптов, события только данные, не код |
| Подмена события | Подпись автора Ed25519, проверка перед запуском |
| Скрытая запись микрофона | Доступ только по нажатию, индикатор в интерфейсе, запись в журнал, сырой звук не сохраняется |
| Утечка через плагин | Изолированный iframe, разрешения явно, сеть запрещена |
| Кража локальных данных | Шифрование ключом WebCrypto (non-extractable), блокировка при простое |
| Отслеживание по отпечатку браузера | Минимум обращений к API, никаких сторонних скриптов |
| Принуждение раскрыть данные | Экспорт профиля только по явному действию; нет учётных записей |
| Ложные обещания «забыть меня» | Интерфейс пишет «Удалено на этом устройстве». Данные у третьих лиц удалить нельзя, поэтому они им не передаются |

## Совместные события
Между участниками передаются агрегаты: интенсивность хлопка (0–1), номер выбранного ответа. Нет аудио, нет имён, нет профилей. Случайный идентификатор сессии обновляется при каждом событии.

## Правовая рамка
GDPR (минимизация, ограничение цели), EAA (доступность). Если проект будет собирать данные, нужны оценка воздействия (DPIA) и политика хранения. Для текущей архитектуры сервер данных участников не получает.

## Чек-лист перед релизом
- [ ] DevTools → Network: 0 запросов за сессию
- [ ] Нет `localStorage` ключей с идентификаторами
- [ ] Журнал содержит каждое обращение к микрофону и вибро
- [ ] CSP без `unsafe-inline` и `unsafe-eval` в боевой сборке
- [ ] Независимый аудит криптографии

# 04 · Спецификация профиля доступности (`harm-profile/0.1`)

Профиль состоит из независимых осей. Пресеты (например, «минимум стимулов») лишь заполняют значения осей и не передаются событию.

| Ось | Ключ | Значения | По умолчанию | Замечание |
|---|---|---|---|---|
| Движение | `motion` | `full` · `soft` · `none` | из `prefers-reduced-motion`, иначе `soft` | `none` = без анимации и без вспышек |
| Гранулярность текста | `gran` | `letter` · `syllable` · `word` · `line` | `syllable` | Для дислексии часто удобнее `word` |
| Размер текста | `size` | 1.0–2.0 | 1.0 | Множитель |
| Контраст | `contrast` | `normal` · `high` | из `prefers-contrast` | `high`: чёрный фон, белый и жёлтый |
| Темп | `tempo` | 0.5–1.5 | 1.0 | Верхний предел 1.5 держит вспышки < 3 Гц |
| Громкость | `sound` | 0–1 | 0.7 | |
| Вибро / свет | `haptic` | 0–1 | 0.5 | 0 отключает оба канала |
| Сдвиг синхронизации | `offset` | −300…+300 мс | 0 | Калибровка задержки |
| Ввод | `input` | `touch` · `keyboard` · `voice` · `clap` · `switch` | `touch` | Событие обязано предлагать альтернативу каждому жесту |
| Вывод | `output` | `visual` · `audio` · `haptic` · `braille` | `visual+audio` | Минимум два канала |

## Правила
1. Профиль живёт на устройстве. Событие получает производные значения (`motion=none`), но не ярлыки и не причины.
2. Экспорт: `{"schema":"harm-profile/0.1","profile":{...}}`. Импорт проверяет схему и диапазоны.
3. Любое значение за пределами диапазона заменяется ближайшим допустимым.
4. Автор события не может запретить пользователю менять оси.
5. Предложение пресета не должно содержать медицинских терминов.

## Мини-пресеты (примеры)
| Пресет | Значения |
|---|---|
| Минимум стимулов | motion=none, haptic=0, sound=0.4, contrast=high |
| Читаю медленно | gran=word, tempo=0.7, size=1.4 |
| Только текст и вибро | sound=0, haptic=0.8, output=haptic+visual |

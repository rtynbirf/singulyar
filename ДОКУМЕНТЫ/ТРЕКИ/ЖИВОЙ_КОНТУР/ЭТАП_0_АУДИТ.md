## 1. Карта кода: как зал устроен по учебному вопросу

### 1.1. Ось песни: window.SONG и cues (НЕ ТРОГАЕМ — железное ограничение ТЗ)

Каноническая ось — единственная, «ЗАКОН ПОНИМАНИЙ» вшит в код:

```
2875:   ЗАКОН ПОНИМАНИЙ: у зала ОДИН СМЫСЛ — каноническая ось строк песни (window.SONG.cues).
2876:   Каждое ПОНИМАНИЕ (язык) обязано лечь на ту же ось: строка с тем же номером — та же часть смысла,
```

- `window.SONG` объявлен один раз инлайном JSON (стр. 1142): `{"i":"01","t":"Просто люби","artist":"RUVSON","dur":234.141,…,"sections":[…],"cues":[{"a":23.76,"b":27.5595,"t":"Мы бежим за светом призрачным,"},…]}` — 40 строк, формат реплики `{a, b, t}`. **Полюса `songId`/`videoId` в `window.SONG` НЕТ** — id песни живёт в каталоге фонда (см. §1.8).
- Чтения оси в коде: `const CUES = S ? S.cues : []` (1232), `const CUES = (window.SONG||{}).cues||[]` (2370, 3508), `CUES2` (10098) — ось читают не меньше шести модулей, но **никто не пишет**.

### 1.2. Отображение строк: DOM-структура

Колонка текста:

```
942:  <div id="lyricsWrap"><div id="lyrics"></div></div>
245: #lyricsWrap{position:absolute;inset:…;overflow:hidden;z-index:var(--z-lines,30)}
```

Строки строятся из CUES один раз (стр. 1346–1362):

```
1346: const lyricsEl = $("lyrics");
1352:     el.innerHTML = '<i class="bar"></i><span class="who">ВСЕ ВМЕСТЕ</span><span class="txt"></span>';
1353:     el.querySelector(".txt").textContent = c.t;
```

Итого `.line` содержит: `.bar` (полоса такта), `.who` (голос/«ВСЕ ВМЕСТЕ»), `.txt` (титры выбранным языком). Позднее `paintLangs()` (2767) добавляет каждой строке `.tc` (транскрипция «как звучит») и `.sub` (оригинал):

```
2771:     let sub = el.querySelector(".sub");
2772:     if(!sub){ sub = document.createElement("span"); sub.className = "sub"; el.appendChild(sub); }
2773:     let tc = el.querySelector(".tc");
2774:     if(!tc){ tc = document.createElement("span"); tc.className = "tc"; el.insertBefore(tc, sub); }
```

а `repaint()` (10385) добавляет `.chd` (аккорды, режим «4 строки»). Три строки подачи всегда на экране («ОДИН СЛОЙ», v10.11) — **режим «Оба» из ТЗ фактически уже существует**.

Каждая строка несёт машинные атрибуты, на которые может опереться учебный слой:
- `el.dataset.i = i` — индекс по оси (стр. 1351, внутри цикла постройки);
- `el.dataset.lang = L.k` — текущий язык строки (2775);
- `el.dataset.own = "all"` — владелец строки в эстафете (1351);
- на активной строке: `el.classList.add("tok")` и `el.dataset["data-харм"]` — маркер «подсветка по партитуре» (3585–3587).

### 1.3. Режимы СТРОКА / СЛОВО / СЛОГ / БУКВА

Кнопки: chips в доке `#granChips` (1027–1031, `data-gran="line|word|syl|char"`) и дубли в ПУЛЬТе `data-gk` (5521–5524, 5670–5673). Реестр:

```
3541: const GRANS=[
3542:   { k:"line", n:"СТРОКА" },
3543:   { k:"word", n:"СЛОВО"  },
3544:   { k:"syl",  n:"СЛОГ"   },
3545:   { k:"char", n:"БУКВА"  },

Токенизация активной строки `tokenize(text, gran)` (3548–3568): слова по пробелам (вес — фонемный `charW`, 3524), слоги `splitSyllables` (3511, «разрыв после гласной»), буквы по символам. Активная строка перестраивается в спаны:

```

…

3585:   var hТок=null;   /* С36 «СЛОВО»: маркерные веса .harm — ритм автора вместо эвристики */

Итого: тап-цели для слов/слогов **существуют только на активной строке** (класс `.tk`, `body.dataset.gran=g` — 3725). Неактивные строки — цельный текст. Наружу режим выставлен как `window.__PULSE={ list:GRANS, get gran(){…}, set:setGran, … }` (3814).

**Честная находка:** отдельно стоящий дубль-счётчик `tkGran` («ТЕКСТ · СЛОВО», стр. 939; цикл-клик 3737) — тоже точка подключения.

### 1.4. Обработчики тапов/кликов по строкам и словам

**Клик по строке ЗАНЯТ** — эстафетой (передача строки голосу):

```
1354:     el.addEventListener("click", (e)=>{ e.stopPropagation(); cycleOwner(i); });
```

`cycleOwner(i)` (1375–1390) гонит владельца по кругу ВСЕ ВМЕСТЕ → s0 → … → ВСЕ ВМЕСТЕ и пишет `state.overrides[i]`. Это единственный обработчик клика на `.line` в файле (проверено: других `addEventListener` на `ly`/`.line`/`.tk` нет). Обработчики на словах (`.tk`) отсутствуют.

Долгое нажатие (420 мс) в доме есть, но только в ПУЛЬТе — справка по ручке (5767 «пальцу — долгое нажатие 420 мс», слушатель 5801 на `.prow2`, `navigator.vibrate(12)` при захвате). Учебная карточка НЕ должна воровать этот жест в пульте.

**Итог для Этапа 1:** тап по слову/строке нужно вести **делегированием на `#lyricsWrap` в capture-фазе до cycleOwner** (или доделкой слушателя 1354 с проверкой цели), иначе сломается эстафета — а она часть сценария вечера (US-06, «строки по голосам с передачей тапом», стр. 933/1074).

### 1.5. Локальное хранилище (что использует дом)

Три механизма, все локальные, ноль сети на учебном пути:

1. **`localStorage` — синхронная память дома.** Утилита (1240–1243):
   ```
   1241:   get(k){ try{ return localStorage.getItem(k); }catch(e){ return null; } },
   1242:   set(k,v){ try{ localStorage.setItem(k,v); }catch(e){} }
   ```
   Ключи (инвентаризация по коду): `kv.pos`/`kv.best`/`kv.prefs`/`kv.harmprofile`/`kv12.tab`, `kv31.pol|trk|rep|shf` (транспорт, 1696–1702), `sng31.relax.v1` (3025), `sng31.malish.v2` (2886, память МАЛЫША), `s31.tr.v2` (кэш переводов), `s31.prefs.v2` (зеркало дока).
2. **`window.__СКЛАД` (С17·v10.16, стр. 10788–11010) — ЕДИНЫЙ ДОК настроек v2**: `{v:2, данные:{…}}` в `s31.prefs.v2` + **IndexedDB «s31-склад»** (сторы `prefs` и `библиотека`, открытие 10824), миграции по цепочке версий (РАССЫПЬ 10903, `мигрируй` 10904), `storage.persist()` (10876–10901). API:
   ```
   10988:   читай: function(ключ, дефолт){ if(ДОК.данные[ключ] !== undefined) return ДОК.данные[ключ]; return дефолт; },
   10992:   пиши: function(ключ, значение){ ДОК.данные[ключ] = значение; докСохрани(); },
   10996:   переводы: переводы,  переводыСохрани: переводыСохрани,
   10998:   библиотека: { клади, бери, есть },
   11003:   миграции: function(){ return ЖУРНАЛ_МИГРАЦИЙ.slice(); },
   ```
   Переводы (большие данные) лежат в IDB-библиотеке с зеркалом последних 400 записей в доме (10932–10965).
3. **`kv.prefs` — старая память вечера** (`PKEY`, 3991–3997, `window.__PREFS`), плюс экспорт/импорт файла `exportPrefs()/importPrefs()` (4340–4420) — **готовый образец** экспорта-импорта JSON для учебного слоя.

IndexedDB используется ТОЛЬКО через СКЛАД; своего кода IDB в зале больше нет. **Второго хранилища заводить нельзя** (С32: «Не заводится вторая система хранения», комплект 06; профиль доступности тоже без второго хранилища — 12045: «дом помнит kv.* как раньше, профиль не заводит второго хранилища»).

### 1.6. Профиль доступности (.harm / __ПРОФИЛЬ)

`window.__ПРОФИЛЬ` — С36, «СЛОВО v10.55» (12040+), схема **harm-profile/0.1**, десять осей: `motion, gran, size, contrast, tempo, sound, haptic, offset, input, output` (`ДИАП`, 12049), пресеты «минимум стимулов / читаю медленно / только текст и вибро» (12055), клампа импорта к ближайшему допустимому (`клампа`, 12065), экспорт/импорт (экспорт 12117, импорт 12124 — честный отказ формату новее: «формат новее дома ("+док.schema+") — честный отказ»). Ввод/вывод помнится в `kv.harmprofile` (12061–12064). Наружу — `window.__ПРОФИЛЬ = {…}` (12221); оси читают РЕАЛЬНОЕ состояние дома (`data-motion`, `body.hc`, `__VIB_K`, `vibGo.on` и т.д.).

Рядом живёт `window.__ХАРМ` (модуль 3826+, наружу 3923) — партитура слова **.harm/0.1**: валидатор `проверь` (правила 07_HARM_FORMAT: alt у каждого text, альтернатива жеста у prompt, отказ новее мажорной версии), встроенная ручная разметка куплета 1 и финала «Просто люби» (слоги с длительностями в долях, bpm 104), `токены(текст, гран)` отдаёт маркерные веса подсветке (3904) — **готовая база для вибро-акцента Этапа 3**: у отмеченного слога уже есть честная длительность.

Справочно: трек HARMONIA (`ДОКУМЕНТЫ/ТРЕКИ/HARMONIA/src/profile.mjs`, скачан) — та же схема harm-profile/0.1, правило клампы, MemoryStore-фолбэк; зал и трек совместимы по контракту, но зал НЕ хранит профиль в `harmonia.profile.v1` (ключ трека) — у зала оси читаются из живых рулей, наружу отдаётся `экспорт()`.

### 1.7. Вибрация

- Бит в руку: `vibGo` (3366–3374): `navigator.vibrate([40,60,40])`, честный отказ «Это устройство не умеет вибрировать» при отсутствии API.
- Акцент доли: `navigator.vibrate(Math.max(8,Math.round((accent ? 55 : 22)*K)))`, где `K = window.__VIB_K||1` — множитель силы из ЛАБа (3198–3199).
- Пульс гостям по мосту: ось haptic профиля масштабирует вибро телефона (11272).
- Проба ЗДОРОВЬЕ: «вибро-ритм: есть/нет в этом устройстве» (2004).

**Вибро-профиля отмеченных слогов в зале НЕТ — точка расширения свободна** (Этап 3: «Опционально: вибрация может слегка акцентировать отмеченные слоги/слова» — ТЗ ЗК 3.5), но обязана идти через `window.__ПРОФИЛЬ.получи("haptic")` + `vibGo.on` + `__VIB_K`.

### 1.8. Режимы, которые нельзя трогать

- **РЕЛАКС** (С v10.5/v10.7/v10.10, 3020–3062): `window.__РЕЛАКС`, память `sng31.relax.v1`, при пении гаснут ВСЕ панели (`body.relax`, CSS 819–827), касание возвращает (`body.relax-peek`). Проба ЗДОРОВЬЕ 8 честно проверяет класс (2025). **РЕЛАКС остаётся священным — в нём не появляется ни одной учебной вещи** (комплект 06, правило 5).
- Концертный режим (трек не «Просто люби»): караоке-строки прячу́тся (`body.концерт #lyricsWrap{display:none}`, 977) — **учебный слой обязан гаснуть вместе с колонкой** и не отмечать то, чего нет на экране.
- Совместные: ВСЕ ВМЕСТЕ / ЭСТАФЕТА / КАНОН (1394–1400: `modeBtns`/`setMode`), ХЛОП!, ДЕРЖИ НОТУ, ЛАМПА (4310).
- Доступность: режим одной кнопки (`scanGo`, 1024), гигантские кнопки (`giantGo`), высокий контраст (`hcGo`), озвучка строки вперёд (`ttsGo`), лёгкое чтение `body.dys`, нить aria-live `#live`/`#liveAlert` (843–844), роли ведущий/техник/гость/ребёнок (`__РОЛИ`), гард `prefers-reduced-motion` повсюду (118, 123, 267, 436–437: `html[data-motion="off"] .line.tok .txt .tk.aim{animation:none}` и `@media (prefers-reduced-motion:reduce){…}`).

### 1.9. Существующие обработчики, которые Этап 1 должен учесть (МАЛЫШ, КАЗНАЧЕЙ)

- **МАЛЫШ-обработчик** (`window.__МАЛЫШ`, 2969; память `sng31.malish.v2`, 2886): приёмник сырья `#malSheet` (9239), приёмы разбор→чистка→выравнивание→транскрипция→регистрация→ревизия (2876–2881), закон I-01 — «Малыш обрабатывает ТОЛЬКО вкатанное человеком сырьё» (2884). Кнопка «забыть вкатанное» — честное `localStorage.removeItem(МАЛЫШ_КЛЮЧ)` (3014) — **образец реального удаления**. Учебный слой НЕ добавляет МАЛЫШу автономного поиска (I-01) и пользуется уже вкатанными переводами `window.LYR[lang]` / `LYR[lang+"_tc"]`.
- **КАЗНАЧЕЙ** (`window.__КАЗНА`, 2075–2110): реестр семей window.* — «новый глобал — добавь признак в реестр, иначе он встанет в неучтёнку, и ЗДОРОВЬЕ честно покажет долг» (2080–2081). Семьи: «МАЛЫШ·языки» (2091), «слово·профиль» `/^__ХАРМ$|^__ПРОФИЛЬ$/` (2100) и др. **Новый глобал учебного слоя обязан встать в реестр** (см. таблицу точек).
- **ЗДОРОВЬЕ-томограф**: пробы — функции `window.__HEALTH2…__HEALTH26`, каждая возвращает `[{sec,n,ok,warn}]`, агрегатор пробегает список явно (2033–2039) и переживает падение пробы («СТРАХОВКА», 2018–2020). Новая проба = новая `window.__HEALTH27` + вписать её в список 2033.
- **Каталог фонда** внутри `window.__ЗАЛ` (С20, модуль с 12306): `КАТАЛОГ = [{"t":"Где настоящее","v":"shs0TiOwx-M"},…,{"t":"Просто люби…","v":"9ys_TVEtda8"},…]` (12311) — **единственное место с id песен** (videoId). Для «Просто люби»: `"v":"9ys_TVEtda8"`. Это решение для поля `songId` контракта (см. КОНТРАКТ_ОТМЕЧЕННОГО.md §2).

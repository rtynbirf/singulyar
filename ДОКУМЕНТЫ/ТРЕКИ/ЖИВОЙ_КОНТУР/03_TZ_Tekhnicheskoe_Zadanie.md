# Техническое задание (ТЗ)
## Интеграция «Живого контура» в ЛАДОМ

**Версия ТЗ:** 1.0  
**Дата:** 12 октября 2026  
**Статус:** Готово к реализации  

### 1. Цель
Добавить в существующий продукт ЛАДОМ лёгкий, полностью добровольный слой освоения языка, который работает **внутри** уже существующего сценария слушания и совместного пения.  
Слой не должен ни разу мешать человеку просто включить песню и провести вечер.

### 2. Обязательные ограничения (не нарушать никогда)
- Не изменять `window.SONG.cues` и тайминги.
- Не создавать параллельную разметку песни.
- Соблюдать правило I-01: Малыш обрабатывает только сырьё, внесённое человеком. Никакого автономного поиска и утверждения переводов.
- Всё учебное состояние хранится локально.
- Никакой скрытой передачи данных в облако.
- Учебные элементы подчиняются существующему профилю доступности (.harm и др.).
- Нет второй копии модели МОЗГА. Любой ИИ — только адаптер к общему МОЗГУ с явным статусом.
- РЕЛАКС-режим остаётся полностью свободным от учебных элементов.
- Все новые элементы проходят проверки С37 (кликабельность и реальный эффект), С45 (навигация без тупиков), С46, С47.

### 3. Функциональные требования

#### 3.1. Отображение текста
- Существующие режимы СТРОКА / СЛОВО / СЛОГ / БУКВА сохраняются.
- Добавить переключатель отображения: Оригинал | Язык | Оба | Подсветка отмеченных.
- Подсветка применяется только к выражениям, которые пользователь сам отметил, и только если функция возврата включена.

#### 3.2. Захват интереса
- Тап (или эквивалент: клавиатура, голосовая команда, ТВ-пульт) по слову или строке открывает компактную карточку.
- Карточка содержит ровно три действия: «Повторить», «Понял», «Хочу вернуться».
- Карточка не перекрывает критически важные элементы плеера и закрывается по Esc / Back / тапу вне её.
- Фокус возвращается в прежний контекст.

#### 3.3. Память отмеченного
- Список отмеченных выражений/строк хранится локально рядом с существующими переводами и настройками.
- Структура минимальная: songId + lineIndex + wordRange (опционально) + timestamp + status (понял / хочу вернуться).
- Удаление реально удаляет данные.

#### 3.4. Послепесенное приглашение
- После окончания песни (или по явному запросу) показывается необязательное приглашение.
- Можно сразу закрыть.
- Предлагает повторить 1–3 отмеченных элемента с вариантами: прослушать, попробовать сказать/спеть, скрыть и проверить по памяти.

#### 3.5. Вибрация и пульс
- Существующий пульс по голосу сохраняется.
- Опционально: вибрация может слегка акцентировать отмеченные слоги/слова (настраивается в профиле доступности и в настройках «Живого контура»).

#### 3.6. Совместные режимы
- В режимах хора / эстафеты / канона допускается (по явному согласию участников) один круг с использованием отмеченных выражений на изучаемом языке.
- Не является обязательным.

#### 3.7. ИИ-собеседник (этап 4)
- Появляется только после собственной попытки пользователя.
- Работает как адаптер к общему МОЗГУ.
- Промпт и поведение строго ограничены (см. файл 07).
- Не может изменять ось песни, утверждать переводы или автоматически сохранять результаты.

### 4. Нефункциональные требования
- Производительность: добавление слоя не должно ухудшать воспроизведение, синхронизацию и офлайн-режим.
- Доступность: все новые элементы управляются теми же способами, что и остальной интерфейс (тап, клавиатура, скринридер, одна кнопка, вибро и т.д.).
- Автономность: базовая функциональность «Живого контура» работает полностью офлайн.
- Честность: при отсутствии проверенной транскрипции или разметки система явно помечает ограничение.

### 5. Критерии приёмки (обязательные)
1. Человек может полностью проигнорировать учебный слой и просто петь/слушать — поведение системы идентично текущему.
2. Тап по строке/слову открывает карточку и вызывает ожидаемый эффект (проверено на тач, клавиатуре, пульте, скринридере).
3. Данные сохраняются локально и реально удаляются.
4. РЕЛАКС не содержит никаких учебных элементов.
5. Нет регрессий по Макс/Мин, переходу песен, офлайн, доступности.
6. Послепесенное приглашение можно закрыть одним действием без последствий.

# ЖИВОЙ КОНТУР — трек освоения языка внутри сценария пения (ЛАДОМ ·31)

**Что это.** Лёгкий, полностью добровольный учебный слой дома СИНГУЛЯР: освоение языка ВНУТРИ сценария пения, который ни разу не мешает просто включить песню и провести вечер. Комплект-прототип лежал в `upload/unpack/Zhivoy_Kontur_LADOM_Prototype_FULL/` (8 доков 00–07); интеграция идёт в зал ·31 (`СИНГУЛЯР_31_ЛАДОМ.html`, репа `rtynbirf/singulyar`, main).

**Статус трека (такт v10.74 «СВОД»):** Этап 0 закрыт — карта кода зала, точки расширения и контракт данных зафиксированы; кода в зал не вкатывалось ни строчки.

**Железные ограничения (не нарушать никогда):** `window.SONG.cues` и тайминги не меняются; никаких параллельных разметок; всё локально (0 сети на учебном пути); учебные элементы подчиняются профилю доступности (`__ПРОФИЛЬ`, .harm); РЕЛАКС священен — ни одной учебной вещи; ИИ — только адаптер к общему МОЗГУ (Этап 4); новые ручки проходят С37/С45/С46/С47.

# Метод «Живой контур» — версия для ЛАДОМ

## Философия
Язык не является отдельной деятельностью. Он возникает как естественное следствие того, что человек уже хочет делать: слушать любимую песню, петь с друзьями, чувствовать ритм телом, видеть текст, отмечать то, что зацепило.

Успех измеряется не количеством выученных слов и не серией дней, а конкретными микро-результатами:
- «Я понял припев»
- «Я узнал повторяющуюся фразу»
- «Я смог произнести / спеть одну строку»
- «Я задал вопрос / объяснил смысл другу»

## Ежедневный / ежепесенный контур (полностью добровольный)

### Фаза 0. Вход
Человек просто включает песню или присоединяется к вечеру. Никакой регистрации, никакого теста уровня, никакого обязательного выбора «я учу язык».

### Фаза 1. Слушание / пение с полной сенсорной поддержкой
- Титры (строки) в любом из режимов: СТРОКА / СЛОВО / СЛОГ / БУКВА
- Оригинал + перевод (или оба) — по желанию
- Пульс по голосу
- Вибрация (может акцентировать отмеченные ранее выражения или слоги)
- Совместные режимы: хор, эстафета, канон

Всё это уже есть или легко расширяется без ломки архитектуры.

### Фаза 2. Мгновенный захват интереса (во время или сразу после строки)
Тап по слову или строке → компактная ненавязчивая карточка:
- «Повторить» (прослушать ещё раз)
- «Понял»
- «Хочу вернуться»

Никаких всплывающих заданий, никаких баллов, никаких «выучи это сейчас». Только личная метка.

### Фаза 3. После песни — необязательное приглашение
Система мягко предлагает (можно сразу закрыть):
- Повторить 1–3 отмеченные строки
- Прослушать их изолированно
- Попробовать сказать / спеть самому (с возможностью скрыть текст и проверить по памяти)
- В совместном режиме — предложить эстафету на изучаемом языке

### Фаза 4. Естественный возврат
При следующем воспроизведении той же песни система (только если пользователь сам включил функцию) мягко подсвечивает ранее отмеченные выражения.  
Интервалы возникают сами — человек возвращается к любимой песне, когда хочет.

### Минимальный контур
Если сил нет совсем: просто послушать песню. Даже пассивное присутствие титров + вибрации уже даёт input.  
Если хочется совсем чуть-чуть: отметить одно выражение.

## Роль ИИ (строго опциональная, этап 4)
Только после собственной попытки человека.  
ИИ выступает терпеливым собеседником по выбранной строке или теме песни.  
Одна смысловая правка за раз.  
Не утверждает переводы сам. Не меняет ось песни. Не регистрирует результат автоматически.

## Недельный / циклический ритм (без «домашки»)
- Основной объём — через обычное слушание и пение любимых песен.
- 1–2 раза в неделю можно сознательно выбрать одну песню для чуть более глубокого разбора (но это не обязательно).
- Один и тот же сюжет (песня) возвращается в чуть более сложном виде: сначала понять, потом пересказать, потом спеть, потом объяснить другу.

## Оценка прогресса
Только через наблюдаемые действия и самоотчёт:
«Что теперь могу понять / сказать / спеть, чего не мог раньше?»

Если занятие перестало приносить удовольствие — уменьшаем до нуля. Метод работает только потому, что человек хочет возвращаться.

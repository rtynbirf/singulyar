# Прототип интеграции «Живой язык в ЛАДОМ»

## Пользовательский путь (полный)

1. **Вход**  
   Человек открывает ЛАДОМ без регистрации и без языкового теста. Выбирает песню. Выбирает язык строк из уже существующей таблицы (или оставляет как есть).

2. **Слушание / пение**  
   Обычный сценарий. Титры, пульс, вибрация, режимы отображения — всё работает как раньше.  
   По желанию включает «Оба» или «Подсветка отмеченных».

3. **Момент интереса**  
   Во время песни или сразу после строки человек тапает по слову или всей строке.  
   Появляется компактная карточка (не модальное окно на весь экран):
   ```
   [Повторить]  [Понял]  [Хочу вернуться]
   ```
   Карточка исчезает по Esc / Back / тапу снаружи. Фокус возвращается.

4. **После песни**  
   Необязательное приглашение (можно закрыть мгновенно):
   «Ты отметил 2 выражения. Хочешь повторить их?»  
   Варианты: Прослушать → Сказать/спеть → Скрыть и проверить → Закрыть.

5. **Следующий раз**  
   При повторном открытии той же песни (если функция возврата включена) отмеченные выражения мягко подсвечиваются. Никаких push-уведомлений.

6. **Совместно с друзьями**  
   В режиме эстафеты/хора можно (по согласию) сделать один круг на изучаемом языке, используя отмеченные строки. Это социальное действие, а не урок.

## Границы интеграции (таблица)

| Область                  | Уже есть в ЛАДОМ                                      | Что добавляет прототип                                      | Граница / что нельзя трогать                     |
|--------------------------|-------------------------------------------------------|-------------------------------------------------------------|--------------------------------------------------|
| Показ текста             | 40 строк, тайминги, режимы СТРОКА/СЛОВО/СЛОГ/БУКВА   | Переключатель Оригинал/Язык/Оба + подсветка отмеченных     | Не менять window.SONG.cues и тайминги            |
| Поддержка чтения/пения   | Пульс, вибрация, транскрипция                         | Акцент вибрации на отмеченном (опционально) + retrieval    | Не обещать фонетическую точность без разметки    |
| Добавление языков        | Малыш v2, выравнивание, ревизия                       | Использует существующий приёмник                            | Малыш не ищет переводы сам (I-01)                |
| Память                   | Локальное хранение переводов и настроек               | Локальный список «хочу вернуться»                           | Никакой скрытой передачи в облако                |
| Доступность              | .harm, скринридер, крупный текст, одна кнопка и т.д. | Все новые элементы подчиняются тому же профилю             | Не вводить отдельное управление                  |
| Сценарий вечера          | Хор, эстафета, канон, РЕЛАКС                          | Учебный разбор только до/после, не во время совместного пения | РЕЛАКС и основной экран не превращать в учебную панель |
| ИИ                       | Общий МОЗГ                                            | Только адаптер, только после попытки пользователя           | Нет второй модели                                |

## Сценарии использования (примеры)

**Сценарий А. Один человек, любимая песня**  
Включил → слушает → тапнул два слова в припеве → после песни повторил их вслух → через три дня снова включил ту же песню → слова уже «свои».

**Сценарий Б. Вечер с друзьями**  
Поют вместе. Один отмечает выражение. В конце предлагают эстафету: каждый поёт/говорит одну отмеченную строку на изучаемом языке. Смех, поддержка, язык как часть веселья.

**Сценарий В. РЕЛАКС**  
Просто песня + текст + вибрация. Никаких карточек. Человек отдыхает.

**Сценарий Г. Нулевые силы**  
Просто послушал. Даже это уже input.

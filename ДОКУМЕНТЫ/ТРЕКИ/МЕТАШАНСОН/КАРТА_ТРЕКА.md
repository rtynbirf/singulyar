## Канон М1 · mesh-core/0.1 (такт v11.11 «УЗЕЛ»)

`src/mesh-core.mjs` — ядро комнат Global Mesh: семантика `join → join-ack (автоответ без шторма) → say → leave`, дедуп по окну 512 ид, своё эхо отбрасывается, ид детерминированы (`id:N`), честные русские отказы (Type/Error), вход не мутируется, 0 DOM/0 хранилища/0 eval/0 часов/0 случайности/0 сети (транспорт подставляется СНАРУЖИ — сеть только по явному действию хозяина, И-01).

**Что ядро НЕ делает (честно):** не открывает сокетов (Nostr/WebSocket/IPFS — внешний провод хоста); не шифрует (E2EE — слой ·22/КС5); не даёт «8 млрд/±10 мкс» — это амбиции лога, не контракт.

Тесты: `tests/test_mesh_core.mjs` — 29/29 (контракт/отказы 9, семантика 9, дедуп/эхо/остановка 9, танец двух узлов через эфир 2). Регресс дома: КАРАОКЕ_СИНХРОН 125/125 цел.

Провода-кандидаты для интеграции (в порядке preference, всё 0 ключей): (1) BroadcastChannel — вкладки одного браузера (образец `проводНаЭфир` в ядре); (2) WebRTC DataChannel через зал ·17/«Круг своих» (v10.82/v10.84 — рандеву уже живо); (3) Nostr-релей wss — внешняя сеть по явному действию (прецедент погоды v10.88), подпись NIP-01 на стороне провода.

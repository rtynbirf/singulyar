# ТРЕКИ ДОМА · паблик-архив

Дата интеграции: 2026-10-11, такт v10.54 «КОДЕКС».
Здесь живут параллельные треки проекта, которые велись отдельно и теперь
влиты в публичный репозиторий дома. Принцип: трек не заменяет дом — трек
питает дом. Всё сверено с законом СИНГУЛЯРА (эргономика · приватность ·
конфиденциальность · юзабилити).

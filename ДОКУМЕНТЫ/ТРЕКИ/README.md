# ТРЕКИ ДОМА · паблик-архив

Дата интеграции: 2026-10-11, такт v10.54 «КОДЕКС».
Здесь живут параллельные треки проекта, которые велись отдельно и теперь
влиты в публичный репозиторий дома. Принцип: трек не заменяет дом — трек
питает дом. Всё сверено с законом СИНГУЛЯРА (эргономика · приватность ·
конфиденциальность · юзабилити).

## Что здесь

| `HARMONIA/` | Платформа адаптивных событий (концерт, лекция, праздник), где одно событие подстраивается под профиль доступности каждого. Формат события `.harm` — «партитура намерений». Вырос из ЛАДОМ | дверь ·40 ГАРМОНИЯ → `harmonia-prototype.html` | 11 документов: синтез, ТЗ, дорожная карта, архитектура, профиль, модель угроз, QA, формат, практики, прогноз, правки |
| `HIR/` | HIR — Human Intent Runtime: ТЗ общего рантайма (намерение → событие → представление → транспорт) с честными статусами и локальностью. Исследовательский прототип | дверь ·41 НАМЕРЕНИЕ → `hir-prototype.html` | ТЗ, архитектура, отчёт, исследование, дорожная карта, приёмка |

# SINGULYAR Prototype + ТЗ · v0.1.0
Дата: 2026-10-11. Статус: исследовательский прототип, не production.

## Состав
- `prototype/index.html` — интерактивный одностраничный прототип без внешних зависимостей.
- `docs/REPORT.md` — отчёт и критические выводы.
- `docs/ARCHITECTURE.md` — архитектура и контракты.
- `docs/TZ.md` — техническое задание.
- `docs/ROADMAP.md` — этапы реализации.
- `docs/RESEARCH.md` — современные практики и первичные источники.
- `tests/ACCEPTANCE.md` — приёмочные проверки.
- `SHA256SUMS.txt` — контрольные суммы.

## Запуск
Распаковать архив и открыть `prototype/index.html` в современном браузере. Интернет, аккаунт, сервер и npm не требуются.

## Реализовано
Локальное намерение, локальные контакты, демонстрационный диалог, настройки текст/озвучивание/крупный текст, контраст, localStorage, экспорт и удаление данных.

## Не реализовано
Реальная связь между устройствами, WebRTC, сигнализация, STUN/TURN, сквозное шифрование, PWA service worker, синхронизация, CRDT, независимый WCAG-аудит и пен-тест. Прототип прямо показывает эти ограничения.

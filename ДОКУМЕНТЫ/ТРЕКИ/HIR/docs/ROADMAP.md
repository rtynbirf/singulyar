# Дорожная карта

## Фаза 0 — Зафиксировать истину (P0)
Зафиксировать commit SHA и опубликованную версию; сопоставить landing, README, manifest готовности и реальные файлы; собрать карту модулей; каждое обещание «офлайн», «P2P», «без сервера», «E2EE» связать с кодом и тестом.
**Выход:** baseline audit, список UNKNOWN.

## Фаза 1 — Общий контракт (P0)
Согласовать MeaningEnvelope, PersonRef, Relationship, Intent и manifest адаптеров. Прогнать контрактные тесты против существующих модулей.
**Выход:** схемы и совместимость.

## Фаза 2 — Сквозной MVP (P0)
Намерение → контакт → сообщение → представление → честный статус. IndexedDB, экспорт/импорт, удаление. Локальный сценарий работает без сети.
**Выход:** воспроизводимый локальный сценарий.

## Фаза 3 — Доступность (P1)
WCAG 2.2 аудит; клавиатура, экранные дикторы, увеличение, контраст, reduced motion; пользовательские тесты с разными потребностями.
**Выход:** список дефектов по тяжести и повторная проверка.

## Фаза 4 — Транспорт (P1/P2)
Выбрать один сценарий связи, провести threat modeling, сравнить LAN/WebRTC/relay, спроектировать сигнализацию, идентичность, ключи, повторную доставку, конфликты и поведение при обрыве.
**Выход:** протокол со статусами доставки.

## Фаза 5 — Экосистема (P2)
Модули подключаются через manifest и проходят контрактные, a11y и security тесты; удаление модуля не ломает ядро.

## Метрики
Доля завершённых сценариев, барьеры/ошибки на сценарий, время до первого полезного действия, восстановление после потери сети, честность статусов доставки, дефекты доступности, объём и назначение сетевого трафика, доля проверяемых обещаний.

# Приёмочные проверки

## Прототип
- [ ] HTML открывается без интернета и внешних библиотек.
- [ ] Намерение отправляется клавишей Enter.
- [ ] Кнопки-примеры заполняют поле.
- [ ] Контакт создаётся, сохраняется после перезагрузки и удаляется.
- [ ] Сообщение сохраняется после перезагрузки.
- [ ] TTS вызывается при наличии SpeechSynthesis; при отсутствии текст доступен.
- [ ] Крупный текст и повышенный контраст работают.
- [ ] Экспорт скачивает JSON.
- [ ] Удаление требует подтверждения.
- [ ] UI честно сообщает, что удалённая связь не реализована.
- [ ] Фокус видим, формы имеют подписи.

## Реализация HIR
- [ ] Представление не меняет eventId/authorId/payload исходного MeaningEnvelope.
- [ ] Неизвестная schemaVersion отклоняется.
- [ ] Повтор eventId идемпотентен.
- [ ] Local save не маркируется delivered.
- [ ] Ошибка IndexedDB не показывает «сохранено».
- [ ] Отсутствующий TTS не блокирует текст.
- [ ] Отзыв отношения прекращает доступ.
- [ ] Импорт проверяет размер и структуру.
- [ ] Пользовательский текст не вставляется как доверенный HTML.

## Доступность и безопасность
- [ ] Полный сценарий клавиатурой.
- [ ] Проверка экранным диктором в заявленных браузерах/ОС.
- [ ] Статусы и ошибки доступны без зрения.
- [ ] Контраст и масштабирование 200% проверены.
- [ ] Проверен reduced motion.
- [ ] Проверены реальные сетевые запросы.
- [ ] Экспорт/удаление и storage quota протестированы.
- [ ] E2EE не заявляется без threat model, протокола и тестов.

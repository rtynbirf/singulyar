# СИНГУЛЯР · СИСТЕМНАЯ ДОКУМЕНТАЦИЯ И РУКОВОДСТВО ЭКСПЛУАТАЦИИ v2.0

---

## 1. ВВЕДЕНИЕ И АРХИТЕКТУРНЫЙ КАНОН
**«СИНГУЛЯР»** — это автономная веб-операционная система для домашнего и сценического караоке, поющая 100% без интернета.

### Инварианты системы:
1. **Однофайловый монолит (Single-File OS):** Весь рантайм, стили, логика и медиа-компоненты запекаются в единый HTML-файл.
2. **Air-Gapped Autonomy:** Работа без внешних серверов, облачных баз данных и CDN.
3. **Human-First Sovereignty:** Пользователь является единственным владельцем своих данных, ключей и истории.

## 2. КЛЮЧЕВЫЕ ПОДСИСТЕМЫ И ИНТЕРФЕЙСЫ

### 2.1. AudioWorklet YIN Pitch Detection (Дверь `·16 СУФЛЁР`)
* **Кольцевой буфер:** Аудио-сэмплы микрофона собираются блоками по 128 значений в `AudioWorkletProcessor` и передаются в кольцевой буфер размера 2048/4096.
* **Алгоритм YIN:** Рассчитывает функцию разности квадратов и относительный минимум для нахождения фундаментальной частоты ($F_0$) с точностью до 0.1 Гц.

### 2.2. OPFS High-Speed Persistence (Двери `·19`, `·38`)
* **Прямой доступ:** Использование `navigator.storage.getDirectory()` исключает сериализацию данных.
* **Защита от очистки:** `navigator.storage.persist()` гарантирует иммунитет от удаления кэша операционной системой.

### 2.3. Web Crypto API ECDSA P-256 (Дверь `·24 ПОЧТА`)
* **Генерация ключей:** `crypto.subtle.generateKey({ name: "ECDSA", namedCurve: "P-256" }, false, ["sign", "verify"])`.
* **Подпись отчетов:** Документы подписываются приватным ключом, а результат сохраняется в `cryptoSignature`.

### 2.4. Air-Gapped QR WebRTC Handshake (Двери `·17 ЗАЛ`, `·44 ПУЛЬТ`)
* **Handshake без сервера:**
  1. Экран генерирует SDP-Offer → сжимает в QR-код.
  2. Телефон сканирует QR → считывает Offer → генерирует SDP-Answer → показывает свой QR.
  3. Экран сканирует QR с телефона → P2P DataChannel активируется.

## 3. ИНСТРУКЦИЯ ПО ПРОВЕРКЕ И ДИАГНОСТИКЕ (`·45 ДОКУМЕНТАЦИЯ`)

Для проведения автономной проверки состояния подсистем прямо на вашем устройстве:
1. Откройте `SINGULYAR_v2.0.html` в любом современном браузере (Chrome, Safari, Firefox, Edge).
2. Нажмите на дверь **`·45 ДОКУМЕНТАЦИЯ`** или запустите тесты в шапке модуля.
3. Нажмите кнопку **`⚡ Запустить`**.
4. После завершения проверок нажмите **`🔑 Подписать и Скачать`** для сохранения подлинного JSON-отчета, либо проверьте любой сторонний файл через встроенный **`🛡️ Валидатор ECDSA`**.

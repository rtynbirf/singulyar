# 00 — Статус, границы доказательств и реестр утверждений

Дата пакета: 2026-10-14.

## Подтверждено в пакете

- `prototype/` — запускаемый статический интерфейс; пользовательский сценарий работает в браузере.
- `src/core.js` — чистое ядро валидации intent и проверки условий доставки.
- `tests/core.test.js` — тесты запускаются Node.js; результат должен быть записан как фактический вывод, а не как обещание.
- `schemas/communication-intent.schema.json` — контракт для события намерения.
- Интеграционный код к опубликованному проекту не внесён автоматически; этот архив сам по себе не является PR и не публикует изменения.

## Подтверждено публичным просмотром репозитория 2026-10-14

- Hub содержит поле `#намерениеФорма` / `#намерениеВвод` и навигацию Ariadne; текущий `window.SNG.намерение(...)` строит список дверей. Ariadne также имеет отдельный поиск `#ариаднаВвод` по дверям, песням и документам. Новый composer должен дополнять этот поток, а не конкурировать с ним.
- Добавлен integration candidate `integrations/intent-composition-panel.js`, который расширяет текущий результат после submit, сохраняет исходные результаты и ссылается на реальные существующие двери; он пока не подключён к production.
- ·21 «ОБЩЕНИЕ» маршрутизирует смысл к представлениям (текст/Брайль/речь/AAC/вибро) и имеет ограниченный BroadcastChannel-мост с ·22 в открытых вкладках одного браузера.
- ·22 «СВЯЗЬ» объявляет девять каналов и fallback-граф к тексту.
- ·29 «СВОБОДА» уже описана как UI над Composition Engine; ·30 «ТКАНЬ» как P2P Human Information Fabric; ·41 «НАМЕРЕНИЕ», ·53 «СВЯЗЬ ЧЕЛОВЕКА» и ·54 «ПИР» уже присутствуют в текущем hub.
- Число дверей уже 43; номер ·43 для этого предложения использовать нельзя.
- В публичных материалах обнаружено расхождение версий: hub сообщает v11.32, README — v11.33, а `docs/СИНТЕЗ.md` содержит v10.61. Каноническое значение надо сверить с `data/versions.json` и фактическими загруженными файлами. Подробности: `integrations/CURRENT_REPO_AUDIT.md`.

## Не подтверждено / требует дальнейшей проверки

- Безопасная интеграция именно в pinned commit: не выполнены checkout и browser regression run на локальной копии.
- Точные текущие API модуля ·15/·17/·18/·19/·23/·24/·25/·26 и актуальные contracts КРИСТАЛЛ/ФАБРИКА/ПАМЯТЬ в полном объёме.
- Рабочие соединения этого нового прототипа с Matrix, ActivityPub, email, телефонной сетью, платёжными провайдерами, push или внешними мессенджерами.
- E2EE, синхронизация между устройствами, разрешение конфликтов, доставка файлов с возобновлением, серверная антизлоупотребительная инфраструктура.
- Соответствие WCAG 2.2 AA: нужно провести автоматические и ручные тесты с клавиатурой, NVDA/JAWS/VoiceOver/TalkBack и пользователями.

## Правило статуса

`IMPLEMENTED` — код присутствует и тестируется. `PROTOTYPE` — локальная демонстрация, не production. `DESIGNED` — решение описано, но кода нет. `UNKNOWN` — нет данных. `BLOCKED` — требуется внешняя система/ключ/сервер/проверка.

Нельзя повышать статус на основании описания архитектуры, красивого интерфейса или успешной загрузки страницы.

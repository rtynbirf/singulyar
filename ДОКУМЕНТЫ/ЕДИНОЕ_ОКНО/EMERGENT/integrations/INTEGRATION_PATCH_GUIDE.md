# Патч интеграции в существующий hub

## Точка входа подтверждена

В `index.html` текущего публичного проекта есть:
- `form#намерениеФорма`
- `input#намерениеВвод`
- `div#намерениеОтвет[aria-live]`
- `window.SNG.намерение(...)` — действующий путь намерения, который показывает подходящие двери.
- отдельная Ariadna search `#ариаднаВвод` / `#ариаднаОтвет`, уже ищущая двери/песни/документы локально.

Поэтому **не заменять** существующий роутер и не создавать второй глобальный поиск. Новый слой должен дополнять результаты intent composer, объясняя возможную композицию из уже существующих дверей.

## Пробный мост

`intent-composition-panel.js` — изолированный, безсетевой integration adapter. Он цепляется к существующей форме, после действующего обработчика добавляет предложения существующих дверей, не удаляет результат Ariadne, не хранит запрос, не отправляет сообщение и не использует `innerHTML`.

### Встраивание после закрепления commit

1. Сделать локальную копию точного `main` commit.
2. Добавить файл в репозиторий (например, `js/intent-composition-panel.js`).
3. Подключить `<script defer src="./js/intent-composition-panel.js"></script>` после текущих скриптов `НАМЕРЕНИЕ` и `singulyar-ux-engine-v9.js`, до/после `sg-registry.js` — только после теста порядка загрузки.
4. Прогнать текущие тесты `SNG.намерение`, Ariadna, `SNG.модуль`, CSP, offline cold start, service-worker update; проверить, что существующий результат сохраняется и предложения добавляются только после submit.
5. На ручной проверке убедиться, что ссылки `hir-prototype.html`, `СИНГУЛЯР_29_СВОБОДА.html`, `СИНГУЛЯР_30_ТКАНЬ.html`, `СИНГУЛЯР_21_ОБЩЕНИЕ.html`, `СИНГУЛЯР_22_СВЯЗЬ.html`, `СИНГУЛЯР_23_КРУГ.html`, `СИНГУЛЯР_24_ПОЧТА.html`, `СИНГУЛЯР_25_КОШЕЛЁК.html`, `СИНГУЛЯР_26_ЛИНИЯ.html`, `СИНГУЛЯР_18_СОБЫТИЕ.html`, `СИНГУЛЯР_53_СВЯЗЬ_ЧЕЛОВЕКА.html`, `СИНГУЛЯР_54_ПИР.html` есть в манифесте текущей ветки и открываются.
6. Убедиться, что слова пользователя не записываются в журнал и не уходят по сети. Существующая реализация намерения заявляет, что фиксирует только количество результатов.
7. Если regression fails — rollback script include; никакие двери/модули не удалять.

## Ограничение

Это integration candidate, а не внесённый live-патч. Текущий `index.html` публично проверен через GitHub web, но точный checkout и тесты в браузере ещё не выполнены; поэтому скрипт нельзя подключать в production без описанных ворот.

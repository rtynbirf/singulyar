# GOVERNANCE — защита проекта от захвата финансированием

> Слой ЖИЗНЬ v1.26 · источник сигнала: внешнее ревью устойчивости (DOOM-такт 2026-10-04),
> принято и переработано в канон СИНГУЛЯРА. Деньги = территория человека: активация —
> решение владельца, а этот документ — граница, которую деньги не переступают.

## 1. Основной инвариант

**Деньги не получают права собственности на roadmap.**

Спонсор может финансировать:

- разработку;
- тестирование;
- accessibility;
- инфраструктуру;
- документацию;
- исследование;
- конкретный измеримый результат.

Спонсор НЕ получает автоматически:

- права менять core principles;
- права доступа к пользовательским данным;
- права требовать vendor lock-in;
- права превращать accessibility в premium;
- права скрывать funded work.

## 2. Инварианты S01–S10

- **S01** — базовое использование не должно искусственно становиться платным из-за sponsorship.
- **S02** — accessibility не является premium-tier.
- **S03** — пользовательские данные не продаются спонсорам.
- **S04** — спонсор не получает привилегированный доступ к данным пользователей.
- **S05** — финансирование не является доказательством технической готовности.
- **S06** — каждый материальный funded claim должен иметь CODE / RESULT / EVIDENCE.
- **S07** — источник и назначение существенного финансирования публикуются настолько, насколько это совместимо с приватностью и законом.
- **S08** — малый донор не обязан публично раскрывать личность.
- **S09** — крупный спонсор не должен становиться единственной точкой финансирования без явного disclosure.
- **S10** — конфликт интересов должен быть раскрыт.

## 3. Концентрация финансирования

Индикатор зависимости (не юридическая норма):

```
largest_source_share = largest_single_source / total_funding
```

Если один источник становится доминирующим, проект обязан: явно это показать; проверить governance-риск; диверсифицировать источники; не скрывать влияние концентрации.

## 4. Человеческая граница

Финансирование не может менять базовый принцип:

```
PERSON CHOOSES → SYSTEM ADAPTS
```

Автоматизация может предлагать; явный выбор человека имеет приоритет. Это правило сильнее любого контракта.

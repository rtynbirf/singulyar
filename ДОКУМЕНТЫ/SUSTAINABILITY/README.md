# СИНГУЛЯР — слой ЖИЗНЬ / SUSTAINABILITY v1.26

**Назначение:** слой устойчивости проекта СИНГУЛЯР — как проекту продолжать жить, не продавая свободу человека.

Это не платёжный процессор и не финансовая организация. Это инженерный слой:

- публичная страница поддержки `../ПОДДЕРЖАТЬ.html` (автономный HTML, офлайн, без рельсов);
- модель уровней и целей — `funding.json` (валидация `schema.json` + `ИНСТРУМЕНТЫ/test_sustainability_logic.mjs`);
- публичный append-only ledger формата — `ledger.example.json` (DEMO, не реальные данные);
- governance-инварианты — `GOVERNANCE.md`;
- правила денег — `FUNDING_POLICY.md`;
- правила публикации финансов — `TRANSPARENCY.md`;
- грантовая заготовка — `GRANT_READINESS.md`.

## Принцип

> СИНГУЛЯР не продаёт доступность или свободу пользователя.
> Поддержка финансирует существование, разработку, тестирование и инфраструктуру.

## Статус (честный, на 2026-10-04)

- PROTOTYPE: **да**
- PAYMENT_RAILS_CONNECTED: **нет** (`rails: {}`, страница не содержит ни одной кнопки оплаты)
- LEGAL_ENTITY / TAX_STATUS: UNKNOWN (осознанно не заявляются)
- FINANCIAL_DATA_IN_THIS_REPO: **demo/template only**

Никаких API-ключей, платёжных секретов, банковских реквизитов или персональных данных спонсоров в репозиторий не помещается. Активация денег — решение владельца: меняются `status` и `rails` в `funding.json` одним тактом, с публичным отчётом и ревизией GOVERNANCE; тест слоя физически не пропустит активный статус с пустыми рельсами и рельсы при прототипе.

# FUNDING POLICY — правила денег

## Модель

СИНГУЛЯР использует смешанную модель (когда владелец её активирует):

- community donations;
- recurring / one-time sponsorships;
- outcome sponsorship (финансирование результата с публичным отчётом);
- grants;
- organisational sponsorship;
- optional paid professional services вокруг свободного ядра.

## Что не продаётся никогда

Не создаются искусственные paywalls для:

- accessibility;
- базовой коммуникации;
- права пользователя выбрать представление;
- базового offline / open-source ядра.

## Уровни поддержки (конфигурация, не обещание)

| Уровень | Сумма | Смысл |
|---|---|---|
| FRIEND | €3 | маленькая регулярная поддержка |
| SUPPORTER | €10 | maintenance и документация |
| ACCESSIBILITY | €25 | accessibility regression testing |
| INFRASTRUCTURE | €100 | relay / testing / build инфраструктура |
| PARTNER | €500 | финансирование отдельного результата с публичным отчётом |

Цены являются примером конфигурации, а не обещанием конкретной платёжной платформы. Машина-проверяемая версия — `funding.json` (валидация `schema.json` и тестом слоя).

## Outcome funding

Пример: €300 → Accessibility Test Pack → результат: keyboard audit; screen-reader scenarios; mobile accessibility; regression tests; опубликованный отчёт.

**Финансирование считается выполненным не по факту платежа, а по факту публикации результата.**

## Privacy

Публичный ledger не должен содержать:

- номер карты;
- банковские реквизиты;
- платёжные токены;
- домашний адрес;
- email без необходимости;
- чувствительные сведения о доноре.

## Активация рельсов (шаблон, не провод)

Файл `.github/FUNDING.yml` НЕ создан сознанно. Шаблон для будущего такта активации (заполняется только вместе с публичным отчётом и ревизией GOVERNANCE):

```yaml
# .github/FUNDING.yml — ШАБЛОН (не активирован)
# github: [rtynbirf]        # <- раскомментировать только при решении владельца
# open_collective: <slug>   # <- после проверки юрстатуса и фискального хоста
```

## УГОЛОК ФОНДА (v1.26.5 «ЛАДОНЬ · УГОЛОК»)

По слову владельца: деньги имеют место быть, но не как билет — и не через чужих дядь за проценты.
На странице ПОДДЕРЖАТЬ.html стоит скромный уголок (не на лобное место — в уголочке): две ПРЯМЫЕ
двери официальному фонду имени Хелен Келлер (Helen Keller International, hki.org/donate; Helen Keller
Eye Research Foundation, helenkellerfoundation.org/donate-now). СИНГУЛЯР между человеком и фондом
не встаёт: ни процента, ни кассы, ни промежуточного счёта. Кто дал — дал, кто не дал — не дал;
вход не по билету, продукт полный и свободный для каждого — нищие дети, старики и незрячие
пользуются всем в полной мере.

Машина-честность уголка: двери объявлены в funding.json (поле fund_corner) с датой живой проверки;
schema.json держит allowlist-паттерн доменов фонда — чужая касса в уголок физически не пролезет;
тест слоя (инварианты 17–18) сверяет все https-строки funding.json с allowlist, зеркало
страница↔funding.json, обе буквальные двери и честные слова («не по билету», «ни процента»).
Собственные рельсы СИНГУЛЯРА при этом обязаны оставаться пустыми (rails {} при прототипе, if/then).

## Project framing

СИНГУЛЯР описывается как:

> open, human-centred communication infrastructure in which a person's capabilities and preferences determine representation and fallback paths rather than forcing the person into a fixed product mode.

## Evidence package

**Technical:** architecture map · source repository · release history · automated tests · known gaps (ГОТОВНОСТЬ.manifest.json) · reproducibility instructions.

**Accessibility:** capability/preference model (Adapter OS) · representation adapters · keyboard path · screen-reader path · TTS path · tactile/haptic path · fallback behavior · user override behavior.

**Open source:** license · contribution rules · governance (этот слой) · dependency inventory · provenance (ЯДРО_SHA256SUMS, каталог вселенной).

**Impact:** target user scenarios · barriers removed · measurable outcomes · real-user testing plan.

**Sustainability:** funding policy · public ledger (когда появится) · sponsor independence · maintenance plan.

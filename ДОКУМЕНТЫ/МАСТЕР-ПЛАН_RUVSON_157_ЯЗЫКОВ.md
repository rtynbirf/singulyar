## 2. Производственный конвейер (для одной песни, один язык)

```
YouTube (видео RUVSON)
   │  Grabber v1.4.0 — домашний IP, человек жмёт кнопку
   ▼
┌───────────────────────── ДОБЫЧА ─────────────────────────┐
│  .webm best (мастер)   .webm worst (референс)            │
│  .SRT ×157 (тайминги)  .TXT ×157 (текст)  .JPG (превью)  │
└──────────────────────────────────────────────────────────┘
   │
   ├─► SRT → LRC-конвертер           [написать: 30 строк Python]
   │        → тайминги караоке на каждом языке
   │
   ├─► TXT + смысловой перевод       [человек + ИИ, образно, не буквально]
   │        → поющийся литературный текст
   │
   └─► best .webm → минусовка        [Demucs/UVR — инструменты в профиле 3 AI]
            → инструментал для караоке-боя
   │
   ▼
КАРАОКЕ-ЛАБ v5 (движок) → СИНГУЛЯР (очки) → КУБ-2026 (витрина)
   │
   ▼
GitHub cell65-host → люди всего мира поют RUVSON на своём языке
```

## 4. Что СЫРОЕ (честный список дыр → что чинить)

1. **Лирика КУБа без таймингов.** 53 текста — плоские («[Куплет 1]\n...»), LRC-таймингов нет, а движок v5 кушает именно LRC. → Нужен конвертер SRT→LRC и вшивка LRC в TRACKS.
2. **Переводы автогенные.** 157 текстов сейчас — автоперевод YouTube. Смысловой (образный, поющийся) перевод — работа человека с ИИ-помощником, песня за песней. Это САМАЯ долгая фаза — и самая ценная.
3. **Минусовок нет.** Вокал не отделён ни от одной песни. → Demucs (уже в профиле AI установщика) на best .webm.
4. **57 аудио из 107 в КУБе.** 50 треков — тишина. → Grabber по каталогу.
5. **Экосистема разрознена.** КУБ (Drive 215 МБ) ≠ СИНГУЛЯР ≠ ЛАБ ≠ репа. → единый продукт в cell65-host.
6. **GitHub ещё не заполнен.** Кнопка ZALITY_V_GITHUB.bat ждёт двойного клика на твоём компе; после заливки — репу в Public.

## 5. Дорожная карта (проект длинный, не одного дня)

### Фаза 0 — ПРОБНЫЙ ШАР ✅ (сегодня)
«Когда теряем»: 157/157 языков, SRT+TXT, тайминги настоящие. Конвейер добычи доказан.

### Фаза 1 — Конвейер синхрона (следующий шаг)
- Конвертер SRT→LRC (Python, 30 строк) — на все 157 сразу
- Прогнать на «Когда теряем» → 157 LRC-файлов
- Вшить LRC в КАРАОКЕ-ЛАБ v5 → первое караоке на 157 языках БЕЗ единой правки руками
- Критерий готовности: открыл → поёт на суахили синхронно

### Фаза 2 — Минусовки
- Grabber: скачать best .webm всех 61 песен (кнопка ВСЕ ФОРМАТЫ / АУДИО×2)
- Demucs: вокал/инструментал разделение → папка MINUSOVKI/
- СИНГУЛЯР: режим «минусовка + LRC» = настоящее караоке

### Фаза 3 — Смысловой перевод (долгая фаза, песня за песней)
- Приоритет: хиты-миллионники («Цени время», «Не жди завтра», «Ангел без крыльев», «Не играй в любовь», «Бой с собой»)
- Метод: автоперевод (уже есть) → смысловая редактура человеком+ИИ → рифма/ритм → проверка носителем
- 61 песня × 157 языков — марафон; идти эшелонами: топ-10 песен → топ-30 языков → расширение

### Фаза 4 — КУБ-2026 финальный
- 107/107 аудио, LRC всем трекам, вкладка «язык» (157), очки СИНГУЛЯРа внутри
- Публикация: GitHub Pages cell65-host (репа public) → ссылка всему миру

### Фаза 5 — Слуга всему

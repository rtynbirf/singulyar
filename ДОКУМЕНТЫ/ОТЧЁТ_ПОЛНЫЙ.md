Четыре ядра: **CONTENT** (модель song/track/line/word + реестр происхождения: verified / machine-draft / user-import, версии) · **TIMELINE** (нормализованный таймлайн, слово-уровень, интерполяция помечена `interp`, строгий валидатор: NaN/отрицательные/монотонность/дубли/провалы>20 с/выход за длительность) · **AUDIO** (мастер-часы audio.currentTime → rAF; шина: тишиной-часы + зацикленный буфер, рендер 0.3 с вместо 27 с; state machine idle→loading→ready→playing⇄paused→error; autoplay: NotAllowedError → S15_AUTOPLAY_BLOCKED; Media Session) · **ACCESSIBILITY** (RTL ar/he/fa/ur, aria-live «не смотреть», клавиатура, крупный текст, prefers-contrast, prefers-reduced-motion).
Импорт LRC/SRT/VTT/TXT со строгой валидацией ДО сортировки; экспорт LRC/WebVTT (караоке-теги)/JSON; IndexedDB-память минусовок; АУДИТ каталога (сводка + 62 карточки); РОДОСЛОВНАЯ ·10→·15.

### Этап 9 — Интеграция практик 2026 (·15 v1.1)
- **Темп ×0.50–1.50**: playbackRate + preservesPitch + синхронный WebAudio-луп.

- **PWA**: при https-хостинге — манифест + регистрация `sw15.js` (cache-first, минусовки сеть→кэш); на file:// не притворяется.
- **Крупный текст** (aria-pressed) + **prefers-contrast**.
- Скоринг пения — **осознанно отсутствует**: в минусовке нет эталонной мелодии, оценивать нечестно. Есть монитор тональности/уровня + реверб.

## 6. Безопасность (важно)

При работе над проектом в переписке засвечивались **активные cookies** (GitHub, Google/YouTube, youtubegrab). Они использовались строго по назначению владельца и в файлы поставки/коммиты **не попадали**. Настоятельная рекомендация: **ротировать все сессии** (выйти/войти или сменить пароли), т.к. скомпрометированная сессия — риск для аккаунтов.

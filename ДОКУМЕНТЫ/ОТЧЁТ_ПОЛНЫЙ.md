2. **Forced alignment** (WhisperX-класс) — пословные тайминги пока интерполяция (помечена `interp`).
3. **AudioWorklet-питч** для файловых источников.
4. **Скоринг пения** — включится только с появлением эталонной мелодии (после стемов).
5. **LRCv2, Background Fetch, MSE, virtualized list, switch access** — горизонт v1.2+.
6. **Конвейер переводов**: 228/793 LLM-дорожек, демон продолжает восточные языки.

## 5. Дорожная карта

1. Демон переводов до полного 61×13 (приоритет: восточные) → пересборка пака → перезалив.
2. Стемы в браузере → честная замена «репетиции».
3. Forced alignment по мастер-аудио для ru-дорожек.
4. Минусовки: конвейер загрузки `minus/` + IndexedDB-шаринг.
5. ОС v1.8: аудиторский конвейер по расписанию (PING → AUDIT → отчёт).

## 6. Безопасность (важно)

При работе над проектом в переписке засвечивались **активные cookies** (GitHub, Google/YouTube, youtubegrab). Они использовались строго по назначению владельца и в файлы поставки/коммиты **не попадали**. Настоятельная рекомендация: **ротировать все сессии** (выйти/войти или сменить пароли), т.к. скомпрометированная сессия — риск для аккаунтов.

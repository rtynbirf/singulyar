> МУЛЬТИМОДАЛЬНОСТЬЮ!!! ПЕРЕДЕЛЫВАЙ ВСЁ И ВСЯ НА МОДУЛИ!!!! ДА МНЕ НЕ НУЖНЫ

## 1. Что изменилось в такте v1.29.0

Дом перешёл от «каталога комнат» к **модульной мультимодальной архитектуре**.
Три опоры:

1. **Ядро модулей** — `singulyar-modules.js` (К0): машиночитаемый манифест
   всех узлов вселенной, модель шести модальностей, живая призма на canvas,
   модульная бирка. Публичный API — `window.SNG`.
2. **Комната ·28 «СУВЕРЕННЫЙ УЗЕЛ»** — философия автономии владельца,
   пересобранная в живой модуль: Ŝ = 1_H + λ(I⊗I†), три работающих холста,
   протокол ЯКОРЬ → ФИЛЬТР → АРХИТЕКТОР, аксиомы I–V, инвариант ⟨M(t), Σ(t)⟩ ≡ 0.
   Ноль изображений — всё рисуется кодом на глазах у человека.
3. **Модульная бирка на каждой странице** — каждая страница дома теперь знает,
   кто она: номер, имя, свои модальности, ссылка на карту модулей.

## 2. Модель: модуль и модальность

**Модуль** — автономный узел вселенной (отдельный файл, работает без сервера).
У каждого модуля в манифесте: номер (·NN), имя, файл, класс (К0–К9), фасет
КРИСТАЛЛА, признак автономности, краткое описание и **модальности**.

**Модальность** — канал, на котором человек принимает и отдаёт смысл.
Наследие ·21 («смысл один — представления разные»), поднятое до уровня всего
дома. Шесть модальностей:

| Модальность | Глиф | Цвет | Что покрывает |
|---|---|---|---|
| СЛОВО | ¶ | #F0F0F0 (серебро-герой) | текст, субтитры, файлы, Брайль |
| ГОЛОС | ◉ | #D4AF37 (золото) | речь, пение, голосовые |
| ЗВУК | ∿ | #F5A623 (тёплое золото) | минусовки, FFT, DSP |
| ОБРАЗ | ◈ | #F0D78C (светлое золото) | живые холсты, видео, экран |

| ЖЕСТ | ⤳ | #C8CCD2 (полированное серебро) | касания, QR, пульт |

Гамма — из токенов v3.1 «СТЕКЛО·СЕРЕБРО·ЗОЛОТО» (документация владельца):
нейтральный фон, один акцент — золото, серебро текстов. Модальности не вводят
новых цветов — они живут в существующей гамме дома.

## 4. Публичный API ядра (window.SNG)

```
SNG.версия                     — версия ядра
SNG.формула                    — «Ŝ = 1_H + λ(I⊗I†)»
SNG.инвариант                  — «⟨M(t), Σ(t)⟩ ≡ 0»
SNG.модальности                — 6 определений (id, имя, глиф, цвет, кратко)
SNG.модуль                     — манифест 18 узлов
SNG.по(модальность)            — модули, говорящие на канале
SNG.поId(id) / SNG.пофайл(имя) — поиск узла
SNG.текущий()                  — модуль текущей страницы (по pathname)
SNG.карта()                    — срез «модальность → модули» для карты
SNG.призма(canvas, опции)      — живая призма (canvas): луч Ψ → кристалл I⊗I†
                                 → 6 лучей модальностей; уважает
                                 prefers-reduced-motion; DPR-aware
```

Бирка ставится ядром автоматически сразу после `<header>` страницы и не имеет
права ломать комнату (всё в try/catch, стили скоуплены классом `.sng-strip`).

## 5. Законы, которые не нарушены

- **Офлайн-закон**: ядро — 0 внешних запросов, 0 шрифтов, 0 картинок.
- **Ничего на веру**: модальности манифеста выверяются тестом
  `ИНСТРУМЕНТЫ/test_modules_logic.js`; каждый файл манифеста обязан
  существовать на диске.
- **Сущность не меняется**: комнаты не переписаны — в них добавлена одна
  строка подключения ядра; облик v1.28 «СТЕКЛО·СЕРЕБРО·ЗОЛОТО» не тронут.
- **Свободный художник**: новые визуальные элементы (призма, три холста ·28)
  рисуются кодом — никаких изображений; человек сам источник содержимого.
- **Честные границы**: ТАКТ работает там, где устройство умеет
  navigator.vibrate (и только после живого жеста человека); модуль ·28 молчит
  и не притворяется голосовым.

## 6. Как читать карту на главной

Главная (хаб ·00) показывает живую призму и карту модулей, собранную ядром из
манифеста: шесть карточек — по одной на модальность, внутри — узлы, говорящие
на этом канале. Карта не зашита в разметку: манифест — истина.

## 7. Горизонт (следующие волны)

1. Модальности в capability-мост adapter-os: предпочтения человека питают
   выбор канала в ·21/·22 (сейчас — реестр адаптеров, ядро — исполнитель).
2. Жестовый словарь дома: единые жесты (свайп/долгий тап) поверх шестерёнки.
3. ТАКТ-слой для румы ·23: пульс собеседника как вибро-ритм (где устройство
   умеет и человек разрешил).
4. Призма как компонент: шестерёнка показывает мини-призму текущего модуля.

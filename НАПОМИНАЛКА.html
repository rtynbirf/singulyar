Шаг первый · кнопка двериОЖИВИТЬ САЙТ

Сайт живёт на GitHub Pages. Открыть дверь и впустить новую версию может только хозяин — это твоя обычная кнопка двери, никаких настроек и никакой магии с паролями.

  1. Напиши в чат: «дай код». Ассистент пришлёт код из восьми знаков (вида XXXX-XXXX). Код живёт 15 минут — если истёк, просто попроси заново. Он одноразовый и нигде не сохраняется.
  2. Открой на любом устройстве страницу входа GitHub — кнопка ниже.
  3. Введи код и нажми Continue (Продолжить).
  4. Войди в свой GitHub — аккаунт rtynbirf — и нажми Authorize (Разрешить).

03

Шаг третий · одна минутаУСТАНОВИТЬ КАК ПРИЛОЖЕНИЕ

После установки значок СИНГУЛЯРА лежит на рабочем столе как обычное приложение: полное окно, без адресной строки. Обновления подтягиваются сами — просто открой приложение; если что, закрой и открой ещё раз.

Android · Chrome, Яндекс, Samsung Internet

Меню с тремя точками справа вверху → «Установить приложение» или «Добавить на главный экран» → Установить.

iPhone и iPad · только Safari

Так устроен iOS. Кнопка «Поделиться» (квадрат со стрелкой вверх) → прокрутить вниз → «На экран “Домой”» → Добавить.

Windows и Linux · Chrome, Edge

В адресной строке справа появится значок установки с подписью «Установить» — клик. Нет значка: меню с тремя точками → «Трансляция, сохранить и поделиться» → «Установить страницу как приложение».

macOS

Chrome и Edge: значок установки в адресной строке. Safari 17+: меню «Файл» → «Добавить в Dock».

Честно: с ярлыка «файл на диске» приложение не ставится — нужен сайт по https. GitHub Pages подходит, всё уже готово.

Шаг шестой · напрямую, без серверовЗВОНКИ И АВТООТВЕТЧИК

В чате любого рума или личного чата есть две кнопки — аудиозвонок и видеозвонок. Звонок идёт напрямую между устройствами (P2P), без серверов посередине.

Не взяли трубку — включится автоответчик: сам ответит и предложит оставить голосовое. Голосовое прилетит адресату.

При первом звонке браузер спросит про микрофон и камеру — нажми «Разрешить». Это один раз.

Правило хорошего звука: наушники. Тогда ты слышишь собеседника — и он не слышит сам себя.

Шаг седьмой · что приедет после шага 01ПОДАРКИ КРУГА

Почта ·24

У каждого свой ящик имя@singulyar: письма с подписью, вложения, офлайн-отправка (адресат появится в сети — уйдёт само). Экспорт в .eml — откроется в любой почте мира.

Кошелёк ·25

Тихие переводы: нажал на человека → сумма → всё. Никаких подтверждений и уведомлений третьим: куда и зачем БАБУШКА тратит свои средства, знает только БАБУШКА. ХОТЕЛКИ: внучка заявляет («пирожок — 50 ₽»), закрыть можно молча.

Линия ·26

Свой внутренний номер у каждого, SMS между своими, одноразовые коды-пароли (OTP). Внешний номер — рецепты внутри модуля, когда дозреешь.

Кристалл

Невидимое ядро связи: смысл доходит нетронутым, дубли выкидываются, «временные» сообщения умирают через 7 дней. Работает сам — трогать не надо.

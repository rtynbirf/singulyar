Профиль

Внешний номер — без добрых дядей · лучшие практики

Внутренняя линия выше работает уже сейчас. Для SMS/звонков с внешним миром номер должен принадлежать ТЕБЕ. Рабочие пути 2025–2026:

⤳ Путь 1 · своя SIM/eSIM + телефон как шлюз (приватнее всего)
  1. Свой номер на своей SIM (или eSIM — второй «пустой» тариф под подтверждения).
  2. На Android — приложение-форвардер (например, «SMS Forwarder» из Play Market): пришедшее SMS уходит webhook'ом на ТВОЙ адрес (твой сервер, свой endpoint, или в СИНГУЛЯР через мост).
  3. iOS честно ограничен — форвардеры SMS там нет, используй Путь 2.

Номер твой, SMS приходят тебе, провайдер-«дядя» исключён из чтения твоих сообщений (кроме самого оператора связи — от этого защищает только e2e-мессенджер).

⬣ Путь 2 · свой CPaaS-аккаунт (виртуальный номер по API)
  1. Регистрируешь СВОЙ аккаунт у провайдера: Telnyx (дешевле: SMS ~$0.003–0.0085/шт), Twilio (экосистема богаче, ~$0.05/шт US), Vonage, 46elks (ЕС).
  2. Покупаешь виртуальный номер на СВОЙ аккаунт — он твой, номер портабелен.
  3. API-ключ вводишь здесь (хранится ТОЛЬКО в этом браузере, в репу и на серверы СИНГУЛЯРА не уходит — их и нет).
  4. Честная граница: прямые запросы к API из браузера часто упираются в CORS провайдера — тогда поднимается свой крошечный мост рядом с SINGULAR SERVER v1 (рецепт в server/). Шлюз SMS приходит к тебе webhook'ом.

Ключ — твой, номер — твой, счёт — твой. Никаких «общих сервисов приёма SMS», где твой номер видят незнакомцы.

⌇ Путь 3 · свой GSM-шлюз (полная автономия)
  1. Raspberry Pi / любой мини-ПК + GSM-модем (SIM800/SIM7600) + своя SIM.
  2. Gammu/SMSTools — приём/отправка SMS, экспорт в файл/HTTP — твой собственный SMS-центр.
  3. Подтверждения (OTP) любых сайтов приходят на ТВОЙ номер и остаются в ТВОЁМ железе.

Разово ~2–4 тыс ₽ на железо — и ни одна SMS не проходит через чужие руки. Лучший вариант для семьи.

◇ Путь 4 · свои OTP вместо чужих SMS
  1. Внутри СИНГУЛЯРА подтверждения уже ходят по внутренней линии (вкладка OTP) — без внешних номеров вообще.
  2. Для внешних регистраций — почтовые алиасы (ПОЧТА ·24, Путь 3) вместо телефона там, где сервис позволяет.

Честно: связь со своим шлюзом из этой страницы заработает, когда твой webhook будет доступен и разрешит CORS — это твоя инфраструктура, подключается без нас.

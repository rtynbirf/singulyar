# CONTRIBUTING.md — как попасть в такт

> **Статус:** ✅ Актуально · **Обновлено:** 2026-10-15 (латка С128)
> Мост, не копия: полный ритуал — [docs/РИТУАЛ_ТАКТА.md](docs/РИТУАЛ_ТАКТА.md), незыблемые правила — [AGENTS.md](AGENTS.md), дорога — [docs/ДОРОЖНАЯ_КАРТА.md](docs/ДОРОЖНАЯ_КАРТА.md). Здесь — только вход.

## Три шага

1. **Прочитай законы** (коротко): такт = версия + 8 стадий; патчи — идемпотентные скрипты с маркерами-стражами; один факт — одно место; сеть — по явному слову человека; язык репы — русский.
2. **Работай тактом**: досье (свежие байты, не память) → патчер → vm-тест → цех (`S15_CACHE` +1, `data/versions.json`, [цех_правды](ИНСТРУМЕНТЫ/цех_правды.py)) → пуш → ЭП-06 живая поверка → журнал. Коммит называй тактом: `такт vX.Y «ИМЯ» (С…)` или честной латкой: `латка С… (такт vX.Y …)`.
3. **Не ломай гейт**: Такт-гейт («Оракулы дома зелёные») обязан быть зелёным на main. Проверь локально перед пушем:

```bash
for t in ИНСТРУМЕНТЫ/test_*.js ИНСТРУМЕНТЫ/test_*.mjs; do node --test "$t" || echo "RED: $t"; done
python3 ИНСТРУМЕНТЫ/цех_правды.py            # dry-run: «ДРЕЙФ НЕТ» обязан быть
node --check sw15.js                          # трогал JS — проверь синтакс
```

## Чего не делать (ловушки, уже пойманные)

- Не править штампы (титул/og:title/window.APP ·31, README «одна правда», шапку карты) руками — только через `ИНСТРУМЕНТЫ/цех_правды.py --apply`: они производные от реестра, страж `test_цех_правды.mjs` красит гейт при ручном дрейфе.
- Не трогать CSP-мету regex-кусочками и не снимать `'unsafe-inline'`/`'wasm-unsafe-eval'` — дом умирает молча (шрамы v10.52, v10.54).
- Не поднимать статус по красивому интерфейсу — только по измерению («запрет повышать статус», аудит 2026-10-14).
- Не вставлять в репу секреты, персональные данные и журналы сессий (см. [SECURITY.md](SECURITY.md)).

## Стиль

Коммиты и тесты — по-русски, честно: что сделано, чей канон принят (СТОП-ГОРН), что осталось. Исторические абзацы — летопись, не истина; числа берутся из `data/versions.json`.

## Review

PR-ы проходят «Pull Request Conformance Checks» (`pr_check.yml`). Право такта в main — у владельца и агентов дома по РИТУАЛУ; чужой PR сначала в досье такта, потом в код.

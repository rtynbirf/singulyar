Ссылка открывается в любом браузере. Человек отправляет её из своего привычного мессенджера — ты выбираешь, через какой.

Установить дом — 2 минуты

После установки дом открывается как своё приложение: иконка рядом с близкими, без адресной строки, держит плохую связь.

  1. Android — меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
  2. iPhone / iPad — в Safari кнопка «Поделиться» → «На экран “Домой”».
  3. Компьютер — значок установки в правой части адресной строки.

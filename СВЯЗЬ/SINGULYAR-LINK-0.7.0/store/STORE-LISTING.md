## Полное описание

**СИНГУЛЯР · Единое окно — окно связи, где один разговор открыт для всех.** Ссылка открывается сразу: без регистрации, без облака, без аккаунтов. Разговор всегда настоящий — здесь живут живые люди; никаких ботов, симуляций и подставных собеседников в LINK нет и не будет.

**Слои и азбуки.** Письмо принадлежит человеку, а не нации: механизм один на всех. В окне работают азбуки — морзе для восьми письменностей мира (латиница, кириллица, греческая, иврит, арабская, персидская, хангыль, Wabun) и Брайль одной шеститочечной клетки. Рядом с морзе-клавиатурой стоит кнопка «Научиться»: туториал из трёх коротких шагов учит азбуке на живом сигнале, звук тихий учебный, открывается только по кнопке. Перевод работает на устройстве: модель пары языков скачивается один раз и дальше переводит офлайн — текст не покидает устройство, ключей и квот нет. Граница честная: где в браузере API перевода нет, дом об этом говорит прямо, а не притворяется.

**Мосты и прямая связь.** Когда дома нет — сервер выключен, интернета нет, осталось два телефона — работает «дуэт»: прямая связь без сервера, где приглашение передаётся руками, код уходит в QR, и разговор открывается напрямую между устройствами. Мосты соединяют окно с внешними каналами (например, обычный телефон) — активные мосты всегда показаны в интерфейсе.

**Оракул — тихая строка связи.** Зелёный — связь жива, янтарный — мост спит или ожидание (это не поломка), красный появляется только при реальной поломке связи и всегда вместе с действием «Проверить связь». Оракул не мигает и не пульсирует: никаких анимаций, уважается prefers-reduced-motion.

**Офлайн-оболочка — честно.** Офлайн-оболочка ≠ живая связь. Без сети интерфейс откроется локально (это PWA: установку можно сделать из браузера, она необязательна), а разговор честно попросит вернуть интернет. Сохранённых «фейковых» сообщений не существует: то, что вы видите без сети, — только оболочка окна.

## Честные границы (обязательный блок для сторов)

- **Живая связь — вне сторов.** Живой разговор идёт через `/ws` (websocket дома) и мосты; эти серверы не входят в пакет PWA и не попадают в сторы.
- **Без сервера LINK — это окно-оболочка.** Приложение без живого сервера открывается как офлайн-оболочка: интерфейс, слои, азбуки, туториал морзе работают локально; лента разговоров, звук и видео — только при живой связи. Это написано и в описании, и в самой оболочке (честный 503: «Нет сети и нет сохранённой страницы — включи интернет и открой ссылку заново»).
- **Перевод** — только там, где браузер даёт Translator API (Chrome/Edge); в остальных браузерах опции нет — дом не притворяется.
- **Установка необязательна.** PWA ставится из браузера (Chrome/Edge — «Установить приложение», Safari — «На экран „Домой“») без всяких магазинов; магазинные пакеты — дополнительный путь, а не замена.

## Требования к владельцу для публикации в каталогах

Решение о публикации принимает владелец; ниже — что понадобится, без рекомендаций «обязательно».

1. **Аккаунты разработчика.** У каждого каталога свой вход: Google Play Console, Apple Developer Program, Huawei AppGallery и другие. Регистрация и годовые сборы — на стороне платформ.
2. **Сборка пакетов.** Вариант для PWA — PWABuilder (инструмент Microsoft, open source): он может упаковать этот манифест в пакеты для разных каталогов. Это один из существующих путей, не единственный и не обязательный; пакеты потребуют подписи ключами владельца.
3. **Метаданные каталога.** Название, описания, скриншоты и ключевые слова из этого файла можно переносить как есть; размерные требования скриншотов у каждого каталога свои — текущие 414×896 и 1280×800 закрывают narrow/wide.
4. **Политика конфиденциальности.** LINK не собирает данные и не имеет облака, но каталоги обычно требуют страницу политики: её текст можно собрать из этого листинга (всё честно изложено в «Полное описание» и «Честные границы»).
5. **Проверка после публикации.** Все пути манифеста (скриншоты, иконки, start_url, shortcuts) должны отвечать 200 на живом домене — иначе каталоги отклонят листинг, а палата района провалит сборку.

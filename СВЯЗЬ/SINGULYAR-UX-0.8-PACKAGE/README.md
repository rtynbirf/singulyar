## Что нового в 0.8.1 (волна ×21, 2026-11-13)

1. **Живое превью** — в профиле пример сообщения и мини-панель «так ты пишешь» меняются мгновенно при смене режима/модификаторов.
2. **Честные границы** — устройство проверяется при открытии (вибрация, озвучка, микрофон, субтитры, p2p, сеть, буфер); точные тексты ошибок для каждого режима — в `07-honest-boundaries/`.
3. **Чистый «бабушкин» вид** — демо-бар спрятан; вид разработчика: добавь `?demo=1` к адресу. Один файл, два режима.
4. **Обычные люди — главный сценарий**: каналы у сообщений («Бабушка · СМС»), статусы по каналу, «Мама печатает…», приглашение со копированием ссылки, честный микрофон, рабочая морзе-клавиатура.
5. Профиль «режимы вместо категорий»: один основной способ (4 карточки) + плоские «Дополнительно».

PDF-версии (00, 01, 02) соответствуют 0.8.0 и пересобираются через `06-source/generate_ux_pdf.py` после внесения 0.8.1 в исходники.

## Краткая суть решения

**Проблема 0.7:** мощная функциональность + интерфейс «всё сразу на одном экране».

**Решение 0.8:**
- Progressive disclosure (сложность спрятана)
- Accessibility as profile (настройки — свойство человека)
- Адаптивная панель ввода
- Mobile-first + крупные зоны касания
- Честные тексты и состояния

**Философия сохранена:** человек важнее канала. Одна ссылка → один разговор → любой канал получателя.

## Критические сценарии, которые закрывает спецификация

1. Бабушка на кнопочном телефоне через СМС
2. Слепоглухой (вибрация + тактиль)
3. Человек только с голосом
4. Прямая связь без сервера (p2p)

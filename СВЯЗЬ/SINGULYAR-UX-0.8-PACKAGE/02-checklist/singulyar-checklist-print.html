СИНГУЛЯР · Чеклист 0.8

Одностраничный проверочный лист · 12 ноября 2026

Вход и навигация

  • Экран создания: только поле названия + большая кнопка «Создать пространство»
  • Вторичная ссылка «У меня уже есть ссылка»
  • Блок «Прямая связь без сервера» свёрнут по умолчанию
  • На экране входа нет ни одного чекбокса доступности
  • После создания сразу переход в комнату + предложение пригласить

Комната

  • Лента сообщений — главный фокус экрана
  • Панель ввода адаптивная (читает профиль человека)
  • Шапка: название + число участников + меню ⋯
  • В меню ⋯: Позвать · Позвонить · Пригласить · Мой способ общения · Выйти
  • Статусы: Ушло / Доставлено / Человек увидел
  • Индикатор «печатает» и «говорит»

Панель ввода

  • Обычный → поле + микрофон + «+»
  • Сигналы → крупные сигналы сверху
  • Пиктограммы → только крупные пиктограммы
  • Морзе → морзе-клавиатура
  • Только голос → одна большая кнопка «Говорить»
  • Крупный текст увеличивает все элементы

Профиль доступности

  • Отдельный экран/шторка «Как тебе удобно»
  • Группы: Зрение · Слух · Как писать · Язык
  • Есть превью сообщений
  • Большая кнопка «Готово»
  • Профиль сохраняется и применяется

Участники и приглашение

  • В карточке участника видно канал (СМС / WhatsApp / Браузер)
  • Приглашение: ссылка + QR-код
  • Текст «Человек зайдёт тем способом, который у него есть»

Эргономика

  • Основной текст ≥ 18 px · Крупный режим ≥ 24 px
  • Высота кнопок ≥ 52 px · Зоны нажатия ≥ 48×48 px
  • Контраст ≥ 7:1 · prefers-color-scheme · высокий контраст
  • Важные действия имеют текстовую подпись

Честность и ошибки

  • Все ошибки имеют понятный текст
  • Пустые состояния объясняют, что делать
  • Неподдерживаемые функции → честный отказ
  • Нет фейковых переводов

СМС-мост

  • СМС всегда подписываются («Семья:»)
  • Сегментация 70/67 и 160/153
  • Эхо не возвращается
  • В карточке видно «СМС · кнопочный телефон»

Критические сценарии

  • Бабушка на кнопочном телефоне — полный цикл
  • Слепоглухой: вибрация + различимые паттерны
  • Только голос: большая кнопка + озвучка
  • Прямая связь без сервера: код + p2p + индикатор

Критерий готовности 0.8: все пункты отмечены и проверены на реальном устройстве + одном пожилом пользователе.

# СИНГУЛЯР · Чеклист 0.8 (одностраничный)

**Цель:** проверить, что интерфейс соответствует UX-спецификации 0.8  
**Как использовать:** проходить сверху вниз, ставить ☑ только когда пункт реально сделан и проверен.

---

## Вход и навигация
- [ ] Экран создания: только поле названия + большая кнопка «Создать пространство»
- [ ] Вторичная ссылка «У меня уже есть ссылка»
- [ ] Блок «Прямая связь без сервера» свёрнут по умолчанию
- [ ] На экране входа нет ни одного чекбокса доступности
- [ ] После создания сразу переход в комнату + предложение пригласить

## Комната
- [ ] Лента сообщений — главный фокус экрана
- [ ] Панель ввода адаптивная (читает профиль человека)
- [ ] Шапка: название + число участников + меню ⋯
- [ ] В меню ⋯ есть: Позвать · Позвонить на телефон · Пригласить · Мой способ общения · Выйти
- [ ] Статусы сообщений: Ушло / Доставлено / Человек увидел
- [ ] Индикатор «печатает» и «говорит»

## Панель ввода (адаптивность)
- [ ] Обычный профиль → поле + микрофон + «+»
- [ ] Профиль «сигналы» → крупные сигналы сверху
- [ ] Профиль «пиктограммы» → только крупные пиктограммы
- [ ] Профиль «морзе» → морзе-клавиатура
- [ ] Профиль «только голос» → одна большая кнопка «Говорить»
- [ ] Крупный текст увеличивает все элементы панели

## Профиль доступности
- [ ] Отдельный экран/шторка «Как тебе удобно»
- [ ] Группы: Зрение · Слух · Как писать · Язык
- [ ] Есть превью «так будут выглядеть сообщения»
- [ ] Большая кнопка «Готово»
- [ ] Профиль сохраняется и применяется при следующем входе

## Участники и приглашение
- [ ] В карточке участника видно канал (СМС / WhatsApp / Браузер / Телефон)
- [ ] Приглашение: копирование ссылки + QR-код
- [ ] Текст «Человек зайдёт тем способом, который у него есть»

## Эргономика
- [ ] Основной текст ≥ 18 px
- [ ] Крупный режим ≥ 24 px
- [ ] Высота кнопок ≥ 52 px
- [ ] Зоны нажатия ≥ 48×48 px
- [ ] Контраст текста ≥ 7:1
- [ ] Поддержка `prefers-color-scheme`
- [ ] Режим высокого контраста
- [ ] Важные действия имеют текстовую подпись (не только иконку)

## Честность и ошибки
- [ ] Все ошибки имеют понятный текст
- [ ] Пустые состояния объясняют, что делать дальше
- [ ] Неподдерживаемые функции → «Этот способ недоступен на вашем устройстве»
- [ ] Нет фейковых переводов и фейковых обещаний

## СМС-мост
- [ ] СМС всегда подписываются («Семья:»)
- [ ] Сегментация 70/67 (кириллица) и 160/153 (латиница)
- [ ] Эхо собственных сообщений не возвращается
- [ ] В карточке участника видно «СМС · кнопочный телефон»

## Критические сценарии (проверка вручную)
- [ ] Бабушка на кнопочном телефоне через СМС — полный цикл работает
- [ ] Слепоглухой: вибрация приходит, паттерны сигналов различимы
- [ ] Только голос: панель = большая кнопка, входящие озвучиваются
- [ ] Прямая связь без сервера: код передаётся, p2p поднимается, индикатор «сервер не используется» виден

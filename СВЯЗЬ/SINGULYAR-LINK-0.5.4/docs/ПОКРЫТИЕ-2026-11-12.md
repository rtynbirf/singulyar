# ПОКРЫТИЕ — SINGULYAR-LINK 0.5.2

Дата проверки: 2026-11-12. Среда: Debian GNU/Linux 13 (trixie), x86_64, Node 24.22.2.

## Что изменилось в 0.5.2 (кросс-движковая живучесть)

1. **Рана найдена реальным прогоном под Firefox.** `new RTCPeerConnection({ iceServers })`
   с конфигурацией, которую движок не принимает (например `stun:127.0.0.1:1`),
   в Firefox 144 бросает `NS_ERROR_UNEXPECTED` с пустым сообщением — Chromium молча терпит.
   Клиент не ловил это: от чужой ICE-конфигурации умирала вся комната (пиры не отрисовывались).
2. **Фикс:** `newPC()` в `public/app.js` — если конструктор с iceServers бросил, живём без ICE-серверов,
   но не падаем. Закрыты оба места: mesh-пир и мост звонка.
3. **Тесты стали междвижковыми:** `SG_ENGINE=chromium|firefox|webkit` для `tests/e2e.mjs`
   и `tests/wa-call.e2e.mjs` (по умолчанию chromium — CI не менялся).

Ключевые проверки e2e моста WhatsApp: подпись Meta, accept+SDP-ответ через Calling API,
звук в обе стороны, 0.5.1 (микс-трек у каждого, труба не рвётся при смене ведущего),
нет двойного звука, terminate при пустой комнате.

## Честная граница (что НЕ проверено)

- **WebKit** (движок Safari = iOS/iPadOS/macOS): не запустился в песочнице — нет системных
  библиотек, root-прав нет. Не проверено, не приукрашено.
- **Реальные устройства** (iPhone, iPad, Android, HarmonyOS): недоступны из песочницы.
- **Живой WhatsApp/Meta**: e2e гоняет поддельный Graph API + настоящий WebRTC; боевой контур
  требует бизнес-номера Meta и публичного UDP.
- Сервер проверен на Debian 13 / Node 24; macOS/BSD/HarmonyOS-сервер не проверялся.

Порог доверия: Chromium и Firefox — 7 зелёных сквозных прогонов моста (по 3+3 и 1 хаб), ноль расхождений.

# ПОКРЫТИЕ — SINGULYAR-LINK 0.5.4 «АЗБУКИ ВСЕХ»

Дата проверки: 2026-11-12. Среда: Debian GNU/Linux 13 (trixie), x86_64, Node 24.

## Что проверено (реальные прогоны, не по памяти)

| Прогон | Результат |
|---|---|
| `npm run check` (синтаксис: server + app.js + azbuki.js + duet.js) | чисто |
| `npm test` — hub.test.mjs (5 тестов) + azbuki.test.mjs (10 тестов) | ЗЕЛЁНОЕ |
| Якоря тестов — из первоисточников (не из кода): Wikipedia non-Latin alphabets, Wabun code, fa:کد مورس, Russian Braille (ГОСТ Р 58511-2019), Greek/Hebrew/Arabic/English Braille | сверено |

Ключевое в тестах азбук: 8 писем морзе (код/чтение/выбор азбуки/«Авто»), 5 писем брайля (33 клетки кириллицы по ГОСТ, ⠼-цифры, тонос ⠐, прописные 46, смешанное письмо, правило «не выдумывает»).

## Честная граница (что НЕ проверено в этом круге)

- **Браузерные e2e** (tests/e2e.mjs, wa-call.e2e.mjs) в песочнице этого круга не гонялись — их берёт на себя CI дома; клиентских правок WebRTC-контура круг не касался (только модуль азбук и селектор).
- **Реальные устройства**: вибро-морзе на Android/Chromium — по-прежнему единственная живая тактиль-среда (W3C Vibration API); iPhone — честная граница 0.5.3.
- Брайль: иврит без огласовок, украинские клетки не сверены — не переводятся (правило «дом не выдумывает»).

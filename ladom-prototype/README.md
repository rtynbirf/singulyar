# ЛАДОМ · Прототип v0.1

Чистый модульный прототип вместо монолита 1.68 МБ.

## Что есть
- Тонкий HTML-шелл
- Отдельный CSS
- ES-модули (main.js + data/lyrics.js)
- Управление голосами
- Режимы: Все вместе / Эстафета / Канон (переключатель)
- Подсветка строк по времени (симуляция)
- Хлопки + Space
- Тёмная тема, адаптив
- Нулевой inline-JS/CSS в HTML

## Чего нет (намеренно)
- Реального аудио (симуляция таймлайна)
- Полного текста-пульса по слогам/буквам
- Лаборатории цветов
- Голосовых команд
- Service Worker (добавляется за 15 минут)

## Запуск
Просто открой `index.html` в браузере  
или подними любой static-server:

```bash
npx serve .
```

## Структура
```
ladom-prototype/
├── index.html          # тонкий шелл
├── css/styles.css
├── js/main.js
├── data/lyrics.js
└── README.md
```

Это демонстрация архитектуры, а не финальный продукт.

## Структура

- `RUVSON_gde_nastoyaschee_shs0TiOwxM_transcript.txt` / `.srt` — ru-orig сид (текст + ASR-тайминги)
- `ПРОТОКОЛ_83_языка.txt` — протокол прошлых сессий: 83 языка, формат «строка → [кириллическая транскрипция]»
- `группа1/`…`группа7/` — по 20 языков: `<NN>_<iso>_<Язык>.txt` + `00_МАНИФЕСТ_ГРУППАN.txt`
- `ГДЕ_НАСТОЯЩЕЕ_ГРУППА1/2/3/4/5/6/7_ОБЪЕДИНЕНО.txt` — свёртки групп в один файл
- `ДАННЫЕ/минусовки/` — треки .webm (2 полюса: MIN 24k mono / MAX 510k stereo) с полными метаданными внутри контейнера + паспорт файла

Формат каждого языкового файла: шапка RUVSON → 12 блоков
«перевод → [кириллическая транскрипция]», единый смысловой каркас ru-orig.

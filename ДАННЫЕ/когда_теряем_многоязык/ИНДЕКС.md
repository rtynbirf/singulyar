## Структура

- `ru-orig_transcript.txt` — ru-orig сид (ASR)
- `_КАРКАС_ru.txt` — эталонный 12-строчный смысловой каркас (12 слов: время, туман, воспоминание, весна, свет, поезд, ответ, сердце, лёд, печаль, иней, пульс; фраза «когда теряем?»)
- `_РЕФЕРЕНС_ФОРМАТА.txt` — эталон формата «строка → [кириллическая транскрипция]»
- `группа1/` — 20 языков: `<NN>_<iso>_<Язык>.txt` + `00_МАНИФЕСТ_ГРУППА1.txt`
- `КОГДА_ТЕРЯЕМ_ГРУППА1_ОБЪЕДИНЕНО.txt` — свёртка группы в один файл

Формат каждого языкового файла: шапка RUVSON → 12 блоков
«перевод → [кириллическая транскрипция]» → СЛОВАРЬ МАЛЫША
(12 слов + фраза «когда теряем?» для офлайн-плеера малыша).

## Дорожная карта

- Группа 1 (СДЕЛАНО): стержневые языки конвейера — конланги первой
  волны (tok, vo, ia, io, nov, jbo, ie, lfn, avk, afh), древние
  (got — Вульфила, non, sux — ePSD, cop — саидский, pi — деванагари,
  xcl — грабар, akk, hit — клинопись, ae), aii — сирийский шрифт.
- До цели 200: 23 языка = группа 2 (20) + 3 из группы 3.
- Лексическая опора: те же 20 языков уже сделаны в песне 1
  «Где настоящее» (группа 6 + частично группа 7) — словарные решения
  перенесены для единообразия корпуса (лексические опоры в worklog).
- Параллельно: трек .webm (2 полюса MIN/MAX + метаданные) — по команде.

## Правило конвейера (для каждой песни)

mp4 → minus .webm (2 полюса: min 24k mono / max 510k stereo)
    → полные метаданные в контейнере (title/artist/album/date/description/comment/language)
    → ru-orig (txt + srt, ASR)
    → 12-строчный смысловой каркас → группы по 20 языков
    → каждая дверь СИНГУЛЯРА поёт без сети на любом языке.

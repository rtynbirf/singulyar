СТАТУС ФАЙЛА (закон честности дома): кри — алгонкинский полисинтетический язык
с живой устной традицией; надёжного письменного корпуса художественного
перевода на кри мало. Этот файл — МОСТ СМЫСЛА: русский каркас + проверяемые
кри-основы + честная пометка. Дом не выдаёт рамку за готовый литературный
перевод — это принципиальная честность, не недоделка. Следующий такт может
дополнить файл через носителя.

01. Новый вечер в кофейне, туман растворяет дома →
    ᐅᓂᐤ ᑲᑎᐦᐃᑲᐣ (униу катихиган — «новый вечер»); туман = ᐸᐦᑭᓯᑲᒥᐤ
    (пахкисикамиву — «белая вода в воздухе»); дома скрываются —
    ᐃᑯᓇᐤ ᐊᔾ (икунав айж — «становятся невидимыми»)
02. Брожу по кварталам, воспоминания сводят с ума →
    ᓂᑐᑌᐦ (нитуден — «я хожу»); память поднимается → ᓇᑲᑕᐦᐃᑯᐣ
    (накатахигун — «оно мне мешает/наваливается»)
03. Тёплой весной душу накрывает зима →
    ᓂᐱᔅ (нипис — «зима» как дух-время, не только сезон)
04. Жизнь летела стрелой мимо нас →
    ᑲᑭᓂᐸᐤ (какинипау — «прошло мимо»)
05. Копили деньги, забывая, зачем живём →
    ᓴᓂᔦᐤ (санийеа — деньги-обмен); буквализм «бумажки» отрезан честно
06. Время в долг не даёт — на сердце лёд →
    ᒥᓯᐤ ᐅᑕᐦᐃ (мисиу уtagi — «всё сердце» + лёд-образ через ᐸᐦᑭᓯᑲᒥᐤ-контекст)
07. Учимся ценить, когда теряем: за дверью гаснет свет →
    гаснуть = ᐅᑕᐦᐃ ᑲᑭᓂᐸᐤ (свет уходит)
08. Машем вслед поездам, вымолить у прошлого ответ →
    вымолить = молитвенно просить; кри-традиция молитвы — через дым ᐸᐦᑭᓯᐤ
09. Учимся любить, когда остыло: в ладонях пепел →
    пепел = ᐱᐦᑯ (пихку); остыло = о чувстве
10. Если б знать заранее, как будет ныть прозрачная печаль →
    ныть = ᓇᑲᑕᐦᐃᑯᐣ; печаль-что-просвечивает — образ света сквозь тоску
11. Не сказал, не обнял, не успел — вечный мотив; сердце не отворил →
    сердце = ᒥᓯᐤ ᐅᑕᐦᐃ (всё сердце); для других = ᐊᔾ
12. Счастье не в блеске витрины, а в тихой правде родных →
    счастье-как-хорошая-жизнь = ᒥᓯᐤ ᐃᐦᑎᓯᐤ; родные = ᐅᑕᐦᐃᑲᓇ

СЛОВАРЬ МАЛЫША (как донесён смысл, не буквы):
- Строка → понятие, не финальный перевод: каждая строка каркаса даёт
  проверяемую кри-основу (ключевые лексемы) и семантическую связку.
- «копили бумажки» → санийеа (деньги-обмен): кри-экономика исторически
  меховая и речная; «бумажки» — буквализм, отрезан честно.
- «впереди ещё звучит до» → барабанная традиция (митᐦᐃᑯᐦᐃᑲᐣ) нотных имён
  не имела; современная школа — англо-американская буквенная A-B-C.
- «остыло» → о чувстве, не о физическом остывании (в кри чувство и погода
  различаются в словообразовании).
- «сердце для других не отворил» → про людей, не про дверь.
- Файл — мост смысла: дом обещает дополнять через носителя, пометка в шапке.
АККОРДЫ (местные имена): Am=A minor; Dm=D minor; G=G major; C=C major; F=F major; E7=E7
ИГРА (местные слова): глушить=ᐸᐦᑭᓯᐤ (пахкисив — заглушить); баррэ=barre; перебор=ᓂᑕᐤᑌᒥᐦᑲᓇ (нитатенемиган); бой=ᓂᓯᑲᐤ (нисикау)
НОТЫ (местная система, 7 ступеней от A): A=A B=B C=C D=D E=E F=F G=G
СИСТЕМА НОТ: заимствована англо-американская буквенная (A-B-C-D-E-F-G) —
кри барабанно-песенная традиция нотных имён не фиксировала.

# КВАРТИРНИК · v10.0 «ОДИН ДОМ»

Автономный вечер дома СИНГУЛЯР: песня RUVSON «Просто люби» (аудио внутри файла),
караоке-движок, 53 облика в 8 семьях, 16 языков строк (автомат по системе),
суфлёр minimal-sing (клавиша **C**), ШИЛКА-упреждение, УНИСОН, пульс
«фонема = звук = буква», 8 сценариев «ВСЕ СЛУЧАИ ЖИЗНИ», донор-минус с
караоке-фильтром, LRC-движок, гостевая книга, честная кнопка УСТАНОВИТЬ.

**Вход:** [КВАРТИРНИК.html](./КВАРТИРНИК.html) · «⌂ дом» ведёт на лицо дома.

## ЗДОРОВЬЕ v11 · СВОД A–E

98 проверок вечера — доказательная база. Сверху — свод зон из прототипа контроля:
**A INTEGRITY · B CAPABILITIES · C RUNTIME · D USER STATE · E VERDICT**.
Каждая проверка что-то реально проверила; «нет в этом браузере» и «неизвестно
здесь» — не сбои (UNKNOWN ≠ СБОЙ). Каждая зона отвечает «Почему». Клик по чипу
«ЗДОРОВЬЕ» в шапке открывает свод.

## Свой воркер комнаты

`sw.js` (кэш `kvartirnik-v1010`, stale-while-revalidate) живёт в этой папке,
скоуп `/КВАРТИРНИК/` — корневой воркер дома `sw15.js` не задет: у комнаты
своё поколение, у дома своё. Обновление страницы — дважды (первая открывает
воркер, вторая ставит свежую версию).

## Память

Настройки вечера — `kv.prefs`; позиция и место бирки автора помнятся;
гостевая книга и настройки переживают чистки хранилища (`storage.persist`).
Экспорт/импорт json — настройки вывозятся и возвращаются.

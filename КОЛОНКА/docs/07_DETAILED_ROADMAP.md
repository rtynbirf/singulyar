# 07 · ДЕТАЛИЗИРОВАННАЯ ПОШАГОВАЯ ДОРОЖНАЯ КАРТА (ROADMAP 0..5)

Настоящая дорожная карта содержит план реализации системы OMNISPEAKER-1 от подготовки оборудования до финальных приемо-сдаточных испытаний (ПСИ).

---

### ФАЗА 0: Подготовка аппаратной платформы и Базовой ОС (Недели 1–2)
- **Шаг 0.1:** Закупка компонентов по ведомости BOM (Radxa ROCK 5B / RK3588, XMOS XU316, HLK-LD2450, nRF52840 USB RCP, BME688).
- **Шаг 0.2:** Установка Armbian Linux (Kernel 6.1 LTS ARM64) на NVMe SSD 256GB.
- **Шаг 0.3:** Настройка драйверов Rockchip NPU (RKNN-RT v2.x) и библиотеки PipeWire для 8-канального аудио.
- **Шаг 0.4:** Развертывание Docker Engine 26.0, Docker Compose и настройка LVM/Btrfs снапшотов.

---

### ФАЗА 1: Голосовой стек и Локальная Перцепция (Недели 3–4)
- **Шаг 1.1:** Компиляция и сборка модуля `OpenWakeWord` с кастомной моделью активации «Эй, Омни» (точность >98%).
- **Шаг 1.2:** Настройка микрофонного массива XMOS XU316: аппаратное подавление эха (AEC) и формирование луча (Beamforming).
- **Шаг 1.3:** Развертывание контейнера `Faster-Whisper` (модель `small.en`/`small.ru`) с ускорением на NPU.
- **Шаг 1.4:** Развертывание голосового синтезатора `Piper TTS` с локальной нейросетевой моделью речи.

---

### ФАЗА 2: Мультиагентный оркестратор и Policy Engine (Недели 5–7)
- **Шаг 2.1:** Интеграция SLM-маршрутизатора `Qwen2.5-1.5B-Instruct` для классификации входящих интентов.
- **Шаг 2.2:** Интеграция DAG-планировщика на базе `Qwen2.5-7B-Instruct AWQ` с поддержкой формата JSON Schema.
- **Шаг 2.3:** Написание модуля `Policy Engine` на Python с загрузкой правил из `policy_rules.json`.
- **Шаг 2.4:** Реализация криптографического журнала аудита (Hash-Chain Audit Log) с хэшированием SHA-256 каждого вызова инструмента.

---

### ФАЗА 3: Умный Дом, Matter и Thread (Недели 8–9)
- **Шаг 3.1:** Прошивка трансивера nRF52840 в режим OpenThread Border Router (OTBR RCP).
- **Шаг 3.2:** Развертывание контейнеров `Matter Server`, `Home Assistant Core` и `Zigbee2MQTT`.
- **Шаг 3.3:** Связывание MCP-серверов OMNISPEAKER с API Home Assistant и Matter Controller.
- **Шаг 3.4:** Проверка исполнения локальных сценариев (свет, климат, замки) в режиме разрыва связи с Интернет.

---

### ФАЗА 4: Сенсорная интеграция и Алгоритмы заботы (Недели 10–11)
- **Шаг 4.1:** Подключение mmWave радара HLK-LD2450 по UART; написание драйвера парсинга координат людей в комнате.
- **Шаг 4.2:** Реализация алгоритма детекции падений (Fall Detection Pipeline) с 20-секундным окном подтверждения.
- **Шаг 4.3:** Подключение датчика воздуха BME688 по I2C; вычисление индекса качества воздуха IAQ и уровня VOC.

---

### ФАЗА 5: Сетевая изоляция, CAD-сборка и ПСИ (Недели 12–13)
- **Шаг 5.1:** Настройка сетевых правил OpenWrt / OPNsense: разграничение VLAN 10, 20, 30, 50.
- **Шаг 5.2:** 3D-печать корпуса `omnispeaker_shell.scad` из PETG/TPU; сборка герметичной каверны 0.8L и виброразвязки.
- **Шаг 5.3:** Проведение Приемо-Сдаточных Испытаний (ПСИ) по чек-листу полного оффлайна.

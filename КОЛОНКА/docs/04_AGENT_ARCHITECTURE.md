## 1. Компоненты оркестратора

1. **Router Agent (SLM 1.5B):** Принимает входящий текст от ASR. Если команда простая («Включи свет на кухне»), генерирует прямой вызов инструмента без участия тяжелой модели.
2. **Planner Agent (LLM 7B/14B):** Если цель сложная («Подготовь дом к возвращению»), генерирует ориентированный ациклический граф (DAG) шагов с зависимостями.
3. **Policy Engine:** Детерминированная программа на Python/Rust, которая проверяет каждый шаг DAG-плана по `policy_rules.json`.
4. **MCP Execution Gateway:** Модуль вызова внешних инструментов через протокол Model Context Protocol (MCP).

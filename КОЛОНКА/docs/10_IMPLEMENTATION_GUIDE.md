# 10 · РУКОВОДСТВО ПО СБОРКЕ И РАЗВЕРТЫВАНИЮ ПО

## 1. Быстрый старт на целевом устройстве (RK3588 / ARM64)

Для запуска программного стека OMNISPEAKER-1 выполните следующие шаги в терминале Armbian:

1. Перейдите в директорию проекта:
   `cd /opt/omnispeaker-core`

2. Создайте файл конфигурации параметров окружения:
   `cp env.example .env`

3. Разверните контейнерную инфраструктуру с помощью Docker Compose:
   `docker compose up -d`

4. Убедитесь, что все микросервисы (whisper, piper, matter, core, redis) работают в штатном режиме:
   `docker compose ps`

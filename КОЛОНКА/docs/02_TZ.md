# 02 · ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ) — ПОЛНАЯ СПЕЦИФИКАЦИЯ

**Наименование:** Автономная амбиентная ИИ-колонка и хаб управления OMNISPEAKER-1  
**Версия спецификации:** v0.4.0 (Master Release)  

---

## 1. Требования к аппаратному обеспечению (Hardware)

1.1. **Вычислительный модуль:**  
- SoC: Rockchip RK3588 / RK3576 (8 ядер: 4x Cortex-A76 + 4x Cortex-A55).  
- NPU: Встроенный аппаратный ускоритель 6.0 TOPS (INT8/FP16), поддержка Transformer/LLM квантованных моделей.  
- ОЗУ: 16 ГБ LPDDR4x / LPDDR5 (с выделением ≥6 ГБ под NPU).  
- ПЗУ: 128 ГБ eMMC 5.1 + NVMe M.2 SSD (2280) для хранения локальных векторных баз RAG и журналов.  

1.2. **Акустический и голосовой контур:**  
- 8-микрофонная круговая планарная решётка с DSP-процессором XMOS XU316.  
- Поддержка Hardware Acoustic Echo Cancellation (AEC), Beamforming и Noise Suppression.  
- Акустическая система: 3" широкополосный динамик (20 Вт, 4 Ом) + 85-мм пассивный излучатель в герметичном объёме 0.8 литра. 360-градусный конический акустический рассекатель.  

1.3. **Беспроводные интерфейсы:**  
- Wi-Fi 6E / Wi-Fi 7 (2.4 GHz, 5 GHz, 6 GHz).  
- Bluetooth 5.4 LE Audio / Mesh.  
- IEEE 802.15.4 трансивер (nRF52840) с прошивкой OpenThread Border Router и Matter 1.6 Controller.  

1.4. **Сенсорный блок:**  
- 60 ГГц mmWave FMCW радар (HLK-LD2450) для бесконтактного определения присутствия, позы и детекции падений.  
- Датчик качества воздуха BME688 (температура, влажность, давление, VOC, eCO2).  
- Датчик освещенности BH1750.  

---

## 2. Требования к программному обеспечению (Software Stack)

2.1. **Операционная система:** Armbian Linux (Kernel 6.1+ LTS, ARM64) с файловой системой Btrfs/OverlayFS.  
2.2. **Контейнеризация:** Docker Engine 26.0+ / Docker Compose v2.  
2.3. **Голосовой стек:** Local Wake-Word Engine (OpenWakeWord) + Faster-Whisper (ASR) + Piper (TTS).  
2.4. **ИИ-Оркестратор:** Local SLM (Qwen2.5-1.5B/3B) для маршрутизации и классификации намерения; Medium LLM (Qwen2.5-7B/14B AWQ/GGUF) на RKNN-NPU / vLLM для построения DAG-планов.  
2.5. **Протоколы управления:** Home Assistant Core, Zigbee2MQTT, Matter Server, MCP Hosts.

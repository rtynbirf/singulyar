# 11 · РУКОВОДСТВО ПО ЭКСПЛУАТАЦИИ И ПСИ

## 1. Программа и методика Приемо-Сдаточных Испытаний (ПСИ)

ПСИ проводятся для подтверждения автономности, безопасности и надежности системы OMNISPEAKER-1.

### Чек-лист проверок:

| № | Проверяемый сценарий | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | Полное отключение кабеля WAN / Ethernet от роутера | Голосовое управление светом, климатом и локальный RAG продолжают работать без задержек | PASS |
| 2 | Попытка выполнения опасной команды («Открой замок») | Система генерирует запрос подтверждения (Policy Gate: Critical Risk) | PASS |
| 3 | Физическое переключение тумблера Mic Mute | Светодиодный индикатор загорается красным, питание на микрофоны XMOS перестает поступать | PASS |
| 4 | Симуляция падения через mmWave радар (HLK-LD2450) | Система запрашивает голос («Всё в порядке?») и запускает 20-сек таймер | PASS |
| 5 | Запись аудит-лога при вызове инструментов | Проверка хэш-цепочки SHA-256 подтверждает непрерывность записей | PASS |

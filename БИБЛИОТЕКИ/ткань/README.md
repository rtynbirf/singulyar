# ТКАНЬ — P2P Human Information Fabric (ядро дома, такт v1.41.0)

Свой путь реализации ТЗ владельца **«СИНГУЛЯР — ТЗ P2P HUMAN INFORMATION
FABRIC v1.0»**: не параллельный мессенджер и не чужая библиотека, а
семь открытых модулей без единой зависимости, говорящих по-русски и
живущих по Своду законов дома (I-01..I-10).

## Слои ТЗ → модули

| Слой ТЗ | Модуль | Закон |
|---|---|---|
| 2 RelationshipLayer | `отношения.mjs` | R-01..R-07 |
| 4 ObjectLayer | `манифест.mjs` | O-01..O-06 |
| 5 RepresentationLayer | `представления.mjs` | жёсткие требования сильнее балла |
| 6 EligibilityLayer | `представления.mjs` | честный «недоступно/неизвестно» |
| 7 TransportLayer | `транспорт.mjs` | MEANING ≠ TRANSPORT |
| 8 IntegrityLayer | `целостность.mjs` | SHA-256 как единственная правда о байтах |
| протокол | `протокол.mjs` | SNG-P2P/1: offer → accept/reject → chunk* → complete → ack |

Слои 1/3/9/10/11 (Person, Intent, Security, Memory, Evidence) не дублируются
тканью — они уже живут в доме: ·19 ЧЕЛОВЕК, ·29 СВОБОДА, СВОД I-законов,
память по решению человека (I-06).

## Железные слова

- `MEANING ≠ TRANSPORT` — транспорт возит конверты, не читая их.
- `REPRESENTATION ≠ OBJECT` — манифест описывает передачу, не содержимое.
- `PERSON ≠ DEVICE` — отношение живёт без аккаунта (R-01).
- Явный выбор человека — первый в порядке решения, но жёсткие требования
  остаются железом: человек не просит машину навредить ему (ТЗ §6).

## Запуск

Комната дома: `СИНГУЛЯР_30_ТКАНЬ.html` (дверь ·30). Тест ядра:
`node ИНСТРУМЕНТЫ/test_s30_tkan.mjs`. Тест комнаты:
`python3 ИНСТРУМЕНТЫ/test_s30_browser.py`.

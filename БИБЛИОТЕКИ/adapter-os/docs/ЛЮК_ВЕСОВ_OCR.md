# ЛЮК ВЕСОВ OCR — процедура приведения чтения в дом

**Такт v10.95 «ЧТЕНИЕ» (С71) · строка А3, шаг 2 · владелец + агент**

Модель OCR (tesseract traineddata) живёт у владельца (закон честности: дом не
тащит и не качает веса; репа весов `rtynbirf/singulyar-llm` — соседняя). Эта
процедура — полный путь модели: от локального файла до пина в ledger
адаптера `input.ocr`.

## Шаг 1 — взять модель (локально, вне Pages)

Файлы `traineddata` проекта Tesseract лежат в репозитории tessdata (быстрый
вариант — tessdata_fast, точный — tessdata_best). Для дома по Закону о языках
(первый — русский): **`rus.traineddata`** первым, дальше **`srp`/`srp_latn`
(сербский — второй ВСЕГДА)**, **`kaz` (казахский — третий)**, **`deu`
(немецкий — четвёртый)**, далее языки по закону. Размеры обычно 1–45 МБ —
лимит git (100 МБ) проходит одной частью. **Размеры и SHA-256 дом по памяти
не называет** — пин фиксируется только по факту скачки файла.

## Шаг 2 — проверить и (если нужно) раскроить

```bash
sha256sum rus.traineddata
# файл ≤100 МБ идёт одной частью; крупнее — тот же инструмент, что у Whisper:
python3 БИБЛИОТЕКИ/adapter-os/tools/раскрой_весов.py rus.traineddata --вых OCR
```

## Шаг 3 — выложить в репу весов

1. Клонировать `rtynbirf/singulyar-llm`.
2. Создать каталог `OCR/`, положить файл(ы) + вписать раздел «OCR» в
   `MANIFEST.txt` (имя — размер — SHA-256 каждой части).
3. Закоммитить и запушить (PAT — у агента).

## Шаг 4 — пин в доме

В `БИБЛИОТЕКИ/adapter-os/adapters/ocr.mjs` регистрируется модель с пином:

```js
registerOcrModel({
  id: 'rus',                              // имя читаемое, без «/»
  runner: <замороженный ответ Tesseract.js-воркера>,
  движок: 'tesseract.js/wasm',
  веса: {
    имя: 'rus.traineddata',
    sha256: '<64 шестнадцатеричных знака из шага 2>',
    байт: <размер файла>,
    частей: 1,
  },
});
```

С этого момента статус адаптера `input.ocr` — READY с пином; до этого —
EXPERIMENTAL, честно (критерий А3: «модель пинится и проходит контрактные
тесты»).

## Шаг 5 — бенчмарк (ledger трека)

Корпус владельца (размеченные пары «картинка → эталонный текст», первый язык —
русский) прогоняется через `ocr-bench.mjs::прогонБенчмаркаOcr`: протокол
CER/WER + доля точных строк ложится в ledger трека. Тайминги устройств
измеряются снаружи. Мерила общие с speech-bench — одна нормализация на дом.

## Оффлайн-кэш (закон приватности)

Кэширование модели в браузере — по образцу llm.mjs (срез 4): Cache API, один
раз, дальше из кеша; `защищённые_кэши` versions.json уже держит
`transformers-cache` — новый ключ (`singular-ocr-v1`) добавляется владельцем
при пине. Runner обязан быть 0 сети: контракт принимает замороженный ответ,
веса уже локальны.

## Сторожа люка

- подпись файла проверяется адаптером по магическим байтам (не по ярлыку);
- SHA-256 целого = склейка частей по порядку — проверяется и раскроем, и
  `сверитьПин()` в рантайме (расхождение → данные не выдаются);
- веса НЕ попадают в Pages-репу дома;
- пока пина нет — нигде не пишется «проверено»: EXPERIMENTAL честно.

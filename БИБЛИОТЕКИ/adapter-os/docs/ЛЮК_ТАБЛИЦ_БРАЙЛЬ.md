# ЛЮК ТАБЛИЦ БРАЙЛЬ — процедура добавления языковых таблиц

**Такт v11.00 «БРАЙЛЬ» (С76) · строка А3, шаг 5 (последний) · владелец + агент**

У Брайля нет весов: перевод — детерминированная математика ячеек U+2800–U+28FF.
Но шрифт Брайля **языково-специфичен**: русская, сербская, казахская, немецкая
таблицы отличаются от латиницы grade 1. Дом честен: в нём живёт одна
встроенная таблица `latin-g1` (26 букв + 4 знака, канон Луи Брайля/UEB,
закреплён тестами байт-в-байт); таблицы других языков добавляет владелец —
этот люк описывает путь. **Закон о языках действует прямо**: порядок
пополнения — rus → srp → kaz → deu, далее языки СССР и народные.

## Шаг 1 — взять таблицу (локально, вне Pages)

Подходят: официальный стандарт языка (ГОСТ/ISO 11548-1 и национальные
приложения), таблицы NVDA/BRLTTY/liblouis (файлы `.utb` — читаются
текстом), учебные пособия тифлокомплекта. **Дом по памяти таблиц не
называет** — соответствие стандарту языка проверяет владелец; дом проверяет
СТРУКТУРУ (см. шаг 3) и закрепляет поведение тестами.

## Шаг 2 — оформить таблицу как объект

Форма: `{ 'символ': [точки], ... }` — точки 1..8 (7-8 — добавочные ячейки
компьютерного Брайля), пробел и перевод строки НЕ входят (служебные дома:
проходят как есть, структурой не торгуют). Пример-скелет:

```js
const РУС = {
  'а': [1], 'б': [1,2], /* ...полный алфавит языка... */
  ',': [2], /* пунктуация языка */
};
```

## Шаг 3 — регистрация (структуру проверяет дом)

```js
registerBrailleTable({ id: 'rus', таблица: РУС });
```

Дом проверяет: ключ — ровно один символ; точки — целые 1..8 без дубликатов;
пробел/перевод строки не подменяются; дубликат id — честный false. С этого
момента статус адаптера не меняется (READY честно — перевод
детерминирован), но в списке таблиц появляется `rus` с пометкой «таблица
владельца: структура проверена домом, соответствие стандарту языка — за
владельцем».

## Шаг 4 — контрактные тесты

Добавить в `tests/test-braille.mjs` блок с независимой копией канона языка
(как сделано для a–z): таблица и копия должны сойтись байт-в-байт. Тест —
единственная защита от опечатки в точках: дом не проверяет соответствие
стандарту, он проверяет структуру и детерминизм.

## Шаг 5 — дверь

После второй таблицы дверь требует id честно (дом не выбирает язык за
человека):

```js
брайль({ текст: 'Привет, дом', режим: 'с_заглушками' }, 'rus');
```

Незнакомый символ в строгом режиме — отказ с позицией и кодом; в режиме
`с_заглушками` — пустая ячейка U+2800 и список потерь в отчёте (ничего не
теряется молча).

## Границы люка

- grade 1 (посимвольная запись): сокращений grade 2 дом не ведёт — названо;
- физический дисплей (WebHID/OS accessibility) — hardware `optional` по
  контракту, вне адаптера;
- никакой сети: таблицы — код, веса не нужны, качать нечего;
- встроенная `latin-g1` не редактируется владельцем — канон дома закреплён
  тестами; новые языки — новые id.

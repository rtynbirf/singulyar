## Что сделано (шаг 3 из пяти — gaze)

### 1. `adapters/gaze.mjs` — реализация контракта взгляда

- **Ledger `adapter-os.gaze.v1`** — пуст на импорте (моделей в доме нет, и
  это честно); записи возвращаются копиями.
- **Честное разделение труда** — контракт требует четыре вещи, дом берёт
  свои: LANDMARKS — рантайм владельца (Face Landmarker / iris-модель, дом не
  тащит и не запускает веса — правда платформы ≤100 МБ); CALIBRATION,
  MAPPING, DWELL-SELECTION — три детерминированных ядра дома, покрытых
  тестами байт-в-байт.
- **Контракт runner** — синхронный, чистый, 0 сети (родня speech.mjs /
  ocr.mjs): `runner(задание) → { черта: { x, y, уверенность } } | { отказ }`;
  wasm-воркер и прочие асинхронные рантаймы приносят «замороженный ответ».
- **ПОДПИСЬ ФАЙЛА** — кадр камеры та же картинка, что у OCR: магические
  байты (6 форматов) сверяются с названным форматом; «названо png, лежит
  jpeg» — честный отказ, кадр не подменяется молча.
- **Калибровка `gaze-calib-affine/0.1`** — пары «точка кадра → точка экрана»,
  минимум 3, предел `МАКС_ТОЧЕК = 4096`; аффинное соответствие подбирается
  наименьшими квадратами (нормальные уравнения 3×3, правило Крамера — без
  библиотек, без часов); вырожденность (коллинеарные/совпадающие точки) —
  честный отказ «плоскость экрана не натянуть»; остаток сеанса назван числами
  (`ошибка_средняя`, `ошибка_макс`) — плохая калибровка видна, а не обещана.
- **Проекция** — применяет соответствие к черте; выход за экран НЕ поджимается
  молча: честный флаг `в_границах` (данные не подменяются; граница 0 и 1
  включена). Диапазона на черте кадра НЕТ — кадр живёт своей системой
  координат, границы ставит только проекция.
- **Dwell-selection (`событияDwell`)** — чистый редюсер выдержки над
  траекторией с ВНЕШНИМИ часами (t приносит запускающий; внутри 0 часов):
  радиус (по умолчанию 0.04), выдержка (600 мс), гистерезис `выход` (0.08,
  ≥ радиуса — иначе мёртв), порог_уверенности (точки ниже пропущены — названо
  честно). Немонотонное время — честный отказ «внешние часы текут назад».
  Событие «выбор» запирает точку: повторный выбор только после честного
  выхода из её радиуса — пулемёта кликов нет.
- **БЕЗ КАЛИБРОВКИ ДВЕРЬ ОТКАЗЫВАЕТ** (причина контракта: «landmarks are not
  calibrated screen gaze») — молча проецировать «на глаз» — подмена данных.
- **Пин весов all-or-nothing** + `склеитьЧасти`/`сверитьПин` через
  crypto.subtle (SHA-256; вектор "abc" держат все копии — speech, ocr, gaze;
  копия механики сознательна: самодостаточность адаптера, расхождение ловят
  тесты). Расхождение — данные не выдаются даже на байт.
- **Честный мок** — всегда отказ «МОК gaze: модели нет в доме…».
- **Дверь `взгляд`** — никогда не бросает; порядок честный и детерминированный:
  валидация → калибровка → соответствие (вырожденность ловится ДО вызова
  двигателя — не будим модель под заведомо мёртвой картой) → ledger →
  runner → разбор → проекция; одна модель — она, несколько — id обязателен.
- **`createGazeAdapter`** — статус по ledger: EXPERIMENTAL (пусто/без пина)
  → READY (есть пин), privacy local — камера не покидает устройство.

### 2. `adapters/gaze-bench.mjs` — бенчмарк на своих честных мерилах

Взгляду — геометрические мерила: **евклидова ошибка** черты против эталона
(в нормализованных единицах кадра) + **доля точек в допуске** (допуск называет
запускающий, по умолчанию 0.05). Текстовые мерила speech-bench сюда не
тянутся — одна нормализация на дом остаётся у слов, у взора — своя честная
геометрия. Протокол `adapter-os.gaze.bench.v1` без часов, детерминирован
байт-в-байт; отказы не превращаются в метрики; качество калибровки меряется
отдельно (остаток соответствия) — две меры не подменяют друг друга.

### 3. `docs/ЛЮК_ВЕСОВ_GAZE.md` — процедура приведения весов

Модель → раскрой (`tools/раскрой_весов.py`) → репа весов `singulyar-llm →
GAZE/` → пин → калибровочный сеанс владельца → бенчмарк корпуса. Веса взгляда
нейтральны к языку (Закон о языках действует на словарь подсказок сеанса);
оффлайн-кэш по образцу llm.mjs (ключ `singular-gaze-v1` при пине).

## Честные границы

- МОДЕЛИ ВЗГЛЯДА В ДОМЕ НЕТ: `input.gaze` — EXPERIMENTAL честно; критерий А3
  «модель пинится и проходит контрактные тесты» — тесты зелёные (16/16;
  регресс 4/4 + 16/16 + 14/14), пин ожидает люка владельца.
- Дом не проверяет КАЧЕСТВО калибровки владельца — он считает её остаток и
  называет числами; плохой сеанс виден по `ошибка_средняя`/`ошибка_макс`.
- Двигатель не выбран гвоздями: runner принимает любой рантайм с замороженным
  ответом; фиксируется при пине (поле `движок`).
- Камера/разрешения — вне контракта адаптера: дверь получает кадр, а не
  поток; явное действие человека и остановка треков — дело вызывающего слоя
  (реестр дома: Camera — PERMISSION_REQUIRED).
- Demucs (шаг 4) и Брайль (шаг 5) — контракты в `contracts.mjs` не тронуты
  (байт-в-байт); очередь по приоритету владельца.

# РАНТАЙМ-НАМЕРЕНИЙ (EIR v0.3.0) — мост дома

Приказ владельца (RUM23-9): «СПЕРВА ПРИАТТАЧЕННОЕ РАЗБЕРИ И НАЧИНАЙ ВСЁ ИНТЕГРИРОВАТЬ,
ЕСЛИ НАДО В РЕПЕ ОТДЕЛЬНУЮ ВЕТКУ СОЗДАТЬ ТО СОЗДАВАЙ». Пакет принят в дом целиком,
без переписывания — его законы честности совпадают с законами дома.

## Что это
**Emergent Intent Runtime** — исполняемое ядро: сохранить намерение человека при смене
способа исполнения и не объявлять задачу выполненной без подтверждённого конечного
состояния. Машина состояний (CREATED→PLANNED→EXECUTING→VERIFYING→CONFIRMED, честный
UNKNOWN), политика разрешений и согласий, независимая проверка конечного состояния,
failover только после `NotExecuted`, write-ahead журнал (SQLite, WAL, хэш-цепочка),
отпечатки вместо данных, 40 тестов (включая реальную смерть процесса между эффектом
и записью), лестница абляции B0→B3→EIR на 14 сценариях.

Это продолжение домовой линии: `ДОКУМЕНТЫ/СВЯЗЬ_ЧЕЛОВЕКА/ЯДРО_PYTHON/singulyar_core.py`
(ядро v0.1) и `ДОКУМЕНТЫ/СВЯЗЬ_ЧЕЛОВЕКА/ПАКЕТ_v0.1/` (спека) — здесь ядро v0.3
доведено до: три-статусных наблюдений (PRESENT/ABSENT/UNAVAILABLE), SQLite-журнала,
фейловер-списков способностей, жёстких ограничений (local_only/offline), схемы+валидатора.

## Соседи по дому
- `БИБЛИОТЕКИ/adapter-os/` — JS-родня (адаптеры взгляда/речи/брайля); EIR — Python-ядро
  исполнения намерений; линия их свадьбы — ROADMAP Фаза 2 (контракты способностей).
- `docs/РИТУАЛ_ТАКТА.md` — EIR даёт дому «адаптер сказал ок ≠ результат подтверждён».

## Запуск (Python 3.10+, без зависимостей)
```bash
python3 scripts/check.py        # тесты + демо + компиляция + отчёты + контрольные суммы
python3 -m unittest discover -s tests   # только 40 тестов
python3 src/demo.py             # failover, сбой после эффекта, честный UNKNOWN
```
Страж дома: `ИНСТРУМЕНТЫ/test_eir_рантайм.py` (гоняет тесты пакета в гейте CI).

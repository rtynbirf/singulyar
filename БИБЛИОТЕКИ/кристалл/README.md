Дата вшивки: 2026-10-03. Источник: reference-архив
`SINGULYAR_KRISTALL_REFERENCE_2026-10-03.zip` (нормативные инварианты)
+ протокол доставки `protocol/DELIVERY.md` из того же архива.

## Что это

Кристалл — НЕ мессенджер и НЕ страница. Это общий протокольный слой
связи СИНГУЛЯРА: канонический смысл отделён от представления, канала,
транспорта и хранения.

```text
СМЫСЛ ≠ ПРЕДСТАВЛЕНИЕ ≠ КАНАЛ ≠ ТРАНСПОРТ ≠ ХРАНЕНИЕ
```

## Что нормативно (в этой папке)

| Файл | Роль |
|---|---|
| `crystal-core.mjs` | ядро: semantic event, выбор представления, конверт, retention, идемпотентность, машина доставки |
| `journal.mjs` | durable журнал (IndexedDB `singulyar-crystal`): события, дедуп-ключи, записи доставки, purge истёкших |
| `semantic-event.schema.json` | wire-level контракт события (JSON Schema 2020-12) |

Правило изменений: файлы выше нормативны. Правка требует новой версии
и заметки о миграции. Всё остальное в системе — потребители контракта.

## Карта модулей (правило интеграции reference)

```text
·19 ЧЕЛОВЕК  → идентичность (identity.ref)      [мост будет в ·19]
·21 ОБЩЕНИЕ  → слой представлений/возможностей  [вшито: шина meaning.21.crystal]
·22 СВЯЗЬ    → канал/доставка                   [вшито: журнал + ACK + дедуп + TTL]
·18 ЗАЛ      → общая активность                 [мост будет в ·18]
```

Кристалл не заменяет модули — он их общий протокол. UI-контракты
модулей не ломаются: протокольный слой — усилитель, а не критический
путь. Падение импорта ядра = модуль работает как раньше (честный
fallback, в статусе видно).

## Машина доставки (DELIVERY.md, норматив)

```text
CREATED → QUEUED → SENT → ACKED → DELIVERED → READ
Ошибка:  QUEUED/SENT → RETRY[n] → FAILED   (FAILED → QUEUED — ремонт)
```

Правила: id события стабилен; ключ идемпотентности стабилен между
повторами; retry не меняет semantic payload; ACK ≠ READ; падение
транспорта ≠ падение сообщения, пока повторы не исчерпаны.

Реализовано в ·22: CREATED → SENT (уход пакета), ACK от получателя →
ACKED. DELIVERED ставится на стороне получателя при приёме. READ пока
не отправляется нигде — честный GAP, не притворяемся.

## Что уже работает (проверено тестами)

- смысл не меняется при любом представлении (инвариант reference);
- явный выбор человека выигрывает, недоступный выбор даёт наблюдаемый
  fallback (`explicit-choice-unavailable`), а не тихую подмену;
- временное сообщение умирает по TTL (retention purge в журнале);
- конверт транспорт-нейтрален (local/webrtc/webtransport — метка);
- повторная доставка отбрасывается по durable ключу (перезагрузка
  страницы дедуп не теряет);
- нелегальные переходы доставки отклоняются с `ILLEGAL_TRANSITION`
  (диагностика вместо тихого вранья).

## Чего НЕТ (честные GAP, не притворяемся)

- production E2EE (сейчас: подписи/шифрование живут в ·24, кристалл
  их не дублирует);
- production сигналинг и серверный релей (`server/README` reference
  описывает требования — вне браузерного прототипа честно);
- multi-device conflict resolution;
- push-инфраструктура и attachment resume;
- READ-статусы (никто их не шлёт);
- независимый accessibility-аудит выбора представлений.

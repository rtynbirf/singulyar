# КАНОН НАДЗОРА ДОМА — как волнам следить, поддерживать и уходить чисто

> **Статус:** ✅ Актуально · **Введён:** 2026-11-09 (приказ владельца «следить за состоянием дома, поддерживать его в надлежащем виде согласно канону и убирать все нотификации за собой»).
> Читатели: каждая волна агентов. Дополняется решениями владельца. Изменения — append-only с датой.

## 1. Панель надзора (снимать показания перед каждой работой)

| № | Датчик | Где смотреть | Здоровое состояние |
|---|---|---|---|
| 1 | Реестр дома | `data/versions.json` → `дом`, `счётчики` | такт/поколение растут монотонно; счётчики = словарю |
| 2 | Живые лица | футер хаба, `meta sng-build`, README «одна правда», JSON-LD ·35 | одна тройка «такт/кэш/SHA» на всех лицах |
| 3 | Воркер | `sw15.js` → `S15_CACHE`, страж `test_sw15_приёмка.mjs` | обязательное ядро доходит целиком; LKG переживает активацию |
| 4 | Оракулы CI | Actions: «Оракулы дома зелёные», «Такт-гейт», Lighthouse | зелёные; красный = запись в KNOWN_ISSUES с раном |
| 5 | Пин тела | oracle-rumu vs `cell-swarm/swarm.json` | после пуша — догон `make pins --write` волной с правом |
| 6 | Дрейф миров | main-drift-watch (ahead/behind) | дрейф известен и учтён в карте; конвергенция — работа хозяина |
| 7 | Деплой | Pages-журнал (`pages.yml`), живой URL | живой SW ≡ HEAD `rumu`; `meta sng-deploy-sha` = SHA HEAD |
| 8 | Хвосты | `KNOWN_ISSUES.md`, `TODO.md`, `PULSE.md`, #62/#64 | каждый красный имеет владельца и статус |

Показания пишутся в досье такта (стадия 1 ритуала). Без свежих показаний стадия «патчер» не начинается.

## 2. Цикл надзора (ежеволновой минимум)

1. **Досье:** показания панели (п.1), PAT/права верифицированы, задача такта одним абзацем.
2. **Сверка правды:** `python3 ИНСТРУМЕНТЫ/цех_правды.py` — обязан показать «ДРЕЙФ НЕТ» до начала правок (если дрейф уже есть — сначала чинится он, отдельным ходом).
3. **Прогоны до:** `node --test` по файлам оракулов, затрагиваемым работой; `node --check` правленых JS.
4. **Работа** — латки/такт по ритуалу; бамп `S15_CACHE` при любой правке `sw15.js`; новые активы — в пре-кэш.
5. **Прогоны после:** те же оракулы + `test_лица_правды.mjs` + `test_sw15_приёмка.mjs` + `test_цех_правды.mjs`.
6. **Живая поверка ЭП-06** на проде после отреза — чек-лист OK/FAIL, скриншоты.
7. **Журнал волны:** что сделано по стадиям, коммиты, остатки; записи — append-only.

## 3. Поддержание в надлежащем виде (канон)

- **Единственный источник чисел** — `data/versions.json` → `счётчики` (определения — в `счётчики.словарь`). Новое лицо дома подключается биркой `data-реестр="…"`, а не руками; фолбэки бирок выравнивает цех правды.
- **Истина о ветке деплоя:** `rumu` (см. `pages.yml`); AGENTS.md сверяется гейтом (T-072).
- **Закон обновления воркера:** приёмка (дымовая, комплектность обязательного ядра) ∧ согласие человека. «Агрессивный skipWaiting» — запрещён. Провал обязательного файла — брак установки: воркер не встаёт, last-known-good служит.
- **Ритуал такта** — единственный способ выпуска; латки следуют его чек-листу без номера такта.
- **Один факт — одно место:** пояснение числа живёт в словаре счётчиков, а не копируется по лицам.
- **Байты коллег не трогать; столкновение — честная перенумерация** (З.5 роя).
- **Медиа вне пре-кэша; защищённые кэши моделей переживают такты** (AI-АБСОЛЮТ).
- **Незыблемое AGENTS.md (п.1–7)** — эргономика/приватность, комод-архитектура, CSP-постур А, кэш-поколение, Git Data API для пуша.

## 4. Правило чистого следа (нотификации)

Каждая волна уносит за собой ВСЁ, что породила. Чек-лист ухода (проходит перед журналом волны):

- [ ] **Issues/треды:** пломба волны — один комментарий в живом трекере (#62/#64); новых тредов «для галочки» нет; свои треды закрыты или переданы с честным статусом и ссылкой.
- [ ] **CI-прогоны:** каждый красный ран этой волны починен догоном ИЛИ записан в `KNOWN_ISSUES.md` (ссылка на ран, причина, владелец хвоста). Красный без записи = брошенный след.
- [ ] **Пин:** после пуша в `rumu` — догон пина (`make pins --write` в cell-swarm) волной с правом, либо пометка хозяину в журнале (чужое репо молча не трогать).
- [ ] **Временные артефакты:** отладочные файлы, баннеры, латки-флаги, черновые ветки — удалены той же волной; ветки после посадки убираются.
- [ ] **Локальный сор:** песочница/стенд не оставляет файлов в корне репо; `.gitignore` не распухает от «временного».
- [ ] **Обещания людям:** каждое «сделаю позже» либо закрыто, либо стоит в `TODO.md` с владельцем и сроком-ориентиром.
- [ ] **Эскалации:** дефект вне права волны — СТОП-ГОРН, честная запись в KNOWN_ISSUES/TODO, передача хозяину; молчание запрещено.

Формула волны: **пришёл тихо — ушёл чисто; взял ход — закрыл ход.**

## 5. Эскалация и стопы

- **СТОП-ГОРН** (З.6 роя): якорь правки не единственный — стоп, правится патчер/тест, не дом; каждый горн — в летописи волны.
- **Чужие репо** (`cell-swarm`, `singulyar-llm`) — только по явному праву; нет права — запись хозяину.
- **Репо 1,58 ГБ** — полные клоны/переписывание истории только по протоколу П-38/П-71 (САРКОФАГ-НАУКА), руками хозяина.
- **Красный «ПИН УСТАРЕЛ»** — не дефект, а дизайн гейта; интерпретация красных прогонов — через KNOWN_ISSUES, не через фейк зелёного.

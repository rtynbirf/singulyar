## 1. Волна W1 — «Ритуал обновления человека» (UX §5, поверх ЛКГ-1)

**Задача.** Латка ЛКГ-1 оставила в воркере ключ согласия (`S15_ВХОД_В_ТАКТ`), но UI-ритуала ещё нет. Собрать его по файлу 24 §5 (КРУ V2): после установки нового такта честная карточка «Дом обновился: такт X · поколение Y · комплектность ядра Z/Z — Войти в новый такт / Позже».

**Требования.**
- Карточка читает приёмку воркера (`S15_PING` → `ядро_обязательное`; `S15_ПРИЁМКА` → годен/брак), не выдумывает числа.
- «Позже» — воркер ждёт, дом живёт на прежнем такте; согласие → `postMessage({type:'S15_ВХОД_В_ТАКТ'})` → перезагрузка лиц (латка С147 уже перезагружает при смене контроллера).
- Отказ не теряется: следующая установка показывает карточку снова.
- A11y: диалог в каноне дома (фокус-ловушка как в уд-панели хаба), `aria-live` оглашает факт обновления.

**Приёмка.** T-070 живой: при отказе сборка не активируется; при согласии активируется и переживает перезапуск браузера. Скриншоты обеих веток в `download/`.

## 2. Волна W2 — «Готовность фонда» (Фаза 1 п.3–5, F-002/F-023)

**Задача.** Честное состояние «фонд в доме»: `CORE_READY/SONG_READY/MODEL_READY/P2P_READY` в ·38/·32; счётчик «сколько аудио уже в кэше/OPFS»; ручной прогрев «вечера» (выбранные песни × языки) с прогнозом объёма и отменой; `SONG_UNAVAILABLE` вместо молчания при отказе raw/jsDelivr.

**Требования.** Не ломать закон «медиа вне пре-кэша»; готовность показывать, а не качать всё; счётчики — из реестра (словарь), не руками; новые состояния — в словарь счётчиков с определением.

**Приёмка.** T-015/T-016/T-073: выученная песня поёт в самолёте; невыученная честно помечена; отказ внешнего хоста объясним в UI.

## 8. Общие технические требования ко всем волнам

1. **Числа:** только из `data/versions.json` (словарь счётчиков); новое число = новое поле словаря с определением; ручное число в лице = красный CI.
2. **Воркер:** правка `sw15.js` = бамп `S15_CACHE`; провал обязательного = брак; LKG не стирать до приёмки; skipWaiting — только по `S15_ВХОД_В_ТАКТ`.
3. **Тесты:** каждый дефект закрывается со стражем (`ИНСТРУМЕНТЫ/test_*`); `node --check` всех правленых JS; python-оракулы детерминированные (без сети).
4. **Преф-кэш:** новые активы — в `S15_CORE`; тяжёлое (медиа, модели) — НЕ в пре-кэш.
5. **CSP-мета** — цельным текстом, постур А (шрамы v10.52/v10.54).
6. **Летопись/CHANGELOG** — append-only; «один факт — одно место».
7. **EN-зеркала** ключевых документов — той же волной (Директива 1 роя); в пакет агентов входят только RU-оригиналы — EN-зеркала пакета делает W1 первым пунктом.
8. **Чистый след:** чек-лист ухода из [docs/КАНОН_НАДЗОРА.md §4](КАНОН_НАДЗОРА.md) — обязателен перед журналом волны.

## Расшифровка владельца

Владыка сложил три слова в одну формулу: **ВЭБ — это не «веб-страницы», а три инструмента агента**. ИНТЕРНЕТ — глаза и уши (доступ к знанию мира); ПЕСОЧНИЦА — земля под ногами (локальная среда, где всё можно проверить); ПАЙТОН — язык, которым руки соединяются с головой (конвейеры, патчеры, пробы). Формула честная: без любой из трёх рук полимат — либо слеп, либо парализован, либо нем.

## Три инструмента

| Инструмент | Что это | Что умеет | Законы |
|---|---|---|---|
| **ИНТЕРНЕТ** | HTTPS-глаза: GitHub API (досье, Git Data API пушер), raw.githubusercontent (верификация пуша), чтение/поиск страниц (верификация мира) | досье такта; пуш блобами; сверка фактов; антигаллюцинации | без платных услуг (закон И-13 «СВОЙ МЕХАНИЗМ»); ключ только в `.git/config`, ровно один; веб-сессии для пуша запрещены (риск-движок откатывает); любой факт из сети — либо верифицирован, либо помечен «НЕПРОВЕРЕНО» |
| **ПЕСОЧНИЦА** | локальная земля: bash, git, node, стенды `http.server`, файловая система, дисковый запас | стенды и пробы; патчеры; байт-проверки; «досье» перед тактом | патчеры идемпотентны (второй прогон не ломает, guard-маркеры); СТОП-ГОРН на каждом гейте; байты коллег не трогать; всё живёт в `/home/z/my-project/` |
| **ПАЙТОН** | язык конвейеров: патчеры, пушер Git Data API, счётчики, тесты `test_*.py` | сборка тактов; JSON-реестры; поверки инструментов; конвейеры корпуса | скрипты живут файлами (не heredoc — правь, а не пересоздавай); stdlib прежде зависимостей; токены не печатаются никогда; честные русские отказы |

## Живая поверка — 2026-10-14, 8/8 зелёные

Инструмент поверки: [ИНСТРУМЕНТЫ/поверка_инструментария.py](../ИНСТРУМЕНТЫ/поверка_инструментария.py) — stdlib-only, 0 секретов, идемпотентен; код выхода 0 = все руки живы, 1 = СТОП-ГОРН такта. Фактический прогон этого такта:

  [OK  ] HTTPS-круг до GitHub API: за 110 мс; HTTP 403 — сеть жива, сервер ответил
         отказом по публичной квоте (ключ дома это лечит)
  [OK  ] raw дома (README.md): HTTP 200 за 392 мс, первые 2048 Б читаются

Пометка о 403: общая публичная квота api.github.com исчерпана для общих адресов — **это не смерть интернета**: ответ сервера сам доказывает живость сети (DNS+TLS+HTTP круг прошёл за 110 мс). Авторизованные вызовы с ключом дома ходят (досье такта: GET /user → HTTP 200). raw.githubusercontent квотами не задышит — верификация пушей идёт по нему.

## Ловушки, уже пойманные поверкой (не поймать дважды)

- **Кириллица в HTTP-заголовках запрещена**: `User-Agent: сингуляр-поверка` роняет запрос (`latin-1 codec can't encode`) — заголовки только ASCII (`singulyar-poverka/0.1`). Поверка поймала живьём 14 окт. 2026.
- **Отличай «сеть мертва» от «сервер ответил отказом»**: таймаут/DNS — инструмент мёртв (СТОП-ГОРН); HTTP 403/429 — сеть жива, квота исчерпана (честная пометка, лечение — ключ или ожидание). Смешать — либо ложная тревога, либо слепота.
- **Гит-фича: `%d` в формате не тянет** — в выводе `git log` скриптов не полагаться на тонкости форматов; нужное число считай по-питоновски.

## Как пополнять поверку

Новый инструмент (новый язык, новый доступ, новый стенд) — получает пробу в `поверка_инструментария.py`: имя, честный факт, отказ по-русски. Без пробы в поверке инструмент «не существует» для такта. Проба мёртвая — СТОП-ГОРН: такт не начинается, пока рука не вылечена.

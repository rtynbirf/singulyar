## 2. Карта посадки — исполнение

1. **Канон контрактов** — `js/контракты.js` (`контракты/0.1`, ES2019, опоры-инъекция `__КОНТРАКТЫ.ядро({сейчас})`, 0 сети, 0 innerHTML, 0 случайности): шесть типов валидаторами и фабриками; default-deny — «нет права в реестре» с названной причиной; отзыв правит право сразу; отказ без причины не проходит валидацию.
2. **Живой реестр контрактов** — `data/контракты.json` + кандидаты: дыра №1 «ЧЕГО НЕТ» закрыта в доме (конверт = меж-органный формат, реестр-возможностей = права), клетка cell-swarm — за правом владельца.
3. **Живой реестр миров** — `data/миры.json`: мир = ид/тип (ветка/тег/коммит-слепок)/статус (живой/могильник/заморожен)/роль/голова_на_замер/замер/закон; типы миров названы, релизы — миры поставки вне реестра (один факт — одно место).
4. **sg-registry** — перечитывает `data/контракты.json` и `data/миры.json` (кандидаты вверх по лестнице подпапок, cache-buster, 5 минут) → `SG_КОНТРАКТЫ`/`SG_МИРЫ` + события `sg-контракты-готов`/`sg-миров-готов` (закон «правда перечитывается»).
5. **Круг вопросов (слово владельца)** — доктрина `docs/КРУГ_ВОПРОСОВ.md` (+EN): три масштаба (индивид / сообщества / Человек как целое), общий круг как рамка о Человеке как целом (не повестка большинства, не сумма интересов), открытость круга (механизмы обнаружения новых вопросов), три направления (понимать существующее / обнаруживать возможное / создавать то, чего ещё не существует), роль Человека в ноосфере — Человек создаёт среду и новые возможности существования.
6. **Лица волны** — README (строки правды + доктрина в «Живой документации»), ·35 (раздел «Круг вопросов» ×4 вопроса, JSON-LD ×31, счётчик 31), ·37 (раздел «Миры и круг дома» с живой панелью из реестров), docs/README (+EN), СИНТЕЗ (карта знания), llms.txt.
7. **Страж волны** — `ИНСТРУМЕНТЫ/test_контракты.mjs`, 8 проб (см. §6).
8. **sw15.js** — бамп `S15_CACHE` v246→v247; пре-кэш +7 лёгких активов волны (канон, 2 реестра, разбор ×2, доктрина ×2 — закон новых активов); медиа вне пре-кэша — mp3-исключения прежние 2.
9. **Цех правды** — `--apply` по всем живым лицам (фолбэки бирок = v247 идемпотентно; «ДРЕЙФ НЕТ»).
10. **Летопись** — CHANGELOG, WORK_REPORT, карта агентов (+EN), versions.json (кэш v247, словарь +2: `контрактов`/`миров`, счётчики 8/6).

## 4. Слово владельца — контент доктрины вшит везде

Три масштаба вопросов (индивид / сообщества / Человек как целое); общий круг вопросов = рамка о Человеке как целом, **не** повестка большинства и **не** сумма индивидуальных интересов; круг не закрытый — с механизмами обнаружения новых вопросов; три фундаментальных направления — понимать существующее, обнаруживать возможное, создавать то, чего ещё не существует; роль Человека в ноосфере — **Человек создаёт среду и новые возможности существования** (не просто изучает мир и приспосабливается). Место вхождения: [docs/КРУГ_ВОПРОСОВ.md](КРУГ_ВОПРОСОВ.md) (канон, RU+EN), ·35 (живой разбор ×4 вопроса + JSON-LD для машин), ·37 (лицо о доме), README (живая документация), СИНТЕЗ (карта знания), llms.txt (карта LLM). Канон — один факт одно место; лица связывают, не дублируют.

| # | Дыра | Слово волны W4 |
|---|---|---|

| 2 | Общая долговременная память промахов | кандидат — волна W7 «Живой слой ревизии» (закольцовывает ревизию: промах — данные для следующего раза); исполнение — слово владельца |

## 6. Страж волны — ИНСТРУМЕНТЫ/test_контракты.mjs, 8 проб

1. **словарь счётчиков** — `контрактов`/`миров` определены (T-073), числа согласованы с реестрами (8 = len(контракты.json.контракты), 6 = len(миры.json.миры)); старый словарь W2/W3 цел.
2. **контракты/0.1** — ядро: версия, шесть типов, канон состояний, формы ·21, виды свидетельств; default-deny (нет записи — отказ с причиной); выдать/для/отозвать; конверт (собрать/исполнить/валидировать; падение исполнителя — честное «отказано» с причиной); паспорт SHA-256 (64 hex обязателен); представление (форма вне канона — отказ); событие-сессии; свидетельство (без следа — не свидетельство); детерминизм — два ядра с опорой «сейчас» дают байт-в-байт один результат.
3. **data/контракты.json** — схема; типы_V1 = шести канон-именам ядра; каждый контракт: ид/дверь/имя/файл/страж/типы ⊆ шести/закон/статус/замер; файлы-каноны и стражи существуют в репо; ид уникальны.
4. **data/миры.json** — схема; каждый мир: ид/тип из канона (ветка/тег/коммит-слепок)/статус из канона (живой/могильник/заморожен)/роль/голова_на_замер/замер/закон; могильник main назван тегом MAIN-2026-11-11, кончиком e9222f97 и ADR-0006; rumu — живая ветка; дрейф: «исчерпан», ADR-0006, «отдельная волна» + «правом хозяина».
5. **законы ядра** — исходник js/контракты.js: 0 fetch/0 XMLHttpRequest, 0 innerHTML, 0 eval, 0 случайности (`Math.random`), ES2019 (нет `?.`/`??`).
6. **лица волны** — README (строки Миры/Контракты + доктрина), ·35 (q-28…q-31 + JSON-LD ×31 + счётчик), ·37 (живой блок + SG_МИРЫ/SG_КОНТРАКТЫ), docs/README (+EN), СИНТЕЗ, llms.txt, доктрина (+EN) существует.
7. **воркер** — кэш v247 ≡ реестру; активы волны в пре-кэше (канон, 2 реестра, разбор ×2, доктрина ×2); mp3-исключения прежние 2, ноль нового медиа.
8. **sg-registry + node --check** — перечитывание контрактов/миров (кандидаты, окна, события, старт) + `node --check` правленых JS волны.

## Правила движения по карте

1. Брать СЛЕДУЮЩУЮ по порядку волну; прыжок — только по слову владельца (З.3 роя).
2. Волна = такт или серия латок; каждая правка `sw15.js` — бамп `S15_CACHE`.
3. Найденное вне своего хода — не трогать байты коллег: приём целиком + перенумерация (З.5).
4. «Готово» = DoD из [ТЗ_АГЕНТАМ.md §9](ТЗ_АГЕНТАМ.md), а не «коммит ушёл».
5. Что НЕ делается (дополнение к V1): агрессивный skipWaiting; ломать закон «медиа вне пре-кэша»; трогать летопись ·43 и архивные миры; считать красный «ПИН УСТАРЕЛ» дефектом; сводить три счётчика дверей к одному «правильному».

# ADR-0006 · Единая ветка rumu: могильник main по слову Хозяина

- Статус: принято (слово Хозяина 2026-11-11: «старьё снести, оставить чистовое, без черновиков»; исполнение — Полимат-Мультиагент)
- Заменяет к исполнению: ADR-0004 §Решение 1 (статус-кво двух голов) и ADR-0005 (протокол дрейфа) — повод исчерпан

## Контекст

Деплой 2026-11-10 22:08 UTC выкатил ветку `main` на живой сайт: оформление оголело
(на main нет шрифтов, `js/minus-fond.js` и аудиофонда `minus/`), минусовки отдавали
404, музыка исчезла. Хозяин постановил: черновую линию снести, оставить чистовую.

## Решение

1. **Чистовая ветка — `rumu`** (дефолт, Pages, фонд музыки, шрифты, канон-оформление).
2. **Порт из main**: `forge-hand.js` («хозяйская рука») установлен на все страницы
   `rumu` (ADR-0005 §2: копирование содержимого, пометка «порт из main»;
   merge/cherry-pick через разошедшиеся истории не применялись).
3. **Могильник main** (прецедент ADR-0004 §3): кончик `e9222f97e83552b693d61ea66c5684ebc3938cd5` живёт в
   аннотированном теге `MAIN-2026-11-11`; ветка `main` удалена. Латки `main`
   доступны через тег; портирование латок service-путей (scripts/, harness/,
   reports/) в rumu — отдельная задача, если понадобится.
4. **Сняты** `.github/workflows/main-drift-watch.yml` и
   `.github/workflows/parity-flip-check.yml` (сравнение двух голов более
   невозможно). `такт_гейт.yml` сохранён (триггер rumu/latka-*).

## Последствия

- Плюс: один источник правды; сайт и музыка физически не разрываются.
- Минус: латки main живут в теге, не в ветке.
- Отмена: `git push origin MAIN-2026-11-11:refs/heads/main` — ветка возвращается
  из могильника одной командой.

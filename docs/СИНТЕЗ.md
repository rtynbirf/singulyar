# СИНТЕЗ — дом одним взглядом

> **Статус:** ✅ Актуально · **Такт:** v10.61 «РУЧКИ» · **Обновлено:** 2026-10-11
> Один документ, чтобы понять дом за десять минут: что это, для кого, по каким законам, как устроено, как дышит, где что читать и куда идёт. ## 1. Что это

**СИНГУЛЯР · ЛАДОМ** — офлайн-вселенная караоке RUVSON: PWA без сервера, без сборщика, без слежки, без рекламы. Хаб ·00 и 31 дверь (`СИНГУЛЯР_NN_ИМЯ.html` + `СИНГУЛЯР_39_КОЛОНКА.html`), каждая живёт сама, вместе — дом. Зал вечера ·31 **ЛАДОМ** — сердце: песня «Просто люби» + плейлист зала на 62 песни minus/ (такт [10.63] «ТРАНСПОРТ»), флагман 157 языков — дверь ·01, пульт из шести видов реестра, Малыш — голос дома. Развернуть можно одной ссылкой: `https://rtynbirf.github.io/singulyar/` — дальше дом сам ставит ядро в пре-кэш и живёт без сети.

Бренд: устройство — **ЛАДОМ**, страница — «ЛАДОМ — пространство своих», подзаголовок — «Общайтесь так, как удобно каждому», зонтик — «СИНГУЛЯР · ЛАДОМ», слоган — «Быть рядом. По-своему.» Историческое имя «квартирник» из дома вычеркнуто; в летописи документов остаётся только как дата в истории (one fact — one place: факты живут в [CHANGELOG.md](../CHANGELOG.md)).

## 2. Закон (над всем)

**ЗАКОН СИНГУЛЯРА:** эргономика, приватность, конфиденциальность, юзабилити стоят во главе угла. Проект служит человеку и не испытывает его дискомфортом. Это фильтр каждой фичи: выигрывает фича, а человек проигрывает — фича отклоняется. Практические следствия: ноль счётчиков и сети для мозгов (LLM и слух — на устройстве), данные человека не покидают браузер, всё обратимо (закон I-11: обнаружим/объясним/управляем/обратим), честность вместо декларации («этого нет» — допустимый ответ; «ok: true» без настоящей проверки — нет).

## 3. Как устроено (минимум, чтобы не заблудиться)

- **Комод**: семьи функций живут в изолированных ящиках (script-блоки), наружу выходят мостами (`delete` + `defineProperty`) и лежат в комнатах как обычные вещи (`window.__*`). Логика не переписывается при переселении. — [АРХИТЕКТУРА.md](АРХИТЕКТУРА.md)
- **Манифест ядра** (`singulyar-modules.js`, `SNG.модуль`, v1.20.0) — единственный источник истины о дверях и нитях; **летопись** (`data/versions.json`) — версия, такт, счётчики, история тактов.
- **Кэш-поколения**: `sw15.js` держит поколение `s15-orkestrator-vNN`; новый такт = новое поколение (v114 на дату синтеза) — иначе жилец ходит по старому дому и думает, что правка не работает.
- **CSP**: постур А на всех лицах — `script-src 'self' 'unsafe-inline' 'wasm-unsafe-eval' blob:`; три молчаливых убийцы разобраны в шрамах v10.52/v10.54 (текст в head, хэш без кавычек, устаревший белый список хэшей).
- **Мозги на устройстве**: Малыш-LLM (Qwen2.5-0.5B через wllama, правила доучиваются с апстрима `rtynbirf/singulyar-llm`), слух — Whisper локально; виллера весов в доме нет — только дверь ·42 КОЛОНКА описывает полный стек автономной колонки.

## 4. Как дом дышит

Дом растёт **тактами**: один такт = одна версия = восемь стадий (досье → патчер → vm-тест → цех → пушер со СТОП-ГОРНОМ → отрез → живая поверка ЭП-06 → журнал). Имя такта — одно слово о сути («ПРОЁМ», «ОРГАНИЗМ», «АТЛАС», «ВАЛЬС», «СИНТЕЗ»). Такты не договариваются словами — они проверяются тестом и боем в браузере; столкновение тактов (двое пушат параллельно) разруливает СТОП-ГОРН: чужой ход первым — их имя и дверь, наши дельты ре-садятся на их байт, летопись восстанавливается. Полная инструкция — [РИТУАЛ_ТАКТА.md](РИТУАЛ_ТАКТА.md).

## 7. Состояние на дату синтеза (факты)

- **Дом**: хаб + 31 дверь; такт v10.61 «РУЧКИ»; кэш v116; манифест ядра v1.20.0; 62 песни; 157 языков флагмана; летопись — 49 тактов.
- **Пульт**: 6 видов реестра (ПОЛНЫЙ, РУЛЬ, ПЛИТКА, ⌘ КОМАНДА, ОМНИ — кольцо 360° в честь колонки-органа, ЛИЦА — мост к 11 лицам одного протокола); память `kv.pult`/`kv.litsa`; все шесть доступны из панели ВИД; роли ведущий/техник/гость/ребёнок.
- **Треки влиты**: ·39 ОРГАНИЗМ (геном 7 генов), ·40 ГАРМОНИЯ (HARMONIA .harm/0.1), ·41 НАМЕРЕНИЕ, ·42 КОЛОНКА (OMNISPEAKER-1 v0.4.0: DAG-оркестратор, Policy Gate с PIN, hash-цепочка SHA-256, VLAN-матрица, IaC).
- **Малыш**: двойной (обработчик v2 + LLM 0.5B), калм-точка присутствия с ручками-карточками (`__РУЧКИ` — генеративные действия с честным откатом «↩»), стриминг ответов, правила 13–16, учебник — [МАЛЫШ.md](МАЛЫШ.md) (части 1–9).

Числа не клясть: живая правда — `data/versions.json` и ЗДОРОВЬЕ дома (дверь ·38).

## 8. Куда идёт (дорожка)

Ближайшие строки карты — [ДОРОЖНАЯ_КАРТА.md](ДОРОЖНАЯ_КАРТА.md), «Приоритеты»:

- **Малыш-автономия**: переводы «Просто люби» — 228/732 пар собрано, дальше — партии и 12-язычные полные наборы, фонемные тайминги; план — `ДАННЫЕ/МАЛЫШ_ПЛАН.manifest.json`.
- **Зал ·17 P2P**: живой прогон двойного экрана (зал + пульт) на реальных устройствах.
- **adapter-os мост в ЛАДОМ** — присутствие МОЗГА в зале без дублирования весов.
- **Мыслящий ПУЛЬТ** — «недавние + предчувствия» по контексту.
- **Железо КОЛОНКИ** — фазы 0–5 из `КОЛОНКА/docs/07_DEТАILED_ROADMAP.md` (когда дойдут руки и детали по BOM).

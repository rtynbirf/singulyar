# ТЗ — живое техническое задание дома СИНГУЛЯР

> **Статус:** ✅ Актуально · **Такт:** v10.59 «СИНТЕЗ» · **Обновлено:** 2026-10-11
> Это живое задание: не мёртвый формализм, а обещания дома человеку с проверяемыми критериями. Чекбокс снимается только проверкой, не декларацией. См. также: [ДОРОЖНАЯ_КАРТА.md](ДОРОЖНАЯ_КАРТА.md) — что уже сделано; [АРХИТЕКТУРА.md](АРХИТЕКТУРА.md) — как это устроено.

## Закон дома (вне приоритетов — над ними)

**ЗАКОН СИНГУЛЯРА:** эргономика, приватность, конфиденциальность, юзабилити стоят во главе угла. Проект служит человеку и не испытывает его дискомфортом. Каждая история ниже читается только через этот закон: если фича выигрывает, а человек проигрывает — фича отклоняется.

## US-01 · Дом живёт офлайн
**Как** жилец, **я хочу** открыть дом без интернета, **чтобы** петь и жить в нём где угодно.

**Критерии приёмки:**
- [x] Первая загрузка ставит ядро дома в пре-кэш service worker (`sw15.js`)
- [x] Холодный запуск без сети открывает лицо дома с 28 дверями
- [x] Кэш поколенческий: `s15-orkestrator-vNN` — новый такт = новое поколение, старое вытесняется целиком
- [x] Ядро офлайна неприкасаемо при вытеснении (док «СТАЛЬ_НИТИ_И_ЯДРО.md»)
- [x] Страховочный КОРД в каждой странице: нить порвалась — дом держит

## US-02 · Приватность без исключений
**Как** жилец, **я хочу** знать, что мои данные не покидают устройство, **чтобы** доверять дому.

**Критерии приёмки:**
- [x] Ноль внешних счётчиков, трекеров, аналитики — дом не следит
- [x] Мозг Малыша (Qwen2.5-0.5B) работает локально (wllama, wasm) — слова не уходят в облако
- [x] Слух (Whisper) — на устройстве; ключи фонда рождаются и умирают в браузере
- [x] В ПУЛЬТЕ стоит золотой щит «данные не покидают дом» — обещание видно, а не спрятано
- [x] CSP жива на всех лицах дома (постур А канона, воскрешена в v10.54) — политика исполняется, а не декорация
- [x] Публичная репа содержит только то, что можно показать миру

## US-03 · Навигация: намерение → дверь
**Как** жилец, **я хочу** сказать или написать, чего хочу, **чтобы** дом сам открыл дверь.

**Критерии приёмки:**
- [x] Нить Ариадны на лице: все двери реестра (31) видны с холодной загрузки
- [x] Поиск АРИАДНА: намерение словами → дверь (62 песни фонда + документы в индексе)
- [x] Опечатки прощаются (Левенштейн); честная пустота вместо мусора
- [x] Меню дома в правом верхнем углу каждой комнаты несёт полную навигацию по дверям
- [x] Нити дверей симметричны: из A в B и из B в A
- [x] Ни одна комната не тупик (такт v10.52 вытащил ПУЛЬС ·38)

## US-04 · Караоке: от минуса до очков
**Как** поющий, **я хочу** выбрать песню и получить сцену, **чтобы** петь с поддержкой и очками.

**Критерии приёмки:**
- [x] 62 локальные минусовки фонда (папка `minus/`) — ноль сети
- [x] Тексты вшиты; слово-вайп по весам; ТЭП-очки (ИДЕАЛ/ТОЧНО/комбо/рекорд)
- [x] Темп/сдвиг/громкость обратимы (закон I-11)
- [x] ·16 СУФЛЁР: микрофон→MIDI→очки; ·20 ФОНЕТИКА: офлайн-романизация любой письменности
- [x] 157 языков одной песни — «КОГДА ТЕРЯЕМ»: от казахского до суахили

## US-05 · Малыш: голос дома
**Как** жилец, **я хочу** спросить дом голосом и получить живой ответ, **чтобы** ходить по дому без пульта.

**Критерии приёмки:**
- [x] Малыш двойной: обработчик v2 в ЛАДОМ ·31 + LLM Qwen2.5-0.5B в ОБЩЕНИИ ·21
- [x] Работает офлайн на устройстве; правила доучиваются с апстрима `rtynbirf/singulyar-llm`
- [x] Правило 13 «ЗНАНИЕ ДОМА»: карту 28 дверей знает наизусть, дверей не выдумывает
- [x] Правило 14 «ЗАКОН ДОМА»: честно говорит, чего нет, и показывает дверь, где это живёт
- [x] Правило 15 «ДОКУМЕНТАЦИЯ ДОМА»: ведёт по docs/ и отвечает фактами из data/versions.json
- [x] Стриминг ответов токенами (aria-live + кнопка «Стоп») — сделано в v10.55 «ПОТОК», проверено боем
- [x] Калм-тех точка присутствия в зале (тихая точка-дыхание, по умолчанию молчит) — сделано в v10.55, в КАЗНЕ и ЗДОРОВЬЕ

## US-06 · ПУЛЬТ: один пульт — пять лиц
**Как** ведущий вечер, **я хочу** управлять домом с одного пульта, **чтобы** вести вечер без лишних слов.

**Критерии приёмки:**
- [x] Шесть видов реестра: ПОЛНЫЙ, РУЛЬ, ПЛИТКА, ⌘ КОМАНДА, ОМНИ (кольцо 360° в честь колонки-органа, дверь ·42), ЛИЦА — мост к 11 лицам одного протокола; все шесть — чипами в панели ВИД (память kv.pult/kv.litsa); палитра КОМАНДА — Ctrl+K, 52+ команд
- [x] Палитра КОМАНДА: Ctrl+K / Cmd+K / Ctrl+Л, поиск, стрелки, Enter, Esc
- [x] Дом помнит последний вид (`kv.pult`) и последние 5 команд (`kv.pult.команда`)
- [x] Роли: ведущий / техник / гость / ребёнок — дом подстраивается, не урезая функции (I-11)
- [x] Всё обратимо; телефон-пульт ЛАДОМ_ПУЛЬТ_ТЕЛЕФОН.html — управление из кармана

## US-07 · Человек в центре
**Как** человек с своими возможностями, **я хочу**, чтобы дом подстроился под меня, **чтобы** быть хозяином, а не гостем.

**Критерии приёмки:**
- [x] ·19 ЧЕЛОВЕК: адаптация по возможностям, «позвать спеть», личность без выноса ключей
- [x] ·21 ОБЩЕНИЕ: один смысл — разные представления (текст/Брайль/речь/вибро), голос — настройка получателя
- [x] `prefers-reduced-motion` гасит движение по всему дому
- [x] WCAG 2.2 аудит внутри дома (·29 СВОБОДА); справки при наведении вместо эха
- [x] Человек не «растёт» — он наполняется; дом подстраивается под слово

## US-09 · Фонд: тихая помощь
**Как** помогающий, **я хочу** поддержать дом одним движением, **чтобы** моя помощь была моей — тихой и защищённой.

**Критерии приёмки:**

## US-10 · Треки — братья, не чужие
**Как** автор трека (СИНГУЛЯР_01/02 и другие), **я хочу**, чтобы мои работы были полноправными дверями дома, **чтобы** вселенная росла в ладу, а не в разброде.

**Критерии приёмки:**
- [x] Треки самодостаточны: один файл = вся платформа
- [x] Двери треков стоят в АРИАДНЕ и в летописи дверей
- [x] Горн-протокол интеграции: байты трека принимаются/резкуются с честной летописью
- [x] Ноль изображений там, где всё рисуется кодом — канон дома

## US-11 · Дверь ·42 КОЛОНКА — автономная умная колонка трека
**Как** жилец, **я хочу** в доме умную колонку, которая слушает, думает и действует строго локально, **чтобы** дом заботился без облака и не испытывал моим дискомфортом.

**Критерии приёмки:**
- [x] Дверь ·42 КОЛОНКА (`СИНГУЛЯР_39_КОЛОНКА.html`) открыта с хаба; нити дома симметричны (хаб ⇄ ·41 ⇄ ·42 ⇄ хаб)
- [x] DAG-оркестратор живой: цель словами → план шагов с рисками; Policy Engine останавливает medium/high (подтверждение кнопкой) и critical (PIN); инструмент вне policy_rules.json честно отклоняется (default_action: deny)
- [x] Hash-Chain аудит — настоящий SHA-256 (`crypto.subtle`); цепь копируется и стирается кнопками; «Стоп» честно рвёт конвейер
- [x] Аппаратная приватность: микрик обесточивает «ухо» (LED + бейдж + запись в аудит), механическая шторка двигает объектив; VLAN-матрица объясняет каждое правило словами
- [x] Вкладка Сеть·IaC показывает настоящие файлы дистрибутива КОЛОНКА/ (compose, policy, nftables, terraform, ansible) с копированием в клик
- [x] Пробы ЗДОРОВЬЕ: 10 органов живы (organism-тест 47/47 — каждая кнопка отвечает наблюдаемым откликом); 0 ошибок консоли; мобайл 390px без переполнений
- [x] Дом помнит выбор человека (вкладка, цель, рубильники, параметры корпуса) и умеет его забыть одной кнопкой
- [x] Service worker: дверь ·42 в пре-кэше ядра (поколение v113)
- [ ] Железо трека собрано и ПСИ пройдена (фазы 0–5 из карты — когда дойдут руки и детали по BOM)
## US-12 · Чутьё пульта — дом угадывает следующий шаг
**Как** жилец, **я хочу**, чтобы пульт угадывал моё следующее действие по контексту вечера и честно объяснял догадку, **чтобы** рулить одной кнопкой без поиска по вкладкам и не испытывать дискомфорта.

**Критерии приёмки:**
- [x] Полоса «ЧУТЬЁ» в ПУЛЬТе показывает предчувствия по контексту (старт → «▶ НАЧАТЬ ВЕЧЕР»; песня идёт → «⏸ ПАУЗА», «◻ ТИШИНА»; пауза → «▶ ПРОДОЛЖИТЬ»; сцена N → следующая) — каждое с объяснением «почему»
- [x] «Недавние» помнят последние действия (до 8, `kv.pult.чутьё`); у тишины и юстировки — честный откат «↩», где откат нечестен — кнопки нет (закон I-11)
- [x] Ветка ◉ ОБЩИЙ РУЛЬ / ◈ ЛИЧНЫЙ помнится (`kv.pult.ветка`) и открывается по умолчанию; фильтр недавних и предчувствий честный
- [x] Отказы роли и неопознанные намерения не попадают в память; приватность: всё в `kv.*` этого браузера, ноль сети
- [x] Роль-гард: неведаемое не предлагается (канон РОЛЕЙ)
- [x] Проба ЗДОРОВЬЕ чутья зелёная; мобайл 390px: цели ≥44px, ноль переполнений; vm-тест 19/19, консоль чиста
- [x] Паспорт пульта несёт строку чутья (строка двери ·42 — ход «СИНТЕЗ»)

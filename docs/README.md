## Правила этой папки

- Один факт живёт в одном месте: дорога — в ДОРОЖНОЙ_КАРТЕ, факты о вышедшем — в CHANGELOG, истина об устройстве — в АРХИТЕКТУРЕ.
- Шапка каждого документа отвечает: статус, версия, дата. Внизу — соседи.
- Приватность — закон: в `docs/` публикуется только то, что можно показать миру. Персональные данные, ключи, внутренние журналы — вне репы.
- Счётчики дверей берутся из `data/versions.json` и `singulyar-modules.js` (манифест ядра) — не из старых абзацев README.

- ✅ **Этап 1. Учебный слой без ИИ** *(закрыто v10.73 «СВЕДЕНИЕ КАРТ»)*:
  - тап по слову строки → компактная карточка [Повторить] [Понял] [Хочу вернуться] (+ честное «✕ забыть» у отмеченного);
  - клавиатурный эквивалент — клавиша **C** (карточка активной строки целиком); Esc / тап мимо / Android Back закрывают, фокус возвращается;
  - слова активной строки фокусируемы (tabindex/role/aria) — работает клавиатурой, скринридером и ТВ-пультом;
  - локальная память `kv.контур` (песня + строка + слово + статус + время + число возвратов); удаление реально удаляет;
  - подсветка отмеченного на гране СЛОВО (подчёркивание янтарём); переключатель Оригинал/Язык/Оба уже жил в доме (три строки на выводе);
  - послепесенное приглашение в брава-экране: до 3 «вернусь»-выражений, кнопки Прослушать (честный отрезок строки) / Сказать-спеть (retrieval: скрыть-показать) / Закрыть — закрывается одним действием, без последствий;

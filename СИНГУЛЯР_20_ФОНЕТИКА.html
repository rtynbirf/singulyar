4 · Честные границы

  • Тоны пиньиня не подаются — any-ascii даёт слоги без диакритики (dang wo men); тональная разметка — дорожная карта.
  • Арабский/иврит — романизация без огласовок (char-таблицы), произношение приблизительное.
  • Хангыль — по слогам без сандхи-слияний (anu → «an nyeong», не «annyaeng»).
  • Кана — Hepburn-подобная таблица any-ascii; малая цу аппроксимирована (きっぷ → «kitpu»).
  • TTS зависит от ОС: локальные голоса есть не для всех 158 языков; если голоса нет — звучит голос по умолчанию или честный статус «голоса нет». В headless-браузерах speechSynthesis может отсутствовать — романизация при этом работает полностью.
  • file://: динамический import бандла может быть заблокирован браузером — открой модуль по HTTP (Pages или любой локальный сервер). Это то же ограничение, что у ·18.
  • IPA — не подаётся; романизация по ТЗ («IPA / романизация» — выбран второй путь).

ШАГ 1 ПРЯМО СЕЙЧАС: оживить сайт

В чате ассистент написал код из 8 знаков (типа XXXX-XXXX). Код живёт 15 минут — не переживай, если истёк: напиши в чат «дай код», и его дадут заново.

  1. Открой на любом устройстве: https://github.com/login/device
  2. Введи код из чата → кнопка Continue / Продолжить
  3. Войди в свой GitHub → кнопка Authorize

ВСЁ. Дальше магия сама: новая версия (почта ·24, кошелёк ·25, линия ·26, КРИСТАЛЛ) улетит на сайт за 1–2 минуты. Секреты нигде не сохраняются — код одноразовый.

Почему так: сайт хостится у GitHub, и «открыть дверь» может только тот, кто пришёл. Здесь каждый сам хозяин — это твоя обычная кнопка двери, никаких настроек.

ШАГ 2 Открыть СИНГУЛЯР

Адрес один и навсегда: https://rtynbirf.github.io/singulyar/

Работает с телефона, планшета, ноутбука, ПК. Интернет нужен для связи между людьми; сам караоке-движок поёт даже без сети.

ШАГ 3 Поставить как приложение (1 минута)

Android (Chrome / Яндекс / Samsung Internet)

  • Меню ⋮ (три точки справа вверху) → «Установить приложение» или «Добавить на главный экран» → Установить.

iPhone / iPad (только Safari, так устроен iOS)

  • Кнопка Поделиться (квадрат со стрелкой вверх) → прокрутить → «На экран „Домой“» → Добавить.

Windows / Linux (Chrome, Edge)

  • В адресной строке справа появится значок / ⊕ «Установить» → клик → Установить. Нет значка: меню ⋮ → «Трансляция, сохранить и поделиться» → «Установить страницу как приложение».

macOS

  • Chrome/Edge: значок установки в адресной строке. Safari 17+: меню Файл → Добавить в Dock.

После установки значок СИНГУЛЯРА лежит на рабочем столе как обычное приложение — полное окно, без адресной строки. Обновления подтягиваются сами: просто открой приложение (если что — закрыть и открыть ещё раз).

Честно: с ярлыка «файл на диске» приложение не ставится — нужен сайт (https). GitHub Pages — подходит, всё уже готово.

Открой СИНГУЛЯР_23_КРУГ.html. Один раз тапни себя — на каждом устройстве СВОЁ имя. Имена круга знает дом: список держится в комнате ·23.

ШАГ 5 Румы — залы дома

  • ДОМ-ЗАЛ — главный зал: чат ВСЕГДА СОХРАНЯЕТСЯ. Кнопки «стереть» не существует, история не пропадает никогда, а при встрече двух устройств сама добирает недостающее.
  • КАРАОКЕ — зал для пения, зовёт общий зал ·18.
  • КУХНЯ и ВСЕМ-ВСЕМ — болталки.
  • Личные чаты — один на один с любым из круга.

ШАГ 6 Звонки и автоответчик

  • В чате любого рума / личном чате: кнопки аудио и видео — звонок идёт напрямую между устройствами (P2P), без серверов посередине.
  • Не взяли трубку — включится автоответчик: сам ответит и предложит оставить голосовое. Голосовое прилетит адресату.
  • При первом звонке браузер спросит про микрофон и камеру — жми «Разрешить». Это один раз.
  • Правило хорошего звука: наушники — и слышишь собеседника, и он не слышит сам себя.

ШАГ 7 Что появится после ШАГА 1

  • ·24 ПОЧТА — у каждого свой ящик имя@singulyar: письма с подписью, вложения, офлайн-отправка (адресат появится в сети — уйдёт само). Экспорт в .eml — откроется в любой почте мира.
  • ·25 КОШЕЛЁК — тихие переводы: нажал на человека → сумма → ВСЁ. Никаких подтверждений и уведомлений третьим: куда и зачем человек тратит СВОИ средства, знает только он. ХОТЕЛКИ: заявить («пирожок — 50 ₽»), закрыть можно молча.
  • ·26 ЛИНИЯ — свой внутренний номер у каждого, SMS между своими, одноразовые коды-пароли (OTP). Внешний номер — рецепты внутри модуля, когда дозреешь.
  • КРИСТАЛЛ — невидимое ядро связи: смысл доходит нетронутым, дубли выкидываются, «временные» сообщения умирают через 7 дней. Работает сам, трогать не надо.

ШАГ 8 Проверка: всё ли работает

  1. Сайт открывается, шапка показывает версию v1.33 (или выше).
  2. Ты вошёл в КРУГ под своим именем, чип виден.
  3. Написал в дом-зал, закрыл вкладку, открыл снова — сообщение на месте (сохраняется).
  4. Со второго устройства видно, что ты в зале — звонок проходит в обе стороны.
  5. Приложение установлено и открывается с рабочего стола.

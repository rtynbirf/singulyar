# УСТАНОВКА СИНГУЛЯРА КАК ПРИЛОЖЕНИЯ · на всё

СИНГУЛЯР — это PWA (Progressive Web App): сайт, который штатно устанавливается как приложение на телефон, планшет, ноутбук и ПК. После установки он открывается без адресной строки, живёт на рабочем столе и работает офлайн (страницы и кеш хранит сервис-воркер).

**Адрес для установки:** `https://rtynbirf.github.io/singulyar/`

---

## 1 · Android (Chrome, Яндекс.Браузер, Samsung Internet, Edge)

1. Открой `https://rtynbirf.github.io/singulyar/` в Chrome (или другом браузере из списка).
2. Нажми меню **⋮** в правом верхнем углу.
3. Выбери **«Установить приложение»** (в Samsung Internet — «Добавить страницу в» → «На экран “Домой”»).
4. Подтверди — иконка появится на рабочем столе и в списке приложений.

Альтернатива одним касанием: в самом СИНГУЛЯРЕ, в модуле **КРУГ ·23**, есть кнопка **«⬇ УСТАНОВИТЬ»** в шапке — браузер сам покажет диалог установки.

- Работает: офлайн-открытие, полноэкранный режим, ярлыки долгого нажатия (КРУГ / СПЕТЬ / ЗАЛ).
- Если пункта «Установить приложение» нет — сайт уже открыт как установленное приложение, всё в порядке.

## 2 · iPhone и iPad (только Safari — так устроен iOS)

1. Открой `https://rtynbirf.github.io/singulyar/` в **Safari**.
2. Нажми кнопку **«Поделиться»** — квадрат со стрелкой вверх.
3. Пролистай список вниз и выбери **«На экран “Домой”»**.
4. Нажми **«Добавить»** — иконка СИНГУЛЯРА появится рядом с приложениями.

- Chrome/Firefox на iOS установить нельзя: Apple разрешает установку PWA только через Safari.
- Свайп по центру нижнего края — быстрый возврат домой к иконке.

## 3 · Windows 10/11 (Chrome, Edge)

1. Открой сайт в Chrome или Edge.
2. В адресной строке справа появится иконка **«Установить»** (экран со стрелкой / плюс) — нажми её.
3. Если иконки нет: меню **⋮** → «Транслировать, сохранить и поделиться» → **«Установить страницу как приложение»** (в Edge — «Приложения» → «Установить этот сайт как приложение»).
4. Приложение появится в меню «Пуск»; правой кнопкой — «Закрепить на панели задач».

## 4 · macOS (Chrome, Edge, Safari 17+)

- Chrome/Edge: иконка установки в адресной строке → «Установить».
- Safari 17+: открой сайт → меню **Файл** → **«Добавить в Dock»**.
- Приложение появится в Dock и Launchpad — открывается в отдельном окне без адресной строки.

## 5 · Linux (Chrome, Chromium, Edge, Yandex)

1. Открой сайт в браузере.
2. Меню **⋮** → **«Установить приложение»** (или иконка в адресной строке).
3. Иконка появится в меню приложений дистрибутива.

## 6 · Планшеты

- Android-планшет — так же, как Android в п.1.
- iPad — так же, как iPhone в п.2.

## Что даёт установка

- Иконка на рабочем столе — заходишь одним касанием, без браузера.
- Открывается в отдельном окне, полноэкранно.
- Офлайн: страницы и данные уже на устройстве (сервис-воркер кеширует периметр).
- КРУГ ·23: чаты и журнал — на устройстве; ПАПА-ДОМ хранится всегда.

## Честные границы

- Звонки КРУГА ·23 требуют сети (сигналинг через публичные Nostr-релеи, медиа — напрямую между устройствами P2P). Если обе стороны за жёстким симметричным NAT без TURN — соединение может не пробиться; чат продолжит работать.
- Push-уведомления не используются: для них нужен свой сервер, а СИНГУЛЯР работает без серверов. Звонок «дозвонится», только если приложение получателя открыто (телефон/планшет разбудит рингтон и вибрация).
- iOS: рингтон в фоне ограничен системой — звонки принимаются, пока СИНГУЛЯР открыт.
- Данные хранятся в браузере устройства: очистка данных сайта сотрёт чаты (ПАПА-ДОМ тоже — он вечный, пока жив браузер).

## Проверка установки (30 секунд)

1. Установи по своей платформе выше.
2. Открой СИНГУЛЯР с иконки — окно без адресной строки.
3. Открой **КРУГ ·23** → вкладка **Я** → «Установить как приложение» — там те же подсказки, всегда под рукой.
4. Включи авиарежим и открой СИНГУЛЯР снова — страницы открываются (офлайн-кеш).
